## 1. 定位与第一卖点

**一句话**：一盒**会自己活起来的纸雕微缩世界**——你可以让它与真实时间同频（天气、昼夜、季节皆真），也可以把时间握在手里；你攒下的「余响」开出的**元素包**决定这次能怎样改写它；而它永远不会输。

### 1.1 「现实的桥」三层映射

| 层 | 现实输入 | 世界响应 | 刷新 |
|---|---|---|---|
| 年代环 | 系统日期 | 季节 / 节气阶段；物候、活跃度、地表色板 | 跨真实日 |
| 日照 | 系统时间 + 本机纬度 | 昼长比例、太阳高度角峰值、光照强度与色温 | 每世界日 |
| 天象 | 联网天气 | 你那下雨，界里也下雨；**某些存在只在真实的雨天 / 初雪 / 大雾里出现** | 每 30 分钟 |

### 1.2 现实与虚拟的分工

现实提供"**内容**"，世界钟提供"**节奏**"。真实模式下节奏也交给现实（适合挂着看）；虚拟模式节奏归你（3 分钟一轮昼夜，适合玩）。双向可切（§5.5）。

### 1.3 世界观：界、界外、七原质 · 器物（★本轮修订）

**世界是一座界** —— 不是谁造的，而是**本来就浮在那里**。玩家不在界里，而在**界外最近的那处岸上**。

| 层 | 名 | 内容 |
|---|---|---|
| **外** | **界外** | 界壁之外：**七原质**的本源，以及偶尔漏进来的**外来碎片**（即禁物，⑥） |
| **中** | **七原质** | 世界的**基本材料**：金 · 木 · 水 · 火 · 土 · 光 · 暗，**固定七种、不可增删** |
| **内** | **器** | 界里的一切，都是**七原质的配比** |

**① 界外与「岸」**

界壁之外不是虚无，是**界外**——它一直在压着这座界。压进来的东西沉进界里，成了**七原质**（五行与光暗）。

> **你的真实世界，是界外里离这座界最近的那处「岸」。** 真实的时间、天气、纬度不是"联动"，而是**你站在岸上，看着同一片界外压着这座界**（§1.1、§6）。

**② 七原质**

**世界由七种原质组成**：**金 · 木 · 水 · 火 · 土**（五行：走**五行生克**）+ **光 · 暗**（**与五行互相独立**，自成一对生克）。**七原质固定，不可增删**，合称**七元素**。

**「质」分两种**（其中**异质已整体撤出核心，留作日后扩展**，见 ④）：

| | 是什么 | 状态 |
|---|---|---|
| **原质** | 世界的**基本材料**，7 种固定 | **核心，本作按此运行** |
| ~~**异质**~~ | 质变的产物：由原质合成 | **★已撤出核心，留档待扩展**（④） |

**质变**：七原质不是死材料——**质可以互相转化（质变）**；卡做的事，就是**推动这种转化**（§10.3 创造 / 消除 / 转换）。**质变不再对应任何"性"这一层标签**（见下）。

> **★本轮修订：删除「三原性 / 21 个原性标签」。** 此前每条原质有三个作用倾向（7 × 3 = 21），既当**卡的效果标签**、又当**世界模拟的物理清单**——**这套设定整体撤出**。卡的描述改用**卡类 × 类别 × 卡型 × 元素 × 级**五项（§10.6），**具体效果写在各卡的"参数与模拟效果"里**。「原性」「异性」与"新质"同列作废（§21 #21–#23、§22 第 26 轮）。

**术语表（核心只有一个：原质）**：

| 名 | 是什么 | 数量 | 状态 |
|---|---|---|---|
| **原质** | 世界的**基本材料** | **7** | **核心**，固定不可增删 |
| ~~原性~~ | ~~原质的作用倾向（7 × 3 = 21 个标签）~~ | —— | **★本轮删除，不再存在** |
| ~~异质~~ | ~~原质合成出的质~~ | —— | **★撤出核心，留档待扩展**（④） |
| ~~异性~~ | ~~异质自带之性~~ | —— | **★同上** |

> **元素 vs 级（两个正交维度）**：**元素**是世界的材料（7 种，§1.3②）；**级（环级）**是改动的**尺度**（**0 – 9 + 禁物**，§10.10）。**两者正交**——任何元素都覆盖全部级，任何级都有全部元素；**元素间**走生克（§10.5），**级之间**只讲尺度覆盖。

**⑤ 环级（0 – 9 · 禁物）★本轮修订**

卡按**尺度**分**环级**——**不是强度，是世界被改动的范围**（§10.10）。**数值越大，尺度越大**：

| 环级 | 名 | 说明 |
|---|---|---|
| **9** | **神卡**（最高） | 该元素（× 该卡类）的顶点（**共 11 级**） |
| **8 … 1** | **常规** | 从一粒沙到整界，数值越大改得越广 |
| **0** | **碎片卡**（最低） | **尺度最微的卡**：**有真实效果**，只是小到**"一片碎片"** |
| **禁物** | **禁物**（第 11 级 · 无等级） | **不在尺度上**：界外碎片，**都有负面效果**（⑥） |

> **本轮定名（★）**：原「星级」及试过的「阶」**均作废**，阶梯统一叫 **级**（**环级**）。
> **★本轮删除「超环 / 权能卡」**：权能线取消后，**环级最高档就是 9 神卡**，不再有超环这一档（§22 第 27 轮）。
> **★0 环「碎片卡」定案（方案 A）**：**它是"尺度最微的卡"**——**有真实效果**，只是**小到"一片碎片"**：一片苔、一粒沙、一滴水、一缕烟。**不是废卡、不是残页**（"只能分解成余响"的方案已排除，§21 #32）。**低环永远有效、永远能用**，只是痕迹容易被更大尺度盖过（§10.5 环级生克、§11.7）。
> **禁物档定名「禁物」**（曾叫 外物 / 界屑 / 封印物）：**不属于任何元素、任何组合的外来物**——**从界外漏进界里的碎片**。**件件带负面效果**，**启用即有代价**（扰动值↑、世界留痕，§10.4）。

**⑥ 禁物（第 11 级 · 无等级）★本轮定名**

| 项 | 内容 |
|---|---|
| **是什么** | **从界外漏进界里的碎片**——不属于任何元素、任何组合 |
| **怎么用** | **只能"启用"或"封存"**；**不能养成、不能变强** |
| **负面效果** | **每一件都有代价**：启用后在世界里留下**抹不掉的痕迹**（扰动值↑），并且往往**同时改坏某样东西** |
| **参照** | **SCP 的"项目"** ＋ **《诡秘之主》的封印物**——**越有用，越危险**（反向取舍，这是全作唯一的"负面后果"来源） |
| **等级** | **无等级**——禁物**不分档、不分强弱**，只按"**用不用**"取舍（在卡池矩阵中占**禁物档**格位，**不带元素标签**） |

**示例（不分档）**：常温水杯（永远装满水，但**水无处可排**）· 不落的叶（一株永不落叶，但**根周寸草不生**）· 逆流的沙漏（一片区域时间倒退，但**该区域留下永久斑点**）· 无雨的铁云（整界永不下雨，但**生物缓慢失水**）· 第二颗太阳（天空出现第二颗太阳，但**昼夜紊乱、扰动剧增**）。

## 3. 体验支柱

1. **它真的在活着**——有因果、会自己漂移的生态。
2. **外面发生什么，里面就发生什么**——现实的桥。
3. **万物可干涉**——十二类卡池，从地形到物理法则都能改。
4. **这次能怎么玩**——干涉世界攒下「余响」，开包换回"下一次的命题"：更多卡、更多主题、更多风格。
5. **我的界我做主**——9 步创建向导（含风格主题），法则参数随时可改。
6. **没有失败，也不会结束**——世界永续。
7. **打开就好看**——纸雕微缩的观感即产品。

## 5. 时间系统（★核心设计）

### 5.1 双模式对照

| 项 | **模式 A · 真实时间** | **模式 B · 虚拟时间** |
|---|---|---|
| 世界钟 | **= 系统时钟（1:1）**，锁死 | 自有比例：**默认 1 世界日 = 3 真实分钟**，可调 1–60 |
| 暂停 / 加速 | **全部禁用** | 暂停 · 1x · 4x · 20x · 比例滑块 |
| 昼夜 | 现在几点就是几点 | 一个世界日内走完一轮 |
| 季节 | 真实季节 | 世界钟推进（可快进看四季） |
| 天气 | **联网真实天气** | 虚拟天气（随机 + 可干涉） |
| 联网 | **必需** | 不需要 |
| 生态节奏 | 真实（极慢，适合挂着看） | 加速可见 |
| 时间类卡（§10 第 11 类） | **不可用** | 全部可用 |

### 5.2 昼夜的相位与形状分离

- **相位**：真实模式由系统时间给；虚拟模式由世界钟在一个世界日内走完。
- **形状**（昼长比例、太阳高度角峰值）：**两种模式都**由真实日期 + 纬度算出 → 冬天的白昼更短、太阳更低、更冷。

### 5.3 现实锚刷新

| 数据 | 刷新 |
|---|---|
| 日期 / 节气 | 跨真实日 |
| 天气（仅真实模式） | 每 30 真实分钟 |
| 纬度 / 城市 | 用户设置时 |

### 5.4 玩家时间控制

仅虚拟模式可用：暂停 · 1x · 4x · 20x；比例滑块 1–60 真实分钟 / 世界日。真实模式下这些控件**不出现**。

### 5.5 模式切换

双向可切；切换只改变时间推进规则，**不重置生态**，世界钟重新锚定（真实→系统时钟；虚拟→从当前时刻按比例推进）。联网状态随模式切换。

### 5.6 离线 = 暂停时间

- 退出即**冻结**：世界钟不推进、生态不演化、**不做补偿推演**。
- 再打开：生态从冻结处继续；**真实模式下环境立刻同步到当前现实**，并给一句提示（"你离开期间，外面从寒露走到了霜降"）。**只是文本，不推演生态。**

## 7. 世界规模、分块、生态域与多界

### 7.1 三档尺寸（已按"装得下内容"上调）

| 档 | 尺寸 | 面积 | 格 | 分块 | 隐喻 | 生态域 | 个体预算 |
|---|---|---|---|---|---|---|---|
| **小界** | 128 × 128 | 128 m 见方 | 16,384 | 4 × 4 | **一个地区** | 2–3 | 500–1200 |
| **中界** | 256 × 256 | 256 m 见方 | 65,536 | 8 × 8 | 一片区域 | 4–6 | ~3000 |
| **大界** | 512 × 512 | 512 m 见方 | 262,144 | 16 × 16 | **一个小世界** | 8+ 含气候带 | 8000+（统计式降载） |

- 分块尺寸 **64 × 64 格**；只加载视野内与邻近分块（§14.2）。
- 大界通过**气候带**（纬度式温差）+ 多生态域形成"小世界"感。

### 7.2 生态域

生态域 = 环境参数 + 物种集的组合：水塘 / 草原 / 林缘 / 岩坡 / 沼泽 / 沙地 / 雪原 / 河谷 / 洞穴 / 高原。
小界 2–3 个（已是"地区"感），中界 4–6，大界 8+ 并带气候带渐变。

### 7.3 多界并存

- 可创建 / 切换 / 复制 / 删除多个界；每界独立存档（存档槽 + 界 id）。
- **同一时刻只推演"激活界"**，其余界冻结（性能与电量前提）；切换即解冻。
- 界可导出 / 导入为本地文件（JSON + 分块数据）。

## 8. 视觉风格：五个可选主题（★核心差异化）

### 8.1 机制：风格是纯表现层，因此可随时切换

**架构前提**：`Sim`（世界模拟）**零渲染依赖** → 风格完全属于 `Render` 层。于是：

- 风格主题**可逐界独立**、**可随时切换**、**可存为预设**；
- **同一份存档能长出完全不同的长相**；
- **一套几何资产 → 多套皮**（差异只在材质、后期与几何处理策略上），不会产生多套建模工作量。

### 8.2 五个风格主题（用户可选）

| 主题 | 名 | 一句话 | 关键技术 | 成本 |
|---|---|---|---|---|
| **T1** | **纸雕微缩** Paper Diorama | 一盒手工纸雕景观：纸厚度、硬折角、锐利投影、层叠景深 | 双面挤出 + Cel LUT + Inverted Hull + 硬阴影 + 移轴 | 中 |
| **T2** | **剪纸立牌** Cutout Puppet | 像纸偶戏舞台：大量 2D 立牌插进 3D 景深，景片层层推远 | 立牌（双面面片）+ 层叠背景板 + 轻雾 | **低（产能最高）** |
| **T3** | **手绘纸墨** Ink & Paper | 墨线 + 平涂 + 纸颗粒，承接旧风格锚 C1 | Cel + 描边 + 纸张叠加 | 低 |
| **T4** | **木刻版画** Woodcut | 黑白高对比 + 排线阴影 + 双色套印 | 阈值化光照 + 程序化排线 + 限色 LUT | 低 |
| **T5** | **粘土定格** Claymation | 柔和光 + 指纹肌理 + 微抖动，像逐帧拍的粘土动画 | 程序化凹凸噪声 + 12–15fps 步进 + 微位移抖动 | 中 |

每个主题由六组参数定义：**着色模型 / 描边方式 / 调色板 / 光照与阴影 / 后期（景深·暗角·颗粒·抖动）/ 几何处理（是否用立牌、是否减面）**。
参数落在 `shared/schema/style.schema.json`，实例放 `studio/presets/`，资产放 `game/Content/Styles/<主题>/`（见 `STRUCTURE.md` §2 / §8）。

**排期**：M0 做 **T1**（默认）并打通"换皮"机制；M1 补 **T2**（成本最低、产能最高）；M2 补 **T3–T5**。主题是**参数集**不是独立资产线，因此加主题的成本可控。

### 8.3 T1（默认主题）渲染配方

| 项 | 做法 |
|---|---|
| 主体着色 | Cel Shading：**后处理材质 + LUT 色带**，3–4 段硬色阶，无平滑渐变 |
| 描边 | **Inverted Hull**（反法线外扩）为主；必要时补后处理边缘 |
| 纸厚度 | 网格做**双面挤出**，边缘可见纸厚度；背面比正面暗一档 |
| 纸材质 | **程序化纸纤维法线**（噪声生成，不用贴图）+ 轻微色斑与纸浆颗粒 |
| 阴影 | 定向光 + 阴影贴图，**阴影边缘锐利**（纸片投影感）；不用软阴影 |
| 层叠 | 地形由 **3–5 层纸板平台**叠成，层间有落差与投影 |
| 微缩感 | **移轴 / 浅景深** + 暗角 + 略高机位 → "看模型箱" |
| 风动 | 顶点动画让纸片轻微翘动（低频、小幅度） |
| 昼夜 | 光照颜色 + **整界纸色偏移**（不靠反射与金属） |

### 8.4 风格验收（每个主题各自定标）

每个主题上线前必须出**三张对照图**（正午 / 黄昏 / 雨）由用户裁决锁定；出图与风格锚对不上 = 退回。**风格不定标不进内容量产。**

## 9. 资产生产：2D 与 3D 的分工

**结论先说**：**世界几何是 3D，但大量内容其实是 2D 贴图**——2D 不只是卡面。

### 9.1 2D / 3D 分工表

| 内容 | 形态 | 产出方式 |
|---|---|---|
| 地形、水体、山体、纸板层 | **3D** | 程序化几何生成器（C++） |
| 动物、岩石、建筑、装饰的**主体** | **3D** | 程序化几何（低模块面） |
| **纸板立牌**（树丛、灌木、远景树、旗子、道具、小装饰） | **3D 面片 + 2D 贴图** | 几何由代码生成；**正面贴图来自 ComfyUI** |
| **卡面** | **2D 图** | ComfyUI 生图（3:4）；开包时以纸板卡实体呈现 |
| **UI**（面板、边框、图标、按钮、滑块） | **2D** | ComfyUI 生图 + 九宫格切图 |
| 地表材质、纸纹、水纹、苔藓、雪痕 | **2D 贴图** | ComfyUI + 程序化混合 |
| 粒子贴图（雨滴、雪花、落叶、光斑） | **2D 贴图** | ComfyUI |
| 天空 / 远景背景板 | **2D**（可选 3D） | ComfyUI 全景图 + 程序化色板 |
| 载入图、商店页素材、年表卡 | **2D** | ComfyUI |

→ **生图线重回主力**：纸板立牌的正面、卡面、UI、贴图、粒子——这些 2D 产出恰好是立体纸雕最需要的东西。**全 3D 并没有废掉 ComfyUI，反而给了它更明确的用武之地。**

### 9.2 三条生产线

| 线 | 内容 | 谁做 |
|---|---|---|
| ① **程序化几何** | 生成器产出低模块面：纸板层、岩石、植物、动物部件、云 | AI（C++） |
| ② **生图线** | 立牌贴图 / 卡面 / UI / 纸纹 / 粒子 / 背景板 | AI 调度，用户挑图 |
| ③ **可选 3D 生成** | 日后接入本地 3D 生成补多样性；**M0 不依赖** | 后续 |

### 9.3 动画（程序化，零人工资产）

- **铰链运动**：动物视为纸板关节件，正弦 / 缓动驱动部件旋转（走路、扇翅、低头）。
- **整体摆动**：低频噪声驱动的轻微摇摆（纸片感）。
- **形态变化**：缩放、倾斜、翻转 + 顶点位移（生长、枯萎、翻滚）。
- T2 剪纸主题下，立牌只需**朝向翻转 + 轻微摆动**。
- 结论：**不需要任何人工动画资产**，且"纸板玩具般的动作"正是风格的一部分。

### 9.4 资产规模预算

| 类别 | 数量（M0 → 最终） | 来源 |
|---|---|---|
| 地块纸板层 | 5 种高度模板 | 程序化 |
| 岩石 / 建筑 / 装饰 | 12 → 40 | 程序化 |
| 植物（3D 主体 + 立牌） | 6 → 30 | 程序化 + 生图 |
| 动物 | 5 → 30 物种（共用几套部件集） | 程序化 |
| **立牌贴图** | 20 → 120 | **生图线** |
| **卡面** | 36 → **≥231**（卡种数，每种可多张只出一张卡面） | **生图线** |
| **UI / 图标 / 边框** | 30 → 90 | **生图线** |
| 地表 / 纸纹 / 粒子贴图 | 20 → 60 套 | 生图线 + 程序化混合 |

> **风格包对美术量的影响**：卡面 / UI / 贴图是 2D 图，**每个风格主题都需要自己的一套**。上表数字是 **T1（默认）** 基准；风格包按主题分批产出（T2 在 M1、T3–T5 在 M2，§11.2），使"231 张卡 × N 主题"的成本**分批可控**而非一次爆炸。

## 10. 干涉体系：七元素 × 11 级 × 三种卡类（卡种 ≥ 231）

**三轴定位**：

| 轴 | 维度 | 回答 |
|---|---|---|
| **卡类** | 三种：物 / 术 / 律（§10.0） | 这张卡**是什么** |
| **类别** | 四组 · 十二类（§10.1） | 这张卡**改什么** |
| **卡型** | 十二种（§10.2） | 这张卡**怎么生效** |

外加三个**干涉机制**：三种用法（§10.3）、扰动值（§10.4）、相互作用（§10.5）。

**卡池 = 元素（7 种）× 级（11 级：0 – 9 + 禁物）× 卡类（3 种）：单元素卡种 ≥ 231**（§10.10）——**多元素卡种另计**（元素标签 1..N），**每种卡可有任意多张**；**没有权能线**。

### 10.0 三种卡类：物 / 术 / 律（★本轮新增，参考游戏王的三卡种）

**卡类 = 这张卡在世界里"是什么"**——它决定**卡面样式 / 牌背颜色 / 落地形态 / 能不能固化**，是玩家一眼分堆的第一层。

| 卡类 | 一句话 | 内容 | 落地后 | 固化（§10.3） | 例 |
|---|---|---|---|---|---|
| **物** Matter | **世界里的东西** | 生物 · 死物 · 各个事物 | 变成实体或活体，留在世界里 | **能** → 留下活物 / 地形 / 器物 / 碑 | 走兽、苔草、岩柱、湖泊、火山、**禁物** |
| **术** Rite | **主动施展的效果** | 魔法 · 幻想法术等 | 什么都不留下，只改**状态** | **不能** → 只留一块**印记** | 降雨、重力减半、永昼、岩浆注入 |
| **律** Law | **写下来的规则与仪式** | 仪式 · 规则等 | 把一条**条件或誓约**刻进世界 | **能** → 刻成永久规则 | 水位 > 40 自动结冰、献祭唤风暴、命名、立碑、编年 |

**与游戏王的对应**：**物 ≈ 怪兽卡 + 场地 / 装备卡** · **术 ≈ 魔法卡** · **律 ≈ 陷阱卡**。

**三类的本质区别**：

- **物**——世界里的**东西**：会自己活的（生物）与不会自己动的（死物 / 器物 / 地形）都归这里；**能固化，留下实体**。
- **术**——**你点它，它立刻生效**，世界不留实体（瞬时 / 持续 / 规则 / 合契 / 场域）。
- **律**——**你写条件，世界自己去执行**：一次写定，之后**常驻、自动、长久**（触发 / 仪轨 / 记录）。**这是本作最重要的机制"给世界定规则"的落点**（§10.2）。

**视觉与收藏**：三色牌背 + 卡库三分栏（§10.11）——**建议** 物=灰石 · 术=靛蓝 · 律=赭红（各风格主题另配一套色）。

**不是"类别的替代"**：同一条类别里三类都可能出现（「生命与生态」里既有"物"的走兽卡，也有"律"的保护规则卡），**卡类与类别正交**。

**不分强弱**（守 §11.7）：三类只是**玩法手感**的区分——造东西 / 点一下 / 定规矩。

**231 张的卡类配额（建议，M2 定稿时对齐）**：**物 ~106 · 术 ~87 · 律 ~38**（按 231 对齐）。

### 10.1 分类优化：四组十二类（★本轮改进重点）

原十二类的毛病是**层级不齐、边界重叠**——"天气"与"大气"各切一刀、"温度与能量"与"物理法则"各切一刀；"世界规则"是**元类别**却与具体类别并列。优化为**四组**：

| 组 | # | 类 | 一句话 | 边界 |
|---|---|---|---|---|
| **环境** | 1 | 地形与地貌 | 抬压、切裂、层叠 | 固体地表 |
| | 2 | 水体 | 水位、潮汐、河流、冰封 | 液态水 |
| | 3 | 大气与气候 | 温度基线、湿度、气压、大气成分 | **长期基线** |
| | 4 | 天气 | 雨雪雾暴、干旱热浪 | **短期事件** |
| | 5 | 天体与光照 | 太阳、月亮、星空、光柱 | 天外与光 |
| | 6 | 温度与能量 | 热源、岩浆、冰期、代谢 | 能量的收支 |
| **生命** | 7 | 生命与生态 | 投放、迁移、灭绝、复活 | 个体与种群 |
| | 8 | 演化与遗传 | 突变、特化、分化 | 跨代变化 |
| **法则** | 9 | 物理法则 | 重力、摩擦、生长率、时间泡 | 世界的常量 |
| | 10 | 世界规则 | 永夏、无重力、巨型化 | 世界的整体设定 |
| | 11 | 时间与因果 | 快进、回溯、局部时间 | 时间轴本身 |
| **记录** | 12 | 记录与叙事 | 命名、立碑、编年 | 世界的记忆 |

**三条边界规则**（防止再次重叠）：
- **基线 vs 事件**：3 定的是长期平均（气候），4 是当下正在发生的（天气）。
- **物质 vs 法则**：6 管能量的多少（热、光、代谢），9 管物理常量（重力、摩擦、生长率）。
- **干涉 vs 记忆**：1–11 改世界，12 只记录世界（不产生物理效果）。

### 10.2 十二种卡型（怎么生效）

| 卡类 | 卡型 | 生效方式 | 例 |
|---|---|---|---|
| **物** | **生物** | 活体：投放后自行觅食 / 繁殖 / 死亡 | 走兽、掠禽、溪鱼 |
| **物** | **材质** | 只改地表的材质，不改高度 | 把草地变成沙地 |
| **物** | **遗物** | 附着在某个实体上，跟随移动 | 给一棵树挂"不落叶" |
| **物** | **造物**（★本轮新增） | 直接在世界里**生成一个无生命实体**（不动、不附着） | 岩柱、器物、桥、碑 |
| **术** | **瞬时** | 立即结算、不留续 | 小雨、抬升、快进 |
| **术** | **持续** | 持续到释放或被改回 | 恒定湿度、永昼 |
| **术** | **规则** | 写进世界法则，永久 | 重力减半 |
| **术** | **合契** | 需要两种指定元素同时在场才能施放 | 火 × 木 才会成的野火 |
| **术** | **场域** | 立起一片区域环境 | 一片永雾区 |
| **律** | **触发** | **预设"当…时 → …"，世界自动执行**（★最重要） | 水位 > 40 时自动结冰 |
| **律** | **仪轨** | 需要代价或准备时间才能发动 | 献祭生物量唤来风暴 |
| **律** | **记录** | 写入年表 / 在世界上呈现文本 | 命名物种、立碑 |

> **触发卡是本作最重要的机制**：它把"玩家手动点一下"升级为"**玩家给世界定一条规则**"——世界从此自己执行。这是"我在养一个世界"的核心手感。

### 10.3 三种用法（一卡三用）

★ 参考 Glory to Rome / 火车岛 / Race for the Galaxy

| 用法 | 结果 | 什么时候用 |
|---|---|---|
| **施放** | 卡的效果作用于世界（地形隆起 / 降雨 / 投放物种） | 想改世界 |
| **分解** | 把卡拆解，换一笔**余响**（§11.1） | 缺资源、卡不对路 |
| **固化** | 把卡留在世界里成为**实体**：一座山、一株树、一只活物、一块碑 | 想留永久的东西 |

> 同一张「熔岩」卡：**施放** = 喷发一次；**分解** = 换余响；**固化** = 留下一座**永久火山**。

### 10.4 扰动值（世界的状态）

干涉会**累积扰动**（0–100）。扰动不是惩罚，是**世界的状态**：

| 区间 | 状态 | 世界表现 |
|---|---|---|
| 0–30 | **稳定** | 天气温和、地形稳、生态规律 |
| 30–60 | **波动** | 天气极端、地形震动、生物行为异常 |
| 60–100 | **剧烈** | 奇观频发：浮空岛、极光暴、物种爆发、地貌抖动 |

- **平息**：消耗余响降低扰动（世界回到稳定）。
- **放任**：不理会，让世界进入"剧烈"——**这是另一种玩法，不是失败**（守 §11.7）。
- 界面用**一条指示 + 世界画面上轻微的起伏**表达（§8.3）。

### 10.5 相互作用（三套生克：五行 · 光暗 · 环级）

每张卡带 **1..N 个原质标签**（§1.3、§10.6）。同一区域内，不同原质的卡按**生克**自行结算。生克有**三套**：

**① 五行生克**（金 / 木 / 水 / 火 / 土）

**相生（互相增强）**

| 生 | 结果 |
|---|---|
| 金 → 水 | 金属表面凝露，矿脉渗水 |
| 水 → 木 | 疯长：植被爆发 |
| 木 → 火 | 助燃：火势失控 |
| 火 → 土 | 焦土沃化：灰烬变肥 |
| 土 → 金 | 结矿：土中析出矿脉 |

**相克（互相压制）**

| 克 | 结果 |
|---|---|
| 金 → 木 | 伐：植被被剃光 |
| 木 → 土 | 固：根系锁住土石 |
| 土 → 水 | 掩：填湖、断流 |
| 水 → 火 | 灭：熄火生雾 |
| 火 → 金 | 熔：金属熔化 |

**② 光暗生克**（★本轮新增：**光 / 暗 与五行互相独立**，自成一对）

| 关系 | 结果 |
|---|---|
| **光 生 暗** | 有光才有影：光照到哪，影就长到哪（**昼 → 影**） |
| **暗 生 光** | 暗到极处见光：夜尽天明、暗中之烛（**夜 → 昼**） |
| **光 克 暗** | 照亮即驱散：阴影退散、躲藏者现形（**显形**） |
| **暗 克 光** | 吞没即遮断：光源被吸、能见度骤降（**隐蔽**） |

> **和五行互不作用**：光 / 暗 **不参与**五行生克表（既不生也不克五行，五行也不生克它们）；两者**只与彼此**生克。**光暗的平衡 = 昼夜节律**——这也是世界钟与物候的驱动之一（§5）。

**③ 环级生克**（★本轮新增：**高环克低环，低环生高环**）

| 关系 | 结果 |
|---|---|
| **高环 → 低环：克** | **尺度覆盖**：大尺度的改写会**盖过**同区域内小尺度的既有改动（9 环的改地形盖掉 0 环的一片苔） |
| **低环 → 高环：生** | **累积诱发**：许多小改动长期叠加，会**自己长成**一个大尺度的结果（连年小雨 → 气候变湿） |

> **注意分寸**：这条生克是**尺度覆盖**，**不是数值碾压**——**低环卡永远有效、永远能用**，只是它的痕迹会被更大的尺度盖住（守 §11.7"不分强弱"）。

- **三套生克可同时结算**：一张卡可以既有原质标签（吃五行生克）又被更大尺度覆盖（吃环级生克）。
- 反应**写进年表**（§15）。
- 反应是**涌现**的：玩家常会撞见"我没设计过的组合"（§11.5）。

### 10.6 卡的结构与时效

每张卡：**元素（七原质 1..N）× 级（0 – 9 / 禁物）× 卡类（物 / 术 / 律）**，外加**类别（十二类之一）× 卡型（12 种之一）**，另带：

- **卡类**（§10.0）：**物 / 术 / 律** 三者之一——决定卡面、牌背与**能否固化**。
- **元素标签**（§1.3）：**1..N 个**，取七原质（金 / 木 / 水 / 火 / 土 / 光 / 暗）。默认 1 个 = **单元素卡**；多个 = **多元素卡**，按 §10.5 同时参与结算（**光 / 暗 只与彼此生克，不与五行作用**）。**禁物不带元素标签**。
- **级（环级）**（§10.10）：**0 碎片卡 – 9 神卡**，之外是 **禁物档（无等级）**——决定**改动的尺度**，**不是强度**。
- **~~异质 / 异性标签~~**（§1.3④）：**已撤出核心**，作为**日后扩展**的预留位——本作卡片**不出现**这两个字段。
- **~~原性标签~~**（§1.3②）：**★本轮删除**——卡不再带原性标签，**效果只由"参数与模拟效果"决定**。因此也没有"单/多原性"与"四种组合"，**复合度只由元素标签数量表达**：**单元素卡**（多数）· **多元素卡**（最罕见）。**不分强弱，只分复合度**（守 §11.7）。
- **~~权能线~~**（§10.10）：**★本轮删除**——卡不再属于任何权能线，**卡池只按「元素 × 级 × 类」定位**（§22 第 27 轮）。
- **作用方向**：创造 / 消除 / 转换（同一元素可正可负）
- **作用域**：全局 / 区域 / 单体 / 笔刷（§10.8）
- **参数**、**模拟效果**、**可见反馈**（§10.7 卡表字段）

**时效**：瞬时卡即刻结束；持续卡到释放；规则卡永久（可改回）。可用余响**延长**持续类。

**现实加成**：真实节气与天气影响同类卡的表现——冬至冰类更强、下雨时水类更强（§6 现实耦合）。

### 10.7 卡表（细则见 CARDS.md）

> 每张卡 = **元素 × 级 × 卡类**（+ 类别 / 卡型，§10.6），任何时候都能 **施放 / 分解 / 固化**（§10.3）。
> **卡种由「元素 × 级 × 类」决定**（单元素 ≥ 231，多元素另计）。**十二类的功能位名单（每类 20 个，共 240 个候选名）与卡表细则，见卡片子系统的细化真源 [`docs/CARDS.md`](CARDS.md)**——两者同源，冲突以本文档为准。
>
> **十二类**（§10.1）：1 地形与地貌 · 2 水体 · 3 大气与气候 · 4 天气 · 5 天体与光照 · 6 温度与能量 · 7 物理法则 · 8 生命与生态 · 9 演化与遗传 · 10 世界规则 · 11 时间与因果 · 12 记录与叙事。
>
> 第 11、12 类的**时间倒带与因果重演**是"沙盒里最爽的那一下"：改错了可以退回去重看——这也是我们对同类作品最直接的差异化之一。第 12 类**记录卡**（记事 / 预言 / 口述）则让"世界记得你做过什么"，是"卡与世界的联系"的叙事侧（§11.5）。

### 10.8 作用域、持续性与"接管"

- **作用域**：全局（整界）/ 区域（笔刷或矩形）/ 单体（某个体 / 某格）/ 笔刷（连续涂抹）。
- **持续性**：由**卡型**决定（§10.2）——瞬时 = 立即结束；持续 = 到释放；规则 = 永久；触发 = 常驻待触发。
- **接管规则**：凡是覆盖现实输入的卡（日照 / 天气 / 温度 / 节气），UI 上标记"**已由你接管**"，可一键**释放回现实**。

### 10.9 六种卡包（Pack）—— "怎么获得"

| 包 | 内容 | 定位 | 获取 |
|---|---|---|---|
| **元素包（Element Pack）** | **一个元素**的整套卡（**11 级 × 3 类 = 33 个卡种**，含该元素格的禁物档）（§10.10） | **"这次主玩哪个元素"** | 余响（低 / 中） |
| **故事包（Story Pack）** | 以**一段世界故事**串联的卡：如「逆流的故事」= 水元素的若干卡 + 专属记录卡 + 专属卡背 | **叙事线索 + 收藏** | 余响 |
| **风格包（Style Pack）** | **纯表现层**：卡面美术 + UI 皮肤 + 立牌贴图 + 纸纹 + 粒子 | **"我的界长什么样"** | 余响 / 可选 DLC |
| **特殊包（Special Pack）** | **与真实时节绑定**：至日包（夏至 / 冬至）、节气包、雨月包 | **现实耦合的延伸**（§6） | 余响；到时节自动浮出 |
| **精灵包（Spirit Pack）** | **生灵卡**（物种）成包，一包 = 一个生态位的物种组 | **"往界里放什么活物"** | 余响 |
| **地脉包（Ley Pack）** | **触发卡**（§10.2）成包，一包 = 一套"世界自动规则" | **"给世界定什么规则"** | 余响 |

> **特殊包是"现实的桥"在卡包层的落地**：现实到了冬至，游戏里就浮出「至日包」——**你所在的地球季节直接决定你能开到什么**。这一条别人抄不走。

### 10.10 七元素 × 11 级 × 3 类（卡池的组织）

**卡种 = 元素 × 级 × 类；单元素卡的下限 = 7 × 11 × 3 = 231。**

| 维 | 取值 | 数量 |
|---|---|---|
| **元素**（元素标签） | 金 · 木 · 水 · 火 · 土 · 光 · 暗 | **7**（**可 1..N 个**，§10.6） |
| **级**（环级） | **0 – 9**（十档）+ **禁物**（第 11 档） | **11** |
| **类**（卡类） | 物 · 术 · 律 | **3** |

> **231 是「卡种」的下限，不是卡的总张数。** 三个词分清：
> - **卡种（kind）**——一种卡 = 一组固定的「元素标签 + 级 + 类 + 类别 + 卡型 + 效果」。**单元素卡种 ≥ 231**。
> - **多元素卡种**——**元素标签可取 1..N 个**（§10.6），**多元素卡是额外的卡种**，在 231 之上继续增加；**因此卡池种类"最少 231"**。
> - **每卡多张（copy）**——**同一种卡可以有任意多张实体**（带多张进卡组、反复施放、分解、固化）——**所以卡池实物张数 > 卡种数**。

**单元素卡种 231 的构成**：

| 段 | 算式 | 卡种数 |
|---|---|---|
| **常规卡**（0 – 9 十档） | 7 元素 × 10 档 × 3 类 | **210**（每个卡种都带元素标签） |
| **禁物**（第 11 档） | 7 × 1 档 × 3 类 | **21**（**不带元素标签**） |
| **单元素合计** | | **231（下限）** |
| **多元素卡种** | 元素组合 × 级 × 类 | **另计，往上加** |

> **★本轮删除「权能线 / 四权能」**：卡池只按「**元素 × 级 × 类**」组织，不再有"五行 × 四权能 = 20 条权能线"这一层，也**不再有超环权能卡**（§22 第 27 轮）。
> **矩阵只是坐标**：某个卡种落在「金 · 3 · 物」这样的格位上，**格位不等于属性**——禁物档的格位同样存在，但**禁物本身无元素**（见下）。

**级 = 尺度，不是强度**（**0 最低，9 最大**；不再逐环命名）：

| 级 | 名 | 单元素卡种数 | 说明 |
|---|---|---|---|
| **9** | **神卡** | 21 | 该元素（× 该卡类）的顶点 |
| **8 … 1** | **常规** | 每档 21，共 **168** | 数值越大，改动的世界越大 |
| **0** | **碎片卡**（最低） | 21 | **尺度最微的卡**：**有真实效果**，只是小到**"一片碎片"**（方案 A，§1.3⑤） |
| **禁物** | **禁物**（第 11 档 · 无等级） | 21 | **无环**：界外碎片，**件件带负面效果**（⑥） |

> **本轮定名（★）**：原「星级 / 阶」作废，阶梯统一叫 **级**（**环级**）。**九个尺度词（微 / 点 / 片 / …）已删**。原「特殊卡 / 无星卡 / 超环权能卡」**全部取消**，一律并入「元素 × 级 × 类」矩阵。

**禁物（21 种 · 无等级）**：**从界外漏进界里的碎片**——**不属于任何元素、不进任何生克**，也**不按尺度分级**（在矩阵中占**禁物档**的格位，但**卡本身不带元素标签**）。**机制独一无二**（如"重写整块地形""把界冻住""让时间反向"）**且都有代价**——**越有用，越危险**（§1.3⑥）。**禁物同样"一种多张"**：同一件禁物可以多张持有，但**同时只能启用一件**（§11.7）：

| 例 | 代价（每件都有） |
|---|---|
| 常温水杯：永远装满水 | **水无处可排** |
| 不落的叶：一株永不落叶 | **它的根周围寸草不生** |
| 逆流的沙漏：一片区域时间倒退 | **该区域留下永久斑点** |
| 无雨的铁云：整界永不下雨 | **生物缓慢失水** |
| 第二颗太阳：天空出现第二颗太阳 | **昼夜紊乱，扰动剧增** |

> **禁物只"启"不"养"**：不能变强、不能养成，只能**启用**（承担反噬）或**封存**。参照 **SCP 的项目**与**《诡秘之主》的封印物**——**全作唯一的"负面后果"来源**，与"永远不会输"构成张力（§11.7）。

### 10.11 各视图（用来筛选与推演）

| 视图 | 用途 |
|---|---|
| **卡类视图**（物 / 术 / 律） | 卡库三栏："我要东西 / 要一下效果 / 要定规矩"（§10.0） |
| **类别视图**（四组十二类） | 卡库检索："我要改水"（§10.1） |

## 11. 余响、卡包与施放

### 11.1 「余响」：干涉世界的回响（★新核心资源）

**定义**：你干涉世界 → 世界状态发生**可观测偏移** → 世界"回响"给你一份**余响**。它是全游戏**唯一的可积累物**，语义上是**世界的回声**，不是"钱"（命名见 §21）。

**产出（三源，只增不减）**：

| 源 | 触发 | 量级 |
|---|---|---|
| **事件回响（主）** | 干涉使世界**跨过阈值**并写入年表（§15）：重塑面积、水位升降、相变、种群剧变、灭绝、分化… | **按偏移幅度**给，越大越多 |
| **沉淀回响（次）** | 世界推进（真实或虚拟）时按**生态势能** = 生物量 × 多样性 × 稳定度 持续微量产出 | 小、持续 → 奖励"挂着的活世界" |
| **初见回响（一次性）** | **首次**出现某类现象：初雪 / 第一场雨 / 首次捕食 / 首次灭绝 / 首次分化… | 一次性，同时记入年表 |

> **防刷设计**：只有"让世界真的变了"才给事件回响——反复刷同一张小卡几乎不产出，与"看后果"的循环同向。

**消耗**：

| 用途 | 花费 | 性质 |
|---|---|---|
| 开一个**随机元素包**（3–5 张） | 低 | 有随机性与开包仪式 |
| **指定开**某个元素包 | 中 | 确定，规避随机 |
| 解锁**风格包**（T2–T5 皮肤 / 卡面 / UI / 贴图） | 高 | **纯美学**（§8.1） |
| 卡库直取**已解锁**的卡 | **免费** | 零门槛使用 |

### 11.2 六种卡包（★参考游戏王"套装"思路）

卡包分**六种**（完整定义见 §10.9），按"回答什么问题"归为三轨：

| 轨 | 包 | 回答 |
|---|---|---|
| **玩法轨** | **元素包 / 故事包 / 精灵包 / 地脉包** | "**主玩哪个元素 / 讲哪个故事 / 放什么活物 / 定什么规则**" |
| **审美轨** | **风格包** | "**我的界长什么样**"（纯表现层） |
| **现实轨** | **特殊包（至日 / 节气）** | "**外面是什么季节**"（现实耦合） |

- **卡分两级**：**基础卡** = **0 环碎片卡**（7 元素 × 3 类 = **21 个卡种**）**永久免费直取**；**扩展卡**（**级 1 – 9**）需**开包解锁**，解锁后免费直取。**禁物档**（21 种）**不随机出**，按"发现 / 事件"获得，且**同时只能启用一件**（⑥）。
- **无稀有度**：包内卡只按主题与协同分组，**不分强弱**（§11.7）。
- **包不排他**：同一张卡可同时属于"水元素包"与「逆流的故事」故事包——**包是视角，不是归属**。

### 11.3 开包、卡库与卡组

- **开包**：消耗余响 → **撕纸包动画**（纸雕风格：撕开封套、翻出纸卡）→ 得 3–5 张 + 1 张**签名卡**（该包的核心动作）。
- **卡库**：可**浏览 / 检索**全部**卡种**（单元素 ≥ 231，多元素另计；按**卡类 / 类别 / 卡型 / 元素 / 级 / 包**筛选）；每种显示**持有张数**（同种可多张）；已解锁的**直接可用**，未解锁的以**剪影**呈现（只提示"存在"，不显示效果）。
- **当前卡组**：从已解锁卡中选一套带入右侧栏，可反复使用（除"永久"类改写）。

### 11.4 施放与反馈

- 选中卡 → 世界内出现**作用域预览**（笔刷圈 / 区域框 / 单体高亮）→ 确认施放。
- 可选**仪式感**：在世界上手绘一个简单符（借鉴"神迹"的手势感），默认**关闭**，供玩家手动开启。
- 每次施放写入年表（§15）并给即时可见反馈（§10 卡表的"可见反馈"列）；**跨过阈值的施放额外产出余响**。

### 11.5 卡与世界的联系（★重中之重）

"卡"与"世界"不是两样东西——**卡是世界的一部分**。三个方向双向打通：

**① 卡 → 世界：施放即留痕**

| 环节 | 表现 |
|---|---|
| 预览 | 世界内浮现作用域（笔刷圈 / 区域框 / 单体高亮） |
| 落地 | **纸板卡从 UI 飞出、翻面、插进世界**（§11.6） |
| 生效 | 卡的"模拟效果"真的改写世界状态（§10 卡表字段） |
| 留痕 | 写入年表（§15）；地形卡留下**永久地貌**，生灵卡留下**活着的个体** |

**② 世界 → 卡：世界会"回话"**

| 机制 | 说明 |
|---|---|
| **共鸣高亮** | 当前世界状态下"特别有用"的卡自动发光 / 排前（冰期里「冰封」「雪被」发亮）——**不是解锁，是世界在提示你** |
| **情境表现** | 同类卡在不同条件下表现不同（"雪"卡在极地更持久）——体现"分何时有用，不分强弱" |
| **卡随世界生长** | 生灵卡投放后会**自行演化**（§13）：你抽到的"走兽"几代后可能变成新种——**卡本身在变** |
| **世界改写卡** | 触发卡（§10.2）生效后，卡从"待触发"变为"已生效"，卡面盖上**世界印记** |

**③ 卡 × 卡：相互作用**（§10.5）：不同原质的卡落在同一区域时，世界**自行结算反应**。玩家真正玩的不是"刷卡"，而是**看卡与世界、卡与卡反复对话**——这是本作区别于纯卡牌游戏的地方。

> **设计红线**：共鸣只改"**排序与视觉提示**"，**绝不改卡的强度数值**（守 §11.7）。

### 11.6 开包与世界的动画（★动力来源）

要有"打开它"的动力 → **每一次操作都要有仪式感**。全部程序化 + 2D 生图，零人工动画资产（§9.3）。

| 场合 | 动画 |
|---|---|
| **开包** | 纸包从侧边滑入 → **撕开封套**（纸裂声 + 纸屑）→ 卡成扇形飞出 → **逐张翻面**（背面是纸雕纹样）→ 签名卡最后亮起 |
| **施放** | 卡从手牌飞出 → 空中**翻面朝向世界** → 落入落点、**纸片震荡** → 效果展开（地形隆起 / 光柱升起 / 生物落地） |
| **世界反馈** | 硬阴影 + 移轴 + 纸片微动（§8.3）；大事件配一次**镜头轻推 + 纸屑** |
| **触发卡生效** | 世界某处**亮起一枚印记**，UI 里同步"盖章"——**提醒你：你定的规则生效了** |
| **扰动起伏** | 扰动升高时世界画面**轻微起伏**：边缘微卷、光线下沉（§10.4） |
| **相互作用** | 两条原质在同一区域相遇时，交界处**亮起光纹**，反应随之展开（§10.5） |
| **年表回放** | 倒带 / 因果重演时纸雕**逐帧倒退**（§10 第 11 类） |
| **卡组待机** | 手牌轻微呼吸 / 随风翘动，**让牌面看起来是"活纸"** |

> **可及性**：全部动画可在设置里降级 / 关闭（防晕动、省电）。

### 11.7 与「无失败、无强度成长」的关系（红线）

- **不设**：战斗、失败、等级 / 属性成长、稀有度、每日任务、签到、广告、成就弹窗。
- **余响买什么**：只买**选择**（更多卡）与**审美**（更多风格）——**全卡功能平权**，只分"何时有用"，不分"强弱"。
- **余响只增不减**（除消费），无失败扣除。
- 唯一的"收集"痕迹是世界史年表——它是记忆，不是奖励。

## 13. 世界模型

### 13.1 地块与地形

- 每格：`高度`（0–64，量化 0.25）、`地表类型`（草 / 土 / 石 / 沙 / 水 / 雪 / 冰）、`植被量`（0–1）、`湿度`（0–1）、`局部温度`。
- 全局 `水位`：`高度 < 水位` 的格自动为水（可结冰）。
- 渲染：分层纸板 mesh（3–5 层），由高度场程序化生成并**按分块脏标记重建**。

### 13.2 环境变量

太阳高度角 / 光照强度 / 色温、气温、降水（强度 + 形态）、风力风向、云量、大气含氧量、湿度。
来源：现实锚（或虚拟天气）+ 卡池覆盖 + 法则参数。

### 13.3 物种模板（JSON 契约草案，P1 定稿）

`id`、`角色`（生产者 / 消费者 / 分解者）、`体积`、`寿命`、`成熟期`、`繁殖能量阈值`、`繁殖环境条件`、`食性（目标 + 效率）`、`移动速度`、`栖息偏好`、`温度耐受`、`光照 / 水位需求`、`死亡掉落`、`感知范围`、`遗传字段（体型 / 色彩 / 特化）`、`视觉（几何生成器 id + 部件集 + 着色组）`。

### 13.4 M0 五个物种

| # | 角色 | 定位 | 关键机制 |
|---|---|---|---|
| 1 | 生产者 | **苔草**：基础植被 | 提高植被量；需光照与水；低温停长 |
| 2 | 生产者 | **灌木**：慢生、提供遮蔽 | 提升同格湿度、提供庇护 |
| 3 | 消费者 | **走兽**：食草 | 吃植被、饮水、夜休；繁殖需植被阈值 |
| 4 | 消费者 | **掠禽**：食肉 | 捕食走兽；雨雪天活动下降 |
| 5 | 消费者 | **溪鱼**：水生 | 仅水覆盖区；水温敏感；随水位迁移 |

### 13.5 交互与种群动力

固定 tick 顺序：**环境更新 → 生产者生长 → 消费者决策（有限状态机 + 局部感知）→ 进食 / 被捕食 → 繁殖 → 死亡 → 分解回地力**。

- 消费者**不做全局寻路**（性能与可复现）。
- 承载力由植被量决定；极端条件下转入休眠或留种。
- **无失败落到机制**：物种灭绝后仍可由"种子雨"（每 N 世界日小概率外来迁入）自然恢复；开启演化时还会分化出新形态。

### 13.6 因果可读性（硬要求）

1. 每次死亡带 `原因` 枚举（饿死 / 被捕食 / 冻死 / 淹死 / 老死）并短暂显示图标。
2. 种群崩溃必须给出**主导原因**并写入年表。
3. 验收：随机抽查 10 次死亡，玩家都能从画面读出死因。

## 14. 性能与优化（★一等公民）

### 14.1 目标预算（1080p / RTX 5060 级 8GB）

| 项 | 目标 |
|---|---|
| 帧率 | 观测态 30fps 上限；推演态 60fps |
| 逻辑 | 观测态 ≤ 2ms/帧；推演态 20x 倍率下 ≤ 8ms/帧 |
| GPU | 观测态占用 **< 5%**；推演态 < 60% |
| 内存 | 小界 < 1.5GB；中界 < 2.5GB；大界 < 4GB |
| 加载 | 小界首载 < 3 秒；切界 < 1 秒（惰性分块） |

### 14.2 空间侧

1. **分块（64×64）**：只加载视野内与邻接分块；远离则卸载（保留统计摘要）。
2. **地形网格脏标记重建**：只重建被改动分块，不每帧重建。
3. **LOD 三级**：近（细节纸板层）/ 中（合并面）/ 远（单色块 + 轮廓）。
4. **视锥 + 遮挡剔除**；大界启用距离剔除。

### 14.3 模拟侧

1. **模拟 LOD（SimLOD）**：
   - 近（相机附近）：逐个体状态机；
   - 中：分组聚合（群组按代表个体演化）；
   - 远 / 不可见：**统计式演化**（种群差分方程，不推个体）。
2. **只推演激活界**；非激活界零开销。
3. **预算分摊**：模拟按帧固定预算切片执行，不阻塞渲染。
4. `Sim` 零渲染依赖 → 可 headless 跑基准（§18 验收 2）。

### 14.4 渲染侧

1. **ISM / HISM 实例化**承载岩石、植被、装饰（单次绘制调用渲染数百实例）；用 **per-instance Custom Data** 做颜色 / 风动相位差异（实例共享材质实例）。
2. 动态个体用轻量代理（低面数 + 程序化动画），关键个体才用完整部件集。
3. **Niagara 粒子预算**：按档位缩放粒子数与生成率；雨雪用屏幕空间近似。
4. **纸雕风格本身即优化**：无 Lumen / Nanite / PBR；硬阴影；少量材质参数。
5. 材质参数集中管理，避免材质实例爆炸。

### 14.5 系统侧

对象池（个体、装饰、粒子、UI 元素）、避免每帧分配、分块序列化 + 惰性加载、异步加载与流式。
**度量手段**：headless 基准脚本 + `stat unit / stat gpu` + 自动化 profile 报告。

## 17. 技术架构与硬约束

### 17.1 模块划分（依赖方向 `Render → World → Sim`）

```text
game/Source/Solstice/
├─ Core/    启动、存档与多界管理、现实锚（系统时钟 + 纬度 + 联网天气）、事件总线、数据加载

├─ UI/      HUD（默认 C++ 构建控件树，UMG 可视化打磨）
└─ Render/  纸雕渲染管线：Cel LUT、Inverted Hull 描边、硬阴影、移轴景深、实例化
```

### 17.2 硬约束

1. **零渲染依赖**：`Sim` 不依赖 Tick / 渲染 / 输入，可 headless 驱动。
2. **只推演激活界**。
3. **可复现**：固定逻辑 tick（1 世界分钟）+ 随机数分流域（生态 / 天气 / 事件 / 演化）+ 遍历按显式 ID 升序 + 避免平台差异函数。目的：同种子同世界、headless 回归。
4. **内容数据驱动**：物种、卡池、法则、预设全 JSON，运行时读取；AI 生成 + 官方脚本灌入 DataTable/DataAsset。
5. **游戏逻辑不使用 Python**；资产批处理优先官方编辑器 Python（ScriptPlugin），必要时 C++ Commandlet。
6. **逻辑在 C++，表现层在蓝图**；`Sim` 不得依赖蓝图。
7. 存档版本化：`solstice.save.v<n>`，**每界一份**。
8. UI **中英双语**。
