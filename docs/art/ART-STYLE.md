# 美术风格规范（ART-STYLE）

## 0 本文件管什么 / 不管什么

- **管**：五个风格主题的**执行细则**（渲染配方参数、色板、素材规格、QC 清单）、可继承的旧风格锚参数、风格验收流程。
- **不管**：**风格的设计定位与主题清单**（真源是 [`../setting/STYLE.md`](../setting/STYLE.md)）；**资产怎么生产、存哪、怎么登记**（见 [`ASSETS.md`](ASSETS.md)）；引擎渲染管线代码（见 [`../tech/ARCHITECTURE.md`](../tech/ARCHITECTURE.md) §2）。
- **v2.0 重写说明**：本文件由旧稿 [`../archive/ART-STYLE-v1.md`](../archive/ART-STYLE-v1.md) 重写而成。**旧稿的卡面 / 卡牌版式规范全部作废**；**墨线 + 平涂 + 纸颗粒**的画面语言被继承下来，作为 **T3「手绘纸墨」**主题的基线（§3）。

## 2 T1「纸雕微缩」渲染配方（默认主题）

| 项 | 做法 |
|---|---|
| 主体着色 | Cel Shading：**后处理材质 + LUT 色带**，3–4 段硬色阶，无平滑渐变 |
| 描边 | **Inverted Hull**（反法线外扩）为主；必要时补后处理边缘 |
| 纸厚度 | 网格**双面挤出**，边缘可见纸厚度；背面比正面暗一档 |
| 纸材质 | **程序化纸纤维法线**（噪声生成，不用贴图）+ 轻微色斑与纸浆颗粒 |
| 阴影 | 定向光 + 阴影贴图，**阴影边缘锐利**（纸片投影感）；不用软阴影 |
| 层叠 | 地形由 **3–5 层纸板平台**叠成，层间有落差与投影 |
| 微缩感 | **移轴 / 浅景深** + 暗角 + 略高机位 → "看模型箱" |
| 风动 | 顶点动画让纸片轻微翘动（低频、小幅度） |
| 昼夜 | 光照颜色 + **整界纸色偏移**（不靠反射与金属） |

**M0 硬约束**：**无 Lumen / Nanite / PBR**；少量材质参数；材质实例集中管理（[`../tech/ARCHITECTURE.md`](../tech/ARCHITECTURE.md) §1.4）。

## 3 可继承的旧风格锚（C1「纸墨卡通」→ 作为 T3 基线）

> **状态**：以下参数来自已作废的旧稿 C1，**尚未随新形态定标**。它们现在是 **T3「手绘纸墨」的候选基线**，也可能被 T1 借用（例如纸颗粒叠加）。**定标前不作为硬约束**（[`../setting/STYLE.md`](../setting/STYLE.md) §3：风格不定标不进内容量产）。

### 3.1 色阶与描边

| 项 | 参数 |
|---|---|
| 色阶数 | **3 阶**（基色 / 一次影 / 二次影）+ **1 点高光** |
| 阶间过渡 | **硬过渡**，抗锯齿 ≤ 2px；禁软渐变、禁渐变贴图 |
| 每阶降幅 | 暗部：明度 **−18%~−22%**、饱和 **−8%~−12%**、色相向冷偏 **+5°** |
| 二次影占比 | ≤ 画面 **15%**（仅背光转折处） |
| 外描边粗细 | 主体高度的 **0.8%~1.2%** |
| 描边色 | 墨色 **`#1E1A24`**（深墨紫黑），随环境光偏色 ±10%，**绝不发光** |
| 内线 | 仅结构分割，粗细 = 外线 **40%~50%**，取环境暗部色 |
| 描边稳定性 | 拒绝屏幕空间抖动；远景可切**贴图描边**省性能 |

### 3.2 色块、剪影与颗粒

- 主体色块 **≤ 5 块**，配饰点缀 **≤ 2 块**；**剪影测试**（纯黑填充下须一眼辨识主体与朝向）不通过则重做轮廓。
- 纸张颗粒：屏幕层全屏叠加 **8%~15%**（1–2px）、单位自身贴图 **5%~10%**（1px 噪点）、轮廓毛边极轻。
- 受光：**硬边二分明**，阴影用**提升饱和度的冷色块**而非单纯压暗；**场景主光锁定左上 45°**。

### 3.3 四季地表色板（候选，迁移自旧稿 §2）

四套板共享 **墨线 `#1E1A24`** 与 **纸底 `#F5F0E6`**，保证同画面不打架。

| 季 | 主色 | 副色 | 点缀 | 阴影 | 环境光 | 强调 |
|---|---|---|---|---|---|---|
| 春 | `#A7C957` 嫩柳绿 | `#F2C9D6` 杏花白粉 | `#F0A6B8` 樱粉 | `#5B7B4B` 苔青 | `#F3EAD3` 暖雾米 | `#F2C14E` 春阳金 |
| 夏 | `#2E8B9E` 海青 | `#FF7A59` 珊瑚橙 | `#FFD166` 骄阳黄 | `#1B4A63` 深渊蓝 | `#DCEEF2` 潮雾青白 | `#3FA34D` 绿荫 |
| 秋 | `#C1440E` 枫赤 | `#E8A33D` 稻金 | `#F26B38` 柿橙 | `#5A3A2E` 褐墨 | `#C9BFC0` 雾灰紫 | `#7A8450` 苔绿残 |
| 冬 | `#6FA8DC` 冰蓝 | `#EAF2FB` 雪白 | `#7FE0D0` 极光青 | `#2A3D66` 夜蓝 | `#B9AFD6` 霜紫 | `#E8873A` 炉火暖橙（限室内/温泉） |

## 4 封面/卡面素材规格（现行，与 UMG 分工）

| 项 | 规格 |
|---|---|
| 卡面尺寸 | **1024 × 1365 px（3:4 竖版）** |
| 画芯 | **无文字、无边框、无徽记**——名称 / 徽记 / 数值由 **UMG 统一绘制** |
| 安全区 | 上 **96px**、左右各 **88px**、下 **176px** 内不得放关键主体 |
| 画芯有效区 | **848 × 1093 px** |
| 主体占幅 | 安全画幅的 **60%~75%**，居中偏上，底部留信息条空间 |
| 立牌贴图 | **1024 × 1024**，**纯色 chroma 底**（模型无 alpha 通道），生成后抠图 |

> **规则**：卡面**只出画芯**，版式与文字一律在引擎里画——这样加风格主题时只需重出画芯（[`ASSETS.md`](ASSETS.md) §2）。

### 4.1 卡面版式（UMG 层，★2026-10-15 第 39 轮细化到区域级）

```text
1024 × 1365 px（3:4 竖版）
┌─────────────────────────────────┐
│ ◉元素章      ▭卡名横额      ○级环 │ ← 顶区 0–110px（安全区内）
│ ┌─────────────────────────────┐ │
│ │                             │ │
│ │        画 芯（无字）          │ │ ← 110–1000px（848×890）
│ │                             │ │
│ └─────────────────────────────┘ │
│  描述条：效果一句话（双语，≤2 行）   │ ← 信息条 1000–1330px
│  类别图标 · 卡型符号      ✦ 回收价值│
│ ═════════ 卡类色带 ═════════════ │ ← 底缘 1330–1365px
└─────────────────────────────────┘
   边框内衬一圈花纹（按卡类，§4.3）；四角角花统一「界印」
```

| 区域 | 尺寸 / 位置 | 内容与规则 |
|---|---|---|
| **元素章**（左上） | Ø88px 蜡封圆章 | 元素徽记（§3.4 候选，定标裁决）；**多元素最多并列 3 枚**，超出缩为一枚复合章；**禁物无章**（换「裂章」黑印） |
| **卡名横额**（顶中） | 宽 ≤420px 纸带 | UMG 文字，中文 ≤8 字 / 英文 ≤20 字符（WORLD §7 尺寸规范） |
| **级环**（右上） | Ø88px 环形刻度 | 刻度 0–9；**超环 = 日轮全环 + 金框**；**禁物 = 黑框 + 无刻度** |
| **画芯** | 848 × 890px | 无字、无边框、无徽记（主体占 60–75%，居中偏上） |
| **描述条** | 信息条第 1 行 | **效果一句话**：中文 ≤40 字 / 英文 ≤90 字符，最多两行（WORLD §7）；由 UMG 绘制 |
| **身份行** | 信息条第 2 行 | 类别图标（十二类）· 卡型符号（12 种）左置；**回收价值**右置 |
| **卡类色带** | 底缘 12px 横贯 | 物 = 灰石 / 术 = 靛蓝 / 律 = 赭红（沿用已定三色） |
| **边框花纹** | 内衬一圈，宽 ~14px | **按卡类区分**（§4.3）；花纹不进画芯 |

### 4.3 花纹系统（★第 39 轮定案骨架）

**原则**：花纹只出现在**边框内衬与牌背**，绝不进画芯；线宽 = 描边的 40%（§3.1），随环境光偏色。

| 卡类 | 边框花纹 | 语言 |
|---|---|---|
| **物** | **回纹**（方折连续） | 大地、砌筑、器物 |
| **术** | **云水纹**（圆曲流动） | 无形、流动、一闪即逝 |
| **律** | **封印菱纹**（连续菱格 + 符点） | 契约、刻写、不可撤回 |
| **超环**（叠加） | 花纹升级为**缠枝纹** + 金线 | 越界档的华丽度（唯一允许的"稀有度可见化"） |
| **禁物** | **无花纹 + 撕裂边** | 不属于任何体系的花纹语言 |

**四角角花**：全部卡类统一为「**界印**」（穹顶 + 方盘的俯瞰微形，与牌背中央同源）。

### 4.4 牌背（★第 39 轮定案）

- **全卡类统一牌背**（正面色带已区分类别，背面不重复承担信息）：
- 构成：中央**界印**（穹顶罩 + 方盘的俯瞰图形，直径 ~30% 卡宽）+ 四角角花 + 纸雕纹底（程序化纸纤维，§2）+ 细双框；
- 开包翻面动画的"背面是纸雕纹样"（INTERVENTION §6）即此背；
- 牌背随风格主题参数集走（换主题 = 捯纹样与纸色，构图不变）。

### 4.5 字体（★2026-10-15 定案初值，全部可商用授权）

| 用途 | 字体 |
|---|---|
| 正文 / 数值 / UI / 描述条 | **思源黑体**（Noto Sans SC，同族西文数字） |
| 卡名 / 界名 / 年表 | **思源宋体**（Noto Serif SC，纸感衬线） |

> 零授权风险、风格中性耐看；日后换风格主题时字体随主题参数集走（`style.schema.json` 加字体槽）。

## 5 人物 / 生灵的"避免人脸特写"约束 ★

生成模型在**正面人脸特写**上不稳定（五官崩坏、瞳距漂移、跨张不一致）。硬规则：

| 约束 | 规则 | 替代方案 |
|---|---|---|
| 卡面主体 | 不得要求正面人脸特写；**面部占画幅 ≤ 1/5** | ① 3/4 侧脸 ② 背身 / 回首 ③ 面部被纹样 / 器物 / 雾遮挡 ④ 只给眼部剪影 |
| 立牌 / 立绘 | **禁止 > 1/3 画幅的正面大脸** | 半身 / 侧身 / 低头侧视；情绪靠身姿与器物 |
| Prompt | 负向串含 `front-facing portrait, extreme close-up face` | 生成后按 [`ASSETS.md`](ASSETS.md) §4 QC 清单筛 |

## 6 风格验收（每个主题各自定标）

**流程**：每个主题上线前必须出**三张对照图（正午 / 黄昏 / 雨）**，由**用户裁决锁定**；出图与风格锚对不上 = 退回重新生成。**风格不定标不进内容量产**（[`../setting/STYLE.md`](../setting/STYLE.md) §3）。

**M0 验收挂钩**：M0 验收标准第 9 条"正午 / 黄昏 / 雨三张截图与风格锚一致（用户裁决）"——见 [`../plan/ROADMAP.md`](../plan/ROADMAP.md) §2。
