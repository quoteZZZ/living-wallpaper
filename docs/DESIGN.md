## 1. 产品概述

### 1.1 一句话愿景

**壁纸里的世界和你窗外的世界同步活着**——共享你的时间、天气和季节，以真实景深回应你的鼠标；画面由可自由组合的元素卡片构成，还有一只活在场景里的精灵宠物。

### 1.2 核心决策记录（已定，不再摇摆）

| # | 决策点 | 结论 | 理由 |
|---|---|---|---|
| D1 | AI 角色 | 仅用于**开发管线**（离线生成素材），运行时零 AI 调用 | 免费分发/买断无法承担按次生成成本 |
| D2 | 素材模式 | **预生成素材库 + 用户设置挑选**，无服务端按需生成 | 零服务器、零审核、零延迟 |
| D3 | 画面构成 | **卡片化图层**：元素卡（树/山/云/日/月…）自由组合（§4.2） | 用户核心诉求 |
| D4 | 冲突仲裁 | 元素卡三态偏好（跟随真实/强制/关闭），**光照永远跟真实**（§4.2） | 解决"隐藏太阳但真实晴天"类冲突 |
| D5 | 架构 | 单 HTML 文件 + 原生 WebGL2，无引擎无构建 | 直接跑在 WE/Lively 的 CEF 里，链路最短 |
| D6 | 语言 | **TypeScript/JS 一门语言**（现阶段 JSDoc 零构建） | 最小技术栈；Go 已评估否决（§5.1） |
| D7 | 差异化 | **精灵宠物系统**：深度排序进场景、懂天气时辰 | 无竞品组合；留存与传播引擎 |
| D8 | 发布路径 | WE 创意工坊先行（免费 lite）→ 独立 Steam 应用（买断+DLC） | 寄生现成生态获客，变现后置 |
| D9 | 平台 | Windows 优先（工坊期仅 Windows） | iOS 不开放动态壁纸；Android 后置 |
| D10 | 开发环境 | 云开发友好：代码在 GitHub，素材生成走云端，本机只需浏览器 | 用户非主力机 |

### 1.3 三大价值支柱（对外只讲这三个）

1. **深度视差** —— 第一眼的 wow，录屏/动图传播的载体
2. **真实时辰光照** —— 按用户纬度计算日出日落，"它和我的生活同步"的证明
3. **天气同步 + 宠物** —— "外面下雨，壁纸里在下雨，宠物会去躲雨"

AI 自定义生成**不是**卖点（D2 已否决）；渲染层的"活感"才是壁垒。

## 3. 最终效果：用户的一天

- **清晨 6:30**：冷粉色薄雾，太阳按当地真实日出时刻升起（冬天下午 5 点天黑，壁纸也 5 点入夜）
- **上午**：光线通透，云缓慢漂移；闲置 4 秒场景自主缓漂"呼吸"
- **鼠标划过**：前后景按深度错位（2.5D 视差）
- **下午暴雨**：壁纸同步落雨、远景朦胧，太阳圆盘自动隐去；宠物打伞躲到树下
- **黄昏**：色温转橙紫，太阳沿真实方位沉落
- **夜晚 23:00**：零星窗户亮灯、月亮升起；整体压暗动画放缓（护眼）；检测全屏时宠物自动睡觉
- **数周尺度**：季节悄悄更替（树从绿到黄到积雪）
- **彩蛋**：随机流星、飞鸟、节日元素（圣诞灯串/中秋月）

### 4.2 卡片化图层系统与冲突仲裁（核心设计）

场景 = 有序图层列表，分两类：

**元素卡**（用户决定"有什么"）：太阳/月亮、云、星空、山峦、树、宠物、彩蛋——可开关、换变体、选锚点（如 tree: fore-left/center/right）。T1 起每张卡 = 带 alpha 的 4K PNG + 可选独立深度 + 变体列表，登记在 pack.json。

**系统层**（世界决定"什么样"）：真实时辰光照、天气粒子、季节演化、护眼压暗。产品灵魂"同步你的世界"所在，用户只控程度不控存在。

**三态偏好**：每张上下文相关卡 = `跟随真实(auto) / 强制(on,show) / 关闭(off,hide)`。

**核心原则：元素卡消失，世界照常运转**——光照是世界的属性，不是太阳圆盘的属性。

冲突矩阵（T0.1 已实现）：

| 用户设置 | 真实上下文 | 结果 |
|---|---|---|
| 太阳=隐藏 | 晴天正午 | 无太阳圆盘，天空仍按正午变亮 |
| 雨=跟随 | 下雨 | 雨粒子 + 云量增加 + 日月圆盘自动隐去（a×0.12） |
| 云=隐藏 | 下雨 | 装饰云消失，雨粒子照常（粒子属天气系统层） |
| 时间=锁定 21 点 | 真实白天 | 自由模式：夜景氛围，牺牲同步感换创作自由 |

### 4.3 时辰光照（T0 已实现）

不按小时插值，**按太阳高度角插值**——一次解决纬度、季节、日出日落时刻：

1. 赤纬 δ=23.44°·sin(2π(284+N)/365)；高度角 e=asin(sinφ·sinδ+cosφ·cosδ·cosH)
2. 调色板关键帧挂 e∈{-90,-12,0,8,25,60}°：天空顶/地平线、日月色、雾色、星光、夜晚系数、环境偏移
3. 月亮=反日点近似（e<0 升起），随夜深变亮

### 4.4 天气系统（T1）

- 数据：Open-Meteo 免费 API（无 key），城市级坐标（用户手选城市或 IP 粗定位），30 分钟缓存，失败静默沿用上次数据
- 天气→渲染映射：clear/cloudy/fog/rain/snow → 云量、粒子类型、调色偏移、日月可见度
- 天气同时驱动宠物行为（§4.5）
- T0 用手动"晴/雨"演示同一套管线

### 4.5 精灵宠物系统（T1 核心，最大差异点）

- **深度排序**：宠物位置深度 vs 场景深度图逐像素比较 → 宠物能走到树后、从山脊后探头——只有带深度图的壁纸做得到
- **上下文人格化**：雨天打伞躲树下、深夜趴睡、冬天围巾——时辰/天气/季节全部通过宠物表达
- **注意力分级**（红线）：桌面活跃 ↔ 全屏自动睡觉；夜间降低活动量
- v0 范围：1 只、状态机 5 态（idle/walk/curious/sleep/shelter）、点击抚摸+喂食、localStorage 存好感
- 动画方案：**部件化精灵 + 参数化形变**（借鉴 Live2D"参数→变形器→网格"），身体/头/眼/尾分层 PNG，2-3 关键帧插值出呼吸/眨眼——不做逐帧动画
- 成长/进化/多物种全部后置 T2

### 4.6 设置与个性化

- 面板结构：时间（跟随/锁定）→ 元素卡（三态）→ 天气源 → 视差/帧率/护眼
- **预设组合**（T1）：官方推荐的一键方案——"极简模式"（关装饰卡只留光照）、"完整模式"、"深夜模式"
- 数据模型见附录 A；两端驱动（网页面板 / WE properties）同一份 S

### 4.7 性能与功耗（壁纸品类生死线）

- 帧率上限 30fps（可调 15/30/60）、DPR≤1.5、`document.hidden` 跳帧、`powerPreference:'low-power'`
- 全屏暂停依赖 WE 效率模式（T1 实测）
- 目标：挂机 GPU<5%
- 体积红线：单 HTML >3000 行时引入 esbuild（产物仍单文件）

## 5. 技术方案

### 5.1 技术栈（锁定）

| 层 | 技术 | 状态 |
|---|---|---|
| 语言 | **TypeScript/JS 一门**（现=JSDoc 零构建） | ✅ 锁定 |
| 运行时 | 浏览器（WE/Lively 的 CEF、未来 WebView2） | ✅ |
| 渲染 | WebGL2 + GLSL（fragment shader 为主） | ✅ |
| 构建 | 无 → esbuild（>3000 行触发，产物仍单 HTML） | 触发前不装 Node |
| 资产生成 | 云端：LiblibAI/即梦（图）、HF Spaces（Depth-Anything 深度图） | 零本地 ML |
| 资产后处理 | shader 内归一化 / 必要时 Node+sharp | 尽量免安装 |
| 桌面壳（T2） | Neutralino（纯 JS）或 Tauri（AI 代写 Rust） | 届时定 |
| 托管/协作 | GitHub + Pages（已上线）+ 未来 Cloudflare Pages 国内镜像 | ✅ |
| 天气 | Open-Meteo（免费无 key） | T1 |

**Go 否决记录**：交付载体是浏览器，Go 进浏览器只有 WASM 一条路——GC 运行时体积大、syscall/js 桥笨重；Go 的优势场景（后端）本项目不存在。**一门语言（TS）+ 一个运行时（浏览器）+ 零本地依赖**即全部。

### 5.2 系统架构

```
┌───────────────────────────────────────────────────────┐
│ 渲染层（单文件 WebGL2，30fps 预算）                      │
│  图层注册表 LAYERS → uniform 标志 → fragment shader      │
│  · 深度视差（UV 位移 v1 → 多步采样 v2）                  │
│  · 时辰分级（高度角→调色板）/ 雨粒子 / 护眼              │
├───────────────────────────────────────────────────────┤
│ 上下文层（本地，无 AI）                                  │
│  · 时钟+纬度→太阳状态（纯数学）· Open-Meteo(30min 缓存)  │
│  · 配置 S：网页面板 ∥ WE properties（同一数据模型）       │
├───────────────────────────────────────────────────────┤
│ 宠物层（T1）：部件化精灵+参数形变+状态机+深度排序          │
├───────────────────────────────────────────────────────┤
│ 资产管线（离线，AI 生成+人工筛）                          │
│  pack = 4 季底图×1 + depth×1 + palette + 卡片变体登记    │
└───────────────────────────────────────────────────────┘
```

### 5.3 渲染层规格

- 两种模式：程序化占位（T0）/ 图片+深度图（自动探测 `assets/scene.png`+`depth.png`）
- 视差 v1：UV 位移（`uv' = uv - mouse·par·depth`，先微放大防露边）；v2：多步采样消遮挡拉伸（参考 POM）
- 图层标志以 uniform 传入（uHasStars/uHasMountains/uCloud/uRain/uLumA…），图层注册表 `LAYERS` 同时生成设置面板——卡片系统一份数据两处用
- 山峦分层视差：4 层远高近低 + 大气透视色，正式素材模式下由深度图取代

### 5.4 上下文层

- 太阳：§4.3 纯数学，无网络依赖
- 天气：Open-Meteo → `S.weather`（T0 手动演示值）；城市坐标手动选择（不做精确定位，隐私友好）
- 时钟：`?hour=` 调试覆盖 > 面板锁定 > 真实时间，三级优先

### 5.5 数据与持久化

- `localStorage["lw.cfg.v1"]`：配置 S（附录 A）
- T1 追加 `lw.pet.v1`：宠物好感/成长
- 不做账号云同步

### 5.6 资产管线

风格包结构：

```
assets/packs/<pack>/
  scene-spring.png … scene-winter.png   # 4K 底图（春为构图基准）
  depth.png                              # 四季共享
  pack.json                              # 调色微调/雾参数/云量/宠物出没区/卡片变体登记
```

- 构图规范：强前/中/远分层，前景有主体物，**避免人脸**（深度估计易崩）
- 季节一致性：春为基准 → img2img/ControlNet 锁构图换季
- 深度图：HF Spaces 在线跑 Depth-Anything V2（免安装），16bit 灰度→PNG（近白远黑），shader 内归一化
- 云端生图：LiblibAI/即梦，每包 4-6 张候选人工筛 1
- 元素卡（树/宠物等）：带 alpha PNG；宠物用部件化分层图

### 5.7 Wallpaper Engine 集成

- web 壁纸 = CEF 跑 HTML，单文件直接可用
- 设置走 `project.json` general.properties（slider/combo/bool），页面内 `wallpaperPropertyListener` 接收——已内置桥接，与网页面板驱动同一 S（附录 B 映射表）
- 计划暴露属性：`par/fps/luminary/clouds/rain/stars/mountains/weather/timemode/lockedhour/pack/pet/eyecare`
- 宠物数据 localStorage（CEF 持久）
- 上传**如实勾选 AI 内容披露**；工坊页文案主打三支柱 + 动图；描述页引导 T2 独立版

### 5.8 云开发工作流（非主力机）

- 代码：GitHub 仓库为唯一真源，任何机器 clone 接续；已开 Pages 在线预览（原型即链接）
- 生成：图/深度图全走云端服务
- 可选：GitHub Codespaces 免费档（120 core-h/月）当云端 VS Code；ZCode CLI 任意机器可用
- 注意：github.io 国内访问不稳 → T1 配 Cloudflare Pages 镜像
- 录屏宣传（OBS）需真桌面——用户已暂缓，恢复时回主力机做

## 附录 A：配置数据模型 `S`

```js
S = {
  // 时间
  timeMode:   'real' | 'locked',   // 跟随真实 | 锁定时段（自由模式）
  lockedHour: 0-24,
  // 元素卡（三态：auto=跟随真实 / show,on=强制 / hide,off=关闭）
  luminary:   'auto' | 'show' | 'hide',  // 太阳/月亮圆盘；隐藏不影响光照
  clouds:     'auto' | 'off',
  rain:       'auto' | 'on'  | 'off',
  stars:      true | false,
  mountains:  true | false,
  // 天气（T0 手动；T1 由 Open-Meteo 驱动）
  weather:    'clear' | 'rain',
  // 渲染
  par:        0-2,                  // 视差强度系数
  // T1 追加：pack, pet, eyecare, city …
}
```

派生规则（每帧）：`raining = (rain==='auto'&&weather==='rain')||rain==='on'`；雨天→调色板灰化+云量 0.95+auto 模式日月 a×0.12；`uCloud = clouds==='off'?0:(raining?0.95:0.4)`。
