## 1. 产品概述

### 1.1 一句话愿景

**一个微内核壁纸引擎 + 一个创意工坊生态**：底座只负责合成、上下文与插件管理；画面里的一切——太阳、云、山、树、雨雪、宠物、彩蛋、预设——都是可插拔的卡片插件，与你的真实时间、天气、季节同步活着。

### 1.2 核心决策记录

| # | 决策点 | 结论 | 理由 |
|---|---|---|---|
| D1 | AI 角色 | 仅用于开发管线（离线生成素材），运行时零 AI 调用 | 免运行时成本 |
| D2 | 素材模式 | 预生成素材库 + 用户挑选；无服务端按需生成 | 零服务器/审核/延迟 |
| D3 | **架构** | **微内核 + 全面插件化**（§3）：官方内容也用插件格式（自举） | 生态可扩展；工坊即插件 |
| D4 | 冲突仲裁 | 元素卡三态偏好；**光照永远跟真实**（§4.2） | "隐藏太阳但真实晴天"类冲突 |
| D5 | 渲染 | 单 WebView + 原生 WebGL2 + GLSL | CEF/WebView2 直接跑 |
| D6 | 语言 | TypeScript/JS 一门；现 JSDoc 零构建，esbuild 按需 | 最小技术栈；Go 已否决 |
| D7 | 差异化 | 精灵宠物 + 会同步真实世界的场景 | 无竞品组合 |
| D8 | **发布路径** | **直接独立 Steam 应用**（Tauri 壳自绘壁纸），**不走 WE/Lively 平台**（仅作开发测试工具）；应用集成**自家 Steam 创意工坊**供素材包替换/上传 | 掌控全链路与商业化 |
| D9 | 平台 | Windows 优先 | iOS 不开放；Android 后置 |
| D10 | 开发环境 | 云开发：GitHub 真源 + Pages 预览 + 云端生图/深度图 | 用户非主力机 |
| D11 | **国际化** | **首版中英双语**：UI 字符串表 + 插件 manifest 双语字段 + 商店页双语 | Steam 全球分发 |
| D12 | 插件安全 | 声明式优先；代码级插件延后且必须 Worker 沙箱（§3.5） | 工坊内容不可信，防过度工程 |
| D13 | **产品定位** | **桌面玩具游戏**（v4）：场景搭建 + 宠物伴侣，壁纸是呈现形态之一 | 游戏性（搭建/养成/成就）是核心价值 |
| D14 | **引擎** | **TS 全栈：Tauri 2 + Babylon.js**（v4.1 用户选定，语言路线=在学的 TS）；双画布架构（程序化背景 + 透明 3D 层）；Godot 4 (GDScript/C#) 降为备选 | 现有原型全复用；AI 辅助开发效率最高；学习即开发 |
| D15 | **素材形态** | **无图路线**：程序化 + 低模 3D（CC0 起步）；AI 图片仅作可选远景整层（v4） | 风格一致性由渲染器保证；用户自由组合不分裂 |

### 1.3 三大价值支柱（对外话术）

1. **深度视差** —— 第一眼的 wow，传播载体
2. **真实时辰光照** —— 按纬度算日出日落，"它和我的生活同步"
3. **天气同步 + 宠物 + 插件生态** —— "外面下雨壁纸在下雨、宠物去躲雨，而这一切都可以被工坊素材替换"

## 3. 架构总纲：微内核 + 全面插件化 ★

### 3.0 设计思想

产品本质是**平台**：底座小而稳，内容无限可换。两条自举原则：

1. **官方内容 = 插件**：太阳、山峦、雨雪、宠物全部打包成与创意工坊完全相同的插件格式——狗粮自吃，生态管线从第一天就是唯一管线
2. **声明式优先**：90% 的插件（素材卡）只需 PNG + manifest.json，零代码；代码级插件是例外且必须沙箱

**务实红线（防过度工程，最重要的一节）**：
- 内核只暴露 **6 个服务**（§3.1），API 面积冻结，扩展只加不改
- T1 不开放任何第三方代码执行——工坊先只收声明式包
- manifest 带版本号（api:1），稳定前不承诺兼容

### 3.1 微内核职责（底座，仅此六项）

| 服务 | 职责 |
|---|---|
| ① 合成器 | 图层栈按类排序（附录 C）、渲染循环、深度视差、性能治理（fps 上限/hidden 跳帧/低功耗） |
| ② 上下文总线 | 时钟+太阳状态（纯数学）、天气数据（来自 provider 插件）、指针/前后台事件、季节/节日 |
| ③ 插件注册表 | 扫描目录/工坊订阅目录 → 读 manifest → 校验 → 启停/排序/卡槽仲裁（§3.4） |
| ④ 存储 | localStorage，按插件 id 命名空间隔离 |
| ⑤ 设置中心 | 读各插件 manifest 的 settings schema → 自动生成设置 UI（双语） |
| ⑥ i18n | 字符串表 + manifest 双语字段解析（§6） |

**内核不包含任何具体画面内容**——天空渐变是唯一例外（内置基础层，一切卡片的背景）。

### 3.2 插件分类学（五类）

| 类型 | 内容 | 是否含代码 | 示例 |
|---|---|---|---|
| `card` 素材卡 | 场景元素图（树/山/云/月亮/流星图） | ❌ 纯声明式 | 官方四季山峦包、工坊樱花树 |
| `effect` 效果层 | 粒子/滤镜（雨、雪、雾、光斑） | T1 内置渲染器+参数；T2 可代码 | 雨雪效果插件 |
| `behavior` 行为 | 有状态机的东西（宠物物种、飞鸟、萤火虫） | ✅ 沙箱 JS（T2 开放） | 官方宠物、工坊新物种 |
| `provider` 数据源 | 天气源、节日日历 | ✅ 沙箱 JS（官方先行） | Open-Meteo（默认内置） |
| `preset` 预设 | 卡片组合方案（极简/完整/深夜模式） | ❌ 纯声明式 | 官方三预设、玩家分享配置 |

### 3.3 插件包格式

```
pack.sakura/
  manifest.json      # 附录 B：id/type/api版本/双语名/卡片/设置schema
  assets/*.png       # 带 alpha 素材（4K 长边）
  main.js            # 仅 behavior/provider，T2 前官方专属
```

要点：**素材卡零代码**；卡片声明 = 图层类 + 锚点区 + 变体列表 + （可选）独立深度图。

### 3.4 生命周期与卡槽仲裁

`发现 → 校验（schema+尺寸上限）→ 注册 → 启用/禁用 → 排序`

- **卡槽**（附录 C）：背景槽（内置天空，单实例）／场景槽（山、树…每槽一实例，同槽多包时用户择一）／覆盖层（粒子、彩蛋、宠物，可叠加）
- 三态偏好（auto/show/hide）作用于每个卡实例；冲突矩阵见 §4.2
- 用户可调同类内排序；跨类顺序由内核锁定（保证深度语义）

### 3.5 安全与沙箱（分阶段）

- **T1**：工坊只收声明式包（card/preset）——无代码即无攻击面
- **T2**：开放 behavior/provider 代码：Web Worker + postMessage 结构化绘制指令（不碰 DOM）；无默认网络权限；包体积上限；崩溃隔离（worker 死 = 插件禁用，内核无恙）
- 商店页与工坊页明示内容性质；AI 素材如实披露

### 3.6 自举：官方内容 = 第一批插件

`official-base`（天空+时辰光照调色）、`official-mountains`（T0 程序化山峦迁为声明式数据）、`official-weather`（雨雪粒子+Open-Meteo provider）、`official-pet`（宠物）、`official-presets`（三预设）。**T0 原型的 uniform 开关方案在 T1.1 重构为插件数据驱动**——概念已验证，重构是机械工作。

**T0.2 已落地原型版**（`src/wallpaper/js/`）：`kernel.js`（i18n/存储/上下文总线/注册表+卡槽仲裁四服务，合成器与设置中心独立成文件）+ `plugins/base|mountains|weather|info.js`。插件以经典 `<script>` 顺序加载（零构建、双击可用），manifest 以 JS 对象内联声明；T1.1（Tauri/http 环境）迁为 `manifest.json` + fetch 加载，服务 API 不变。冲突仲裁集中在 `registry.resolveFrame()`，即 §4.2 矩阵的唯一实现。

### 4.2 卡片系统与冲突仲裁

三态偏好：`跟随真实(auto) / 强制(on,show) / 关闭(off,hide)`，作用于每个卡实例。**核心原则：元素卡消失，世界照常运转**——光照是世界的属性，不是太阳圆盘的属性。

| 用户设置 | 真实上下文 | 结果 |
|---|---|---|
| 太阳卡=隐藏 | 晴天正午 | 无圆盘，天空仍按正午变亮 |
| 雨=跟随 | 下雨 | 雨粒子 + 云量增加 + 日月自动隐去 |
| 云卡=隐藏 | 下雨 | 装饰云消失，雨照下（粒子属天气系统层） |
| 时间=锁定 21 点 | 真实白天 | 自由模式：夜景氛围 |

### 4.3 时辰光照（T0 已验证）

赤纬 δ=23.44°·sin(2π(284+N)/365)；高度角 e=asin(sinφ·sinδ+cosφ·cosδ·cosH)；调色板关键帧挂 e∈{-90,-12,0,8,25,60}°；月亮=反日点近似。时辰光照是**官方基础插件**（`official-base`）而非内核——内核只提供上下文总线。

### 4.4 天气系统（provider 插件）

- 默认 `provider.open-meteo`：免费无 key，城市手选（隐私友好），30 分钟缓存，失败静默沿用
- 天气 → 云量/粒子类型/调色偏移/日月可见度/宠物行为
- T0 手动"晴/雨"演示同管线；T2 可出第三方 provider（日历/节日/股行情？不在范围）

### 4.5 精灵宠物（官方 behavior 插件）

- 深度排序进场景（走树后/山脊后探头）——带深度图壁纸独有
- 上下文人格化：雨天打伞躲树下、深夜趴睡、冬季围巾
- 注意力红线：全屏自动睡、夜间低活动
- v0：1 只、5 态（idle/walk/curious/sleep/shelter）、抚摸+喂食、命名空间存储
- 动画：部件化精灵+参数形变（Live2D 思路），不做逐帧
- 养成/进化/多物种 → T2（工坊新物种=第三方 behavior，随沙箱开放）

### 4.6 设置中心与预设

- 双栏：左=插件列表（启停/排序/变体），右=选中插件的设置（manifest schema 自动生成）
- 官方预设插件：极简（只留光照）/ 完整 / 深夜护眼
- 配置 S 见附录 A；`lw.cfg.v1` + 各插件 `lw.p.<id>.v1`

### 4.7 性能与功耗

30fps 上限（15/30/60 可调）、DPR≤1.5、hidden 跳帧、low-power 上下文；全屏时暂停合成（壳层检测）；挂机 GPU<5%；单 JS 体积红线 >3000 行引 esbuild。
实现备注（T0.2）：fps 计数按"墙钟秒 × 实际渲染帧"统计（修复旧版丢帧高估一倍的 bug）；页面隐藏时 rAF 停摆，渲染循环降级 setTimeout 低频兜底（约 2.5fps，仅维持状态），`?nohid=1` 供自动化测试缩短间隔。

### 4.8 场景编辑器（直接操纵）★ T0.2 新增

来源：用户构想——"点击启用设置；选中右键可替换/修改/自定义添加素材；右键背景弹窗调整；选中太阳可拖拽调整位置和大小"。结合项目完善为以下方案：

**交互语言（T0.4 现状）**
| 操作 | 行为 |
|---|---|
| 悬停卡片 | 淡色虚线幽灵框 + 抓取光标 |
| 左键点击卡片 | 选中，显示 Gizmo（虚线包围框；圆盘卡为圆形） |
| 按住拖拽 | 移动卡片：太阳/树任意方向；云带、山峦垂直方向 |
| 右下角手柄拖拽 | 缩放：太阳圆盘半径 / 树 / 山峦起伏幅度 |
| 双击卡片 | 重置该卡变换 |
| 方向键 / Del | 微调选中卡（Shift×5）/ 隐藏 |
| 右键卡片 | 菜单：显示/隐藏 · **更换变体（圆盘）** · 重置位置 · 卡片设置… |
| 右键背景 | 菜单：场景设置… · 添加素材（圆盘） · 天气（圆盘） · 预设（圆盘） · 重置全部 |
| Esc / 点空白 | 取消选中、关闭菜单/圆盘 |

**规则**
- 变换持久化进 `S.cards[id].{dx,dy,scale}`，与三态偏好同层；「重置位置」恢复默认
- 命中区域是程序化卡的近似包围盒（圆盘/水平带，优先级 树>日月>云带>山峦>天空）；T1 图片卡将改用 manifest 锚点区（附录 B `anchors`）做精确命中
- 编辑模式可在中枢开关（`S.editor`），`?ui=0`（WE/Tauri 壁纸态）整体禁用编辑器与面板，只留画面
- 跨类顺序仍由内核锁定（附录 C），拖拽不改变图层深度语义

**圆盘选择器（T0.4，用户定名的交互样式）**
所有"选择类"操作（更换变体、天气、预设、添加素材）一律使用**圆盘放射菜单**——
中心为标题（点击关闭），选项以图标圆盘环绕展开，当前项高亮圈；不再使用长条列表。
选项随素材包注册自动扩充（如安装新树包后添加素材圆盘出现新卡）。

**T1/T2 演进（未实现，排期）**
- **替换素材**：圆盘直接列出该卡槽已订阅素材包的变体缩略图（声明式，零代码）
- **添加卡片**：圆盘列出可插入空卡槽的素材包卡（缩略图 + 名称）
- 多选 + 框选、对齐吸附、锚点九宫格定位；触屏长按 = 右键
- WE/Tauri 正式版保留编辑器作为"壁纸自定义模式"入口（差异化卖点：所见即所得调壁纸）

### 4.9 信息中枢（official.info 插件）★ T0.2 新增 / T0.4 升级为唯一 UI 组件

来源：用户构想——"信息组件合并为一个通用插件，默认展开天气时间等基本信息，可收缩，点击设置图标进一步自定义"；T0.4 进一步合并为**全屏唯一悬浮 UI 组件**。

- **唯一性（T0.4 红线）**：屏幕上只允许存在这一个悬浮玻璃卡——原右上齿轮、右下工具条、底部提示条全部删除，功能并入卡片右侧按钮列：`–` 收缩 / `✥` 编辑开关 / `↺` 重置全部 / `⚙` 设置中心；设置中心（panel）与右键/圆盘菜单都是它的弹层，不算独立悬浮件
- **默认展开**：大字时间（可选秒）+ 日期 + 天气行（☀/☁/🌧/❄/🌫/🌙 随天气与昼夜）；"详细信息"分区（太阳高度角/帧率/卡片状态）
- **可收缩**：`–` 收缩为迷你时间胶囊，`+` 展开
- **⚙ 自定义**：打开设置中心本插件分区——展开/秒/日期/天气行/详细信息/缩放，全部持久化 `S.info.*`
- **可拖拽**：编辑模式下拖动位置（`S.info.dx/dy`）；T1 支持四角吸附
- WE/Tauri 壁纸态（ui=0）下**信息仍然显示、编辑/设置按钮自动隐藏**（信息是壁纸内容，控制是窗口内容）

## 5. 技术方案

### 5.0 引擎与栈 v4.1（D14 定稿：TS 全栈 = Tauri 2 + Babylon.js）

**引擎对比结论**（对比表见 git 历史 v4.0）：自研 WebGL2 游戏能力不足；Godot 需换语言；Unity/UE 过重。**用户在学 TS → 选定 TS 全栈**，语言投入与产品开发合一。

**栈清单（v4.1 锁定）**：

| 层 | 技术 | 备注 |
|---|---|---|
| 语言 | **TypeScript** | 产品语言；构建 esbuild/Vite 按需 |
| 3D | **Babylon.js**（透明画布层） | GLTF/骨骼动画/粒子/GUI 内置；flat-shading + 调色板光照 |
| 背景 | 现有程序化渲染器（Canvas A） | 天空/山峦/雨雪保留，**不重写** |
| 壳 | **Tauri 2**（Rust 配置层） | WebView2 窗口 → WorkerW 嵌入（原型已验证路径） |
| Steam | steamworks-rs 插件；若工坊受阻 → Electron+greenworks 备选 | T1.3 验证 |
| 素材 | CC0 低模库（Quaternius/Kenney）→ AI 3D（Meshy/Tripo）→ Blender 程序化 | 见 §5.6 |
| 存档 | localStorage / Tauri fs | 沿用附录 A 的 S 模型 |

**双画布架构（D14 关键）**：Canvas A = 现有程序化场景（不重写）；Canvas B = 透明 Babylon 层，只渲染 3D 元素（树/石/宠物）；DOM 叠加合成，深度关系沿用地面锚点分层。现有成果零报废，Babylon 纯增量。

**素材三要素保证（风格化/高清/灵动）**：
- 风格化：渲染器强制——flat-shading + 统一调色板光照；第一版内容单一来源家族（全 Quaternius 或全 Kenney）
- 高清：3D 分辨率无关——顶点色无贴图永不吃糊；FXAA/MSAA + devicePixelRatio 渲染；远景画片层 ≥2048px
- 灵动：代码层给——风摆顶点着色器（风力参数化）、GLTF 骨骼宠物五态、粒子（萤火虫/飘叶）、时辰联动
- 许可证红线：CC0 免署名可商用；AI 3D 免费档多为 CC-BY（需署名），商用前确认或买断

**T1.0-B Spike（48-72h，Go/No-Go）**：
1. Tauri WebView2 → WorkerW 嵌入 + 多显示器
2. 挂机 30fps：GPU<5%、内存<300MB（双画布）
3. Babylon 载入 GLTF 低模树 + 时辰调色光照 + 风摆
4. steamworks 插件初始化
**No-Go**：嵌入失败或功耗超标 → 降级为纯程序化（无 3D）或评估 Electron。

### 5.3 渲染层

- 图片卡模式：`uv' = uv - mouse·par·depth`（v1 UV 位移；v2 多步采样消遮挡），先微放大防露边
- 天空=内核内置基础层；一切卡片按图层类合成（附录 C）
- 官方山峦：T0 程序化实现迁为"程序化渲染器+声明式参数"插件（保留零素材可用性）

### 5.4 上下文层

时钟/太阳纯数学无网络；三级时辰优先：URL 调试 > 面板锁定 > 真实；天气经 provider 插件进总线，消费方（渲染/宠物/预设）只订阅事件。

### 5.5 数据与存储

`lw.cfg.v1`（全局 S）+ `lw.p.<pluginId>.v1`（插件命名空间）；无账号云同步；工坊订阅清单可导出分享（=preset 包素材）。

### 5.6 资产管线（v4：无图路线，D15）

```
程序化（天空/山峦/天气 shader）—— 引擎内 C#，参数即变体
低模 3D 元素（树/石/草/宠物）—— CC0 库起步（Quaternius/Kenney）→ 工坊 UGC（GLTF）
                              季节=材质色切换；一致性由渲染器保证
AI 图片（可选）              —— 仅作"远景画片"整层，不拆零件
```

- **风格一致性由渲染器保证**（统一光照/调色/flat-shading），不依赖素材自觉——用户自由组合也不分裂
- 元素变体=参数（树种/叶色/体型），体积 KB 级，不占包体
- **手工制作或 AI 整图**路线保留为远景层选项，规范见 [docs/PACKS_GUIDE.md](PACKS_GUIDE.md)
- web 时代的批量脚本（tools/make_assets.py）退役，GLTF 优化用 Blender/gltf-transform

**历史方案存档**：v3 的"AI 整图→拆层→场景包"管线（对齐 WE 创作者工序）——若回退路线 B 或需要照片级远景时启用。
