# Living Wallpaper 设计文档

> 状态：**T0 开发中** · 更新：2026-10-12
> 项目代号 `living-wallpaper`（正式名候选见 §1.3）

## 1. 项目概述

### 1.1 一句话愿景

**壁纸里的世界和你窗外的世界同步活着**——共享你的时间、天气和季节，并以真实景深回应你的鼠标。附带一只活在场景里的精灵宠物。

### 1.2 核心决策记录（已定，不再摇摆）

| 决策点 | 结论 | 理由 |
|---|---|---|
| AI 角色 | 仅用于**开发管线**（离线生成素材），运行时零 AI 调用 | 买断/免费分发无法承担按次生成成本 |
| 素材模式 | **预生成素材库 + 用户设置挑选**，不做服务端按需生成 | 零服务器、零审核、零延迟；组合爆炸靠 shader 调色压缩 |
| 架构 | 单 HTML 文件 + 原生 WebGL2，无引擎无构建 | 直接跑在 Wallpaper Engine(Lively) 的 CEF 里，链路最短 |
| 差异化 | **精灵宠物系统**（深度排序进场景、懂天气时辰） | 无竞品组合；留存与传播引擎 |
| 发布路径 | **WE 创意工坊先行（免费 lite）→ 独立 Steam 应用（买断+DLC）** | 寄生现成生态获客，变现后置 |
| 目标平台 | Windows 优先（工坊阶段仅 Windows） | iOS 不开放动态壁纸；Android 后置 T2+ |

### 1.3 命名候选

- **同栖 SymBio** —— 宠物与人共栖一个桌面
- **栖境 Perch** —— 宠物的栖息之地即你的桌面
- **窗语** —— 壁纸是一扇和你的生活同步的窗

### 1.4 三大价值支柱（对外只讲这三个）

1. **深度视差** —— 第一眼的 wow，录屏传播的载体
2. **真实时辰光照** —— 按用户纬度计算日出日落，"它和我的生活同步"的证明
3. **天气同步 + 宠物** —— "外面下雨，壁纸里在下雨，宠物会去躲雨"

AI 自定义生成**不是**卖点（已改为预生成库）；渲染层的"活感"才是壁垒。

## 2. 最终效果：用户的一天

- **清晨 6:30**：冷粉色薄雾，太阳按当地真实日出时刻升起（冬天下午 5 点天黑，壁纸也 5 点入夜）
- **上午**：光线通透，云缓慢漂移；闲置 4 秒后场景自主缓漂"呼吸"
- **鼠标划过**：前后景按深度图错位（2.5D 视差）
- **下午暴雨**（城市级天气）：壁纸同步落雨粒子，远景朦胧，宠物打伞躲到树下
- **黄昏**：色温转橙紫，太阳沿真实方位沉落
- **夜晚 23:00**：零星窗户亮灯、月亮升起；整体压暗、动画放缓（护眼）；**检测到全屏应用时宠物自动睡觉**（壁纸的第一职责是不打扰）
- **数周尺度**：季节悄悄更替（树从绿到黄到积雪）——长期新鲜感的来源
- **彩蛋**：随机流星、节日元素（圣诞灯串 / 中秋月）

## 4. 系统架构

```
┌─────────────────────────────────────────────────────┐
│ 渲染层（本地，单文件 WebGL2，60fps→30fps 预算内）      │
│  · 深度视差：UV 位移（v1）→ 多步采样消遮挡（v2）        │
│  · 时辰分级：太阳高度角 → 调色板关键帧插值（shader）    │
│  · 天气粒子层 / 宠物精灵层（T1）                       │
├─────────────────────────────────────────────────────┤
│ 上下文层（本地读取，无 AI 调用）                       │
│  · 系统时钟 + 纬度 → 太阳赤纬/时角 → 高度角（纯数学）  │
│  · Open-Meteo 城市级天气，30min 缓存，失败静默降级     │
│  · WE properties / 设置面板 → 参数                    │
├─────────────────────────────────────────────────────┤
│ 宠物层（T1）：部件化精灵 + 参数化形变（Live2D 思路）    │
│  状态机行为表（Shimeji 思路）+ 深度排序 + 注意力分级    │
├─────────────────────────────────────────────────────┤
│ 资产管线（离线，AI 生成 + 人工筛）                     │
│  风格包 = 4 季底图 ×1 + 深度图 ×1 + palette.json      │
└─────────────────────────────────────────────────────┘
```

### 4.1 时辰光照实现（T0 已实现）

不按小时插值，**按太阳高度角插值**——一次解决纬度、季节、日出日落时刻的全部变化：

1. 太阳赤纬 δ = 23.44°·sin(2π(284+N)/365)（N 为年内天数）
2. 高度角 e = asin(sinφ·sinδ + cosφ·cosδ·cosH)，φ 纬度、H 时角
3. 调色板关键帧挂在 e ∈ {-90°, -12°, 0°, 8°, 25°, 60°}：天空顶/地平线色、日月色、雾色、星光系数、夜晚系数、环境色偏移
4. 月亮 = 反日点近似（e<0 时升起），随夜深变亮

### 4.2 功耗策略（壁纸品类的生死线）

- 帧率上限 30fps（`?fps=` / WE 属性可调），DPR ≤ 1.5
- `document.hidden` 时跳过渲染；全屏暂停交给 WE 效率模式（T1 实测）
- 渲染器声明 `powerPreference: 'low-power'`
- 目标：挂机 GPU 占用 < 5%

## 5. 资产管线（AI 作为开发工具）

### 5.1 风格包结构

```
assets/packs/<pack>/
  scene-spring.png   # 4K 底图（春季）
  scene-summer.png
  scene-autumn.png
  scene-winter.png
  depth.png          # 深度图（四季共享，构图一致）
  pack.json          # palette 微调、雾参数、云量、宠物出没区
```

关键：**每个风格包只出 4 季 4 张底图 + 1 张深度图**，四时段全部由 shader 分级——这是组合爆炸的解。

### 5.2 生成规范

- 构图：强前/中/远分层（前景主体物、中景山峦、远景天空雾），**避免人脸**（深度估计易崩）
- 季节一致性：春季为基准 → img2img/ControlNet 锁构图换季（同一棵树换叶色积雪）
- 深度图：本地跑 **Depth-Anything V2**，输出 16bit 灰度 → 归一化 PNG（近=白）
- 宠物精灵：**部件化**（身体/头/眼/尾分层 PNG）+ 参数化形变，不逐帧——借鉴 Live2D "参数→变形器→网格形变"体系，2-3 关键帧插值即可有呼吸/眨眼感；AI 出部件图后人工清理

## 6. 宠物系统设计（T1 核心特性）

### 6.1 差异化原理

- **深度排序**：宠物所在位置的深度值与场景深度图比较 → 宠物可以被树/山遮挡（"走到树后面"）——只有带深度图的壁纸架构能做到，是最"魔法"的瞬间
- **上下文人格化**：天气/时辰/季节系统全部通过宠物行为表达（躲雨、夜睡、围巾）
- **注意力分级**：桌面活跃 ↔ 全屏自动睡觉（合理化壁纸不打扰原则）

### 6.2 行为状态机（v0）

| 状态 | 触发 | 表现 |
|---|---|---|
| idle | 默认 | 站立呼吸、偶尔张望、眨眼 |
| walk | 随机计时 | 在宠物出没区（pack.json 定义）内短距移动 |
| curious | 鼠标靠近 | 转向光标、歪头 |
| sleep | 夜间模式 / 全屏检测 | 趴下、呼吸起伏放缓 |
| shelter | 下雨 | 移动到树下锚点，头上出现伞/叶 |

交互：点击=抚摸（爱心粒子）、长按拖喂食（好感度+，localStorage 持久化）。

### 6.3 实现要点

- 同一 WebGL pass 内精灵四边形 + 逐像素深度比较（shader `if(petDepth < sceneDepth) 遮挡`）
- 成长/进化/多物种 → 全部后置 T2，v0 一只就好

## 7. Wallpaper Engine 集成

- web 壁纸 = CEF 里跑 HTML：本仓库 `src/wallpaper/index.html` 直接可用
- 用户设置走 **project.json properties**（slider/combo/bool），页面内 `wallpaperPropertyListener.applyUserProperties` 接收（本文件已内置桥接）；参考官方文档：
  - project.json：`https://docs.wallpaperengine.io/en/web/publishing/projectjson.html`
  - propertyListener：`https://docs.wallpaperengine.io/en/web/events/propertylistener.html`
- T1 计划暴露的属性：`par`（视差强度）、`fps`（帧率上限）、`pack`（风格包 combo）、`pet`（宠物开关）、`eyecare`（夜间护眼 bool）
- 宠物成长数据 → localStorage（CEF 持久）；键名 `lw.save.v1`
- 上传工坊时**如实勾选 AI 生成内容披露**（社区敏感点，主动透明优于被举报）
- 工坊页文案：主打三大支柱 + 15 秒录屏；引导"完整版已上架 Steam"（T2 时）

## 8. 借鉴分析（多搜多抄的成果）

| 来源 | 借鉴 | 我们的差异 |
|---|---|---|
| Wallpaper Engine 生态 | web 壁纸机制、properties 设置、免费工坊获客 | 场景有"真实时辰/天气/深度"，内容懂你 |
| Live2D 类壁纸（Live2DViewerEX 等） | **部件化+参数化形变**的动画思路（不逐帧）；其可与 WE 共存证明桌宠+壁纸组合有真实需求 | 宠物深度排序进场景、被天气驱动 |
| VPet（Steam 桌宠，免费+插件生态） | 免费引流+mod 生态+成就式互动（拖动 1 万次等）验证付费意愿 | 宠物不是贴纸，是活在有深度的世界里 |
| Shimeji 行为目录 | 行为状态机的分类方式（走/爬/摔/繁殖→走/待机/睡/躲雨） | 行为绑定真实上下文 |
| 视差技术（Alan Zucconi 教程、LearnOpenGL、apoorvaj.io 四法对比） | v1 用 UV 位移；v2 升级多步采样（POM 思路）消遮挡拉伸 | 应用于壁纸场景 + 与时辰分级复合 |
