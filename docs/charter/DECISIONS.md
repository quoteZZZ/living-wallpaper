# 裁决沿革（DECISIONS）

## 0 本文件管什么 / 不管什么

- **管**：形态变迁史、**每轮裁决的结论摘要**、外部资料调研结论、参考稿清单。
- **不管**：任何现行规格——**现行规格见 [`GDD.md`](GDD.md) 与文档地图中的各域文档**；本文件只回答"这个结论是哪一轮定的、推翻了什么"。
- **写法约定**：摘要式日志——**不保留对话原文**；每条只写结论与存废（"存" = 仍是现行规则，"废" = 已被后续轮推翻，注明被哪轮推翻）。轮次编号**永久不复用**（其他文档会引用"第 N 轮"）。
