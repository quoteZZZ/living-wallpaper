## 1 定位与第一卖点

**一句话**：一盒**会自己活起来的纸雕微缩世界**——你可以让它与真实时间同频（天气、昼夜、季节皆真），也可以把时间握在手里；你攒下的「余响」开出的**元素包**决定这次能怎样改写它；而它永远不会输。

**第一卖点「现实的桥」**：现实的时间 / 天气 / 纬度不是"联动"，而是**你站在界外的岸上，看着同一片界外压着这座界**——你那下雨，界里也下雨；**某些存在只在真实的雨天 / 初雪 / 大雾里出现**。

> 完整机制见 [`../gameplay/TIME.md`](../gameplay/TIME.md) §1；世界观见 [`../setting/WORLD.md`](../setting/WORLD.md) §1。

## 2 非目标（明确不做）

- 多人 / 联机 / 排行榜 / 服务端、账号体系与云同步
- 移动端与主机、macOS / Linux
- 运行时 AI 调用或对话（AI 仅用于离线量产素材）
- **失败与数值成长**：无战斗、无玩家等级 / 无属性数值、无任务清单、无成就、无教程关卡；**唯一积累物是「余响」**（干涉世界产出 → 开包 → 解锁更多卡与风格）。**环级不是强度而是尺度**：环越高越罕见、影响越广；**高环对低环是"尺度覆盖"而非数值碾压**——低环卡永远有效、永远能用
- 内购、付费抽卡、订阅
- 工坊上传 / MOD 平台（界只在本地导入导出）
- PBR 写实路线、Lumen / Nanite 依赖

## 3 体验支柱（七条）

1. **它真的在活着**——有因果、会自己漂移的生态。
2. **外面发生什么，里面就发生什么**——现实的桥。
3. **万物可干涉**——卡池从地形到物理法则都能改。
4. **这次能怎么玩**——干涉世界攒下「余响」，开包换回"下一次的命题"：更多卡、更多主题、更多风格。
5. **我的界我做主**——9 步创建向导（含风格主题），法则参数随时可改。
6. **没有失败，也不会结束**——世界永续。
7. **打开就好看**——纸雕微缩的观感即产品。

> 支柱如何落到节奏上，见 [`../gameplay/LOOP.md`](../gameplay/LOOP.md)（**本节是支柱的唯一真源**，LOOP 只做"支柱 → 机制"的映射）。

## 5 文档体系规则

1. **一种事务一份文档**：规格 / 计划 / 环境 / 流程不得混写在同一份文件里。
2. **真源唯一**：全仓只允许一个 `truth: owner`（本文）；子系统真源与本文冲突时以本文为准。
3. **索引同次更新**：任何文档的新增 / 作废 / 迁移 / 版本或状态变化，必须在**同一次提交**内更新 [`../INDEX.md`](../INDEX.md)。
4. **结构描述带状态**：写目录树必须标 `现状` / `计划`，禁止把计划写成存在。
5. **术语按语境取词**：世界观用「原质」、卡上用「元素标签」（[`../setting/WORLD.md`](../setting/WORLD.md) §1.4）。
