# 开放问题（OPEN-QUESTIONS）

## 0 本文件管什么 / 不管什么

- **管**：**仍待裁决**的问题清单；已裁决项只留**一行索引**（§2），不保留裁决过程。
- **不管**：现行规格（真源见 [`GDD.md`](GDD.md) 与文档地图）。
- **约定**：编号**永久不复用**；新问题追加到 §1 表尾顺延编号；裁决后移入 §2 并写一行结果。
