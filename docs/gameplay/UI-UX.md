# 界面与交互（UI-UX）

## 0 本文件管什么 / 不管什么

- **管**：**界面区域划分**（每个区域放什么）、**键位草案**、**极简原则**，以及 UI 的实现分工。
- **不管**：卡库的检索维度定义（见 [`../setting/CARDS.md`](../setting/CARDS.md) §10）；开包与施放的**流程规则**（见 [`INTERVENTION.md`](INTERVENTION.md)）；面板里的参数项（见 [`CUSTOMIZE.md`](CUSTOMIZE.md) §3）；视觉风格（见 [`../setting/STYLE.md`](../setting/STYLE.md)）。
- **来源**：由 `charter/GDD.md` §16 拆出（内容未改）。

---

## 1 界面区域

| 区域 | 内容 |
|---|---|
| **顶栏** | 世界钟 · 模式标记（真实 / 虚拟）· 环境读数（节气 / 天气 / 温度 / 光照）· 种群计数 · 界切换 |
| **时间条** | **仅虚拟模式**：暂停 / 1x / 4x / 20x + 比例滑块（[`TIME.md`](TIME.md) §2.2） |
| **卡包区** | **余响余额** · "开一个元素包"（撕包动画）· 卡库入口（按**卡类 / 类别 / 卡型 / 元素 / 级**筛选）· 当前卡组 · 风格切换 |
| **底部工具盘** | 当前卡组按类分组；选中后世界内出现**作用域预览** |
| **创世面板** | 法则滑块、现实项接管开关、预设另存（[`CUSTOMIZE.md`](CUSTOMIZE.md) §3） |
| **选中个体** | 状态卡：物种、年龄、能量、状态、**死因**（[`../setting/SPECIES.md`](../setting/SPECIES.md) §4） |
| **年表抽屉** | 按世界年分组；可"**回到此刻**"（倒带） |

**首屏即世界**：以上界面**默认收起或淡出**，不遮挡世界。

---

## 2 键位草案

| 键 | 作用 |
|---|---|
| `空格` | 暂停（仅虚拟模式） |
| `1` / `2` / `3` | 倍率（1x / 4x / 20x） |
| `G` | 开包 |
| `Tab` | 切卡类（物 / 术 / 律） |
| `B` | 卡库 |
| `Esc` | 收起 |

---

## 3 极简原则与实现分工

- **原则**：无教程、无任务列表、无成就弹窗；**首屏即世界**；机制学习靠世界反馈而非弹窗（[`../charter/GDD.md`](../charter/GDD.md) §2）。
- **实现**：默认由 AI 用 **C++ 构建控件树**；后期审美打磨在编辑器里用 **UMG** 可视化调整。
- **卡面与 UI 素材**：由生图线产出（画芯无文字、无边框，界面上由 UMG 绘制名称 / 徽记 / 数值，见 [`../art/ART-STYLE.md`](../art/ART-STYLE.md) §4）。
- **中英双语**：所有用户可见字符串必须双语（[`../setting/WORLD.md`](../setting/WORLD.md) §7）。

## 4 待补
