# 界面与交互（UI-UX）

## 0 本文件管什么 / 不管什么

- **管**：**界面区域划分**（每个区域放什么）、**手牌区的交互**（拖拽 / 快捷键）、其他键位、**极简原则**、UI 的实现分工。
- **不管**：卡库的检索维度定义（见 [`../setting/CARDS.md`](../setting/CARDS.md) §7）；**手牌与回收的规则**（见 [`INTERVENTION.md`](INTERVENTION.md) §1）；面板里的参数项（见 [`CUSTOMIZE.md`](CUSTOMIZE.md) §3）；视觉风格（见 [`../setting/STYLE.md`](../setting/STYLE.md)）。

## 1 界面区域

| 区域 | 内容 |
|---|---|
| **顶栏** | 世界钟 · 模式标记（真实 / 虚拟）· 环境读数（节气 / 天气 / 温度 / 光照）· 种群计数 · 界切换 |
| **时间条** | **仅虚拟模式**：暂停 / 1x / 4x / 20x + 比例滑块（[`TIME.md`](TIME.md) §2.2） |
| **卡包区** | **余响余额** · "开一个元素包"（撕包动画）· **卡库入口**（只读图鉴，按卡类 / 类别 / 卡型 / 元素 / 级筛选）· **重抽按钮** · 风格切换 |
| **手牌区（底部）** | ★ **最多 10 格**：每格一张纸板卡；不足时显示**纸框空槽**；每张可**向上拖＝释放**、**向下拖＝回收**（[`INTERVENTION.md`](INTERVENTION.md) §1.3） |
| **创世面板** | 法则滑块、现实项接管开关、预设另存（[`CUSTOMIZE.md`](CUSTOMIZE.md) §3） |
| **选中个体** | 状态卡：物种、年龄、能量、状态、**死因**（[`../setting/SPECIES.md`](../setting/SPECIES.md) §4） |
| **年表抽屉** | 按世界年分组；可"**回到此刻**"（倒带） |

**首屏即世界**：以上界面**默认收起或淡出**，不遮挡世界；**手牌区常驻底部**（它是主操作面）。

### 1.1 手牌区的三条视觉规则

1. **容量可读**：10 格固定显示，**空槽用纸框表示**——"我的弹药不多了"必须一眼看出。
2. **共鸣高亮**：当前世界状态下特别有用的卡**发光 / 前移**（只改排序与视觉，**不改数值**，见 [`INTERVENTION.md`](INTERVENTION.md) §5.2）。
3. **实体张数**：卡角标出**该卡种的持有张数**（同种多张时，玩家要知道"还能放几次"）。

## 2 交互与键位

### 2.1 手牌的两个方向（★核心手势）

| 操作 | 手势 | 快捷键 |
|---|---|---|
| **释放** | 手牌**向上拖**（卡飞向世界；有可落地形态时再选"生效即散 / 落地成实体"） | 数字键选中 → `Enter` / 左键点世界 |
| **回收** | 手牌**向下拖**（卡落回纸包，化成一小叠余响） | 选中 → `Delete` / `Backspace` |
| **重抽** | 手牌区"重抽"按钮（整手 10 张全换） | `R` |

> **方向即语义**：**上＝用出去、下＝收回来**——与纸雕动画同向，不需要教程。

### 2.2 其他键位

| 键 | 作用 |
|---|---|
| `空格` | 暂停（仅虚拟模式） |
| `1` / `2` / `3` | 倍率（1x / 4x / 20x） |
| `G` | 开包 |
| `Tab` | 切卡类（物 / 术 / 律） |
| `B` | 卡库 |
| `Esc` | 收起面板 |

### 2.3 相机与视角（★2026-10-15 定案：固定俯视角）

| 项 | 规则 |
|---|---|
| **俯仰角** | **固定范围 45°–75°**，滚轮 / `Q`·`E` 微调；**不做 360° 自由旋转** |
| **缩放** | 滚轮连续缩放；最近 ≈ 每格占屏 1/8（能看清一片苔），最远 = 全界入画 |
| **平移** | **右键拖拽**为主，**屏幕边缘平移**与 `WASD` 为辅 |
| **为什么不自由旋转** | 纸雕的**层叠景深靠固定机位成立**；自由旋转会暴露纸片单面与层间空隙（第 34 轮裁决） |
| **与"岸"的关系** | 相机永不离开界（[`../setting/WORLD.md`](../setting/WORLD.md) §1.1）；"站在岸上看"由俯视机位 + 界外雾表达，无额外操作 |

## 3 极简原则与实现分工

- **原则**：无教程、无任务列表、无成就弹窗；**首屏即世界**；机制学习靠世界反馈而非弹窗。
- **实现**：默认由 AI 用 **C++ 构建控件树**；后期审美打磨在编辑器里用 **UMG** 可视化调整。
- **卡面与 UI 素材**：生图线产出（画芯无文字、无边框；名称 / 徽记 / 数值由 UMG 绘制，见 [`../art/ART-STYLE.md`](../art/ART-STYLE.md) §4）。
- **中英双语**：所有用户可见字符串必须双语（[`../setting/WORLD.md`](../setting/WORLD.md) §7）。
