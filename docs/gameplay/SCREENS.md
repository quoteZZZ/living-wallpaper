# 屏幕清单与线框原型（SCREENS）

## 0 本文件管什么 / 不管什么

- **管**：**屏幕清单、导航流、每屏线框**——开发与建模的界面蓝图；交互的三态过程（拖出 / 瞄准 / 未干期）。
- **不管**：交互**规则**（手势语义、键位、极简原则 → [`UI-UX.md`](UI-UX.md)）；手牌 / 回收 / 经济**机制**（→ [`INTERVENTION.md`](INTERVENTION.md)）；卡面美术规格（→ [`../art/ART-STYLE.md`](../art/ART-STYLE.md) §4）。
- **来源**：2026-10-15 第 39 轮——进入原型设计阶段，按现行设定绘制的界面蓝图。
- **实现分工**（[`UI-UX.md`](UI-UX.md) §3）：默认由 AI 用 **C++ 构建控件树**，后期在 UMG 里可视化打磨；概念参考图是**气质参考**，不是像素定稿。

## 1 设计原则（界面三原则）

1. **S1 是唯一的根屏**：其余全部是**浮层 / 抽屉 / 模态**，没有独立场景切换——"首屏即世界"（[`UI-UX.md`](UI-UX.md) §1）落到导航结构上；
2. **纸材语言**：所有面板 / 卡片 / 按钮都是**纸**（折角、撕裂边、蜡封印章）；浮层不是"玻璃板"而是"翻开的纸页"；
3. **默认收起**：顶栏与抽屉默认淡出，鼠标靠近 / 快捷键才浮现；手牌区常驻底部。

## 3 导航流

```text
首次启动：穹顶开场动画 → S0 问卷（≤5 问） → S1
之后启动：直接进 S1（上次的界）
S1 为根 ─┬─ 顶栏 ⚙ → S6 设置
         ├─ 顶栏 界名 → S7 主菜单覆盖层
         ├─ 卡包区 [卡库 B] → S3 ──（Esc/B 返回 S1）
         ├─ 卡包区 [开包 G] → S3b 开包模态 ──（完成回 S1）
         ├─ 左缘 → S4 年表抽屉（滑出）
         ├─ 右缘 / `C` → S2 创世面板（滑出）
         └─ 点选个体 → S5 状态卡（跟随浮层，再点空地关闭）
```

**S1 补注（★第 39 轮）**：

- **穹顶可见性**：俯瞰时画面**上缘隐约露出穹顶内壁的弧线**（分瓣纸壳 + 瓣缝微光，随 F3 低角机位愈发明显）——世界不是悬空的，它在罩子里；
- **混沌空态**（世界初始无生命）：种群计数显示 **"—"**、S5 状态卡不可用、年表只有"创世"一条——空态本身就是"这个世界还没活起来"的叙事，不弹提示；
- **余响计数**：蝴蝶形纸屑图标 + 数字（概念图已验证此气质）。

**S3b 分镜（五关键帧，全部程序化 + 2D 素材）**：

| 帧 | 画面 | 时长 |
|---|---|---|
| 1 | 纸包居中，蜡封「界印」朝上，微微呼吸浮动 | 0.5s |
| 2 | 撕开封套：纸裂声 + 纸屑四散，封口沿蜡封裂开 | 0.4s |
| 3 | 3–5 张卡**扇形飞出**悬停（背面 = §4.4 牌背；特殊包内超环 / 禁物卡即对应特殊牌背，翻面前已可见） | 0.5s |
| 4 | **逐张翻面**（间隔 0.15s），稀有度无区分、节奏一致 | 0.8s |
| 5 | 特殊包时签名卡**最后亮起**（金光一瞬）；全部实体飞入卡包区计数 | 0.6s |

> 可跳过：点击任意处快进；设置里可关（动画降级档，§6）。

## 5 释放交互的三态（核心交互过程线框）

```text
态1 拖出：手牌卡上拖 → 卡片放大跟手，世界出现十字光标
态2 瞄准：悬停世界 → 相机自动降到 ~45°（F2 位）+ 作用域预览
          （笔刷圈/区域框/单体高亮，按卡的作用域）
态3 确认：松手 → 卡飞向落点、翻面、纸片震荡 → 效果展开 + 年表一笔
          └ 落地成实体：3 秒"纸片未干"涟漪提示，可点收回
态0 取消：拖回手牌区 = 取消，不消耗
```

## 6 建模与实现注记

| 项 | 注记 |
|---|---|
| 控件树 | 每屏一个 `UUserWidget` 根；S1 常驻 + 浮层用 `ZOrder` 叠加，**不切关卡** |
| 九宫格 | 纸面板素材走九宫格拉伸（ASSETS §1 的 UI 产物） |
| 双语 | 所有文案走 `{"zh","en"}` 表（WORLD §7），版式预留英文 90 字符宽 |
| 空槽 | 纸框空槽是独立控件态（不是"不渲染"）——弹药可读性硬要求 |
| 收起 | 顶栏 / 抽屉的"默认淡出"用透明度 + 输入穿透，不做隐藏开关 |
| 概念图 | `tmp/ui-concepts/`（gitignore，过程参考，不定稿不入库） |
