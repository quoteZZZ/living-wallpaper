# 用户自定义 · 界创建向导与创世面板（CUSTOMIZE）

## 0 本文件管什么 / 不管什么

- **管**：**界创建向导（9 步）**、**出厂预设（8 个）**、运行中的**创世面板**、**存档分层与导入导出**。
- **不管**：世界设定的内容（见 [`../setting/WORLD.md`](../setting/WORLD.md)）；风格主题定义（见 [`../setting/STYLE.md`](../setting/STYLE.md)）；界面区域与键位（见 [`UI-UX.md`](UI-UX.md)）。
- **来源**：由 `charter/GDD.md` §12 拆出（内容未改）。

---

## 1 界创建向导（9 步）

| 步 | 内容 | 选项 |
|---|---|---|
| 1 | **尺寸与世界形态** | 小 128² / 中 256² / 大 512²；界名 |
| 2 | **风格主题** | T1 纸雕微缩 / T2 剪纸立牌 / T3 手绘纸墨 / T4 木刻版画 / T5 粘土定格（**运行中可换**） |
| 3 | **地形算法与种子** | 山脊 / 岛屿 / 峡谷 / 台地 / 盆地 / 群岛 / 手绘高度图；种子可输入或随机 |
| 4 | **生态域与气候带** | 生态域数量与类型；是否启用气候带（大界） |
| 5 | **水体** | 无 / 湖 / 河 / 海 / 湿地 / 群岛；水位初值；是否启用潮汐 |
| 6 | **大气与气候** | 温度基线、湿度、降雨量、大气含氧量、昼夜温差 |
| 7 | **物理法则** | 预设（标准 / 低重力 / 高重力 / 慢时光 / 快生长）或逐项自定义 |
| 8 | **生命种子** | 起始物种库（从已解锁物种中挑）、初始数量、演化压力、是否允许自发演化 |
| 9 | **时间与现实耦合** | 真实 / 虚拟模式；比例；是否联网；哪些现实项被接管 |

> **设计意图**：9 步覆盖"**大小 → 长相 → 地形 → 生态 → 水 → 气候 → 法则 → 生命 → 时间**"——从几何到法则再到现实耦合，**每一步都能改，且都可在运行中再改**（§3）。
>
> **向导参数的落地**：第 1 步（尺寸）对应物理尺度；第 3–5 步（地形 / 生态域 / 水体）由地块字段与阈值表承接；第 6–7 步（气候 / 法则）写进环境初值与法则集合。**逐项的数据语义见 [`../setting/WORLD.md`](../setting/WORLD.md) §2.1、§2.2、§3.1、§3.3**（生成流程 6 阶段）。
> **创建界不消耗余响**（自由创造是定位的一部分）；数量上限待性能实测（[`../setting/WORLD.md`](../setting/WORLD.md) §2.3）。

## 2 出厂预设（8 个）

四季常态 / 永夏雨林 / 永冬苔原 / 沙漠绿洲 / 群岛潮汐 / 浮空岛 / 倒置世界 / 无昼夜深渊

> 预设是**参数集**，与风格主题正交：同一个「永冬苔原」可以配 T1 也可以配 T4。

---

## 3 运行中的「创世面板」

- **风格主题随时换**（T1–T5 一键切换；纯表现层，**不重置世界**）。
- 所有法则参数**实时可改**：重力、时间比例、生长率、衰变率、繁殖率、熵、因果延迟…
- 所有现实输入**可接管 / 可释放**（[`TIME.md`](TIME.md) §4.2）。
- **"把当前界存为预设"** → 复用为下次创建的模板。
- **生效规则清单**（★待补）：玩家用「律」类卡写下的触发规则当前有哪些在跑、哪些被现实接管，应在此面板统一查看与停用。

---

## 4 存档分层与导入导出

```
一界 = 元数据(JSON) + 地形分块快照 + 生态快照 + 法则集合 + 卡池与历史 + 年表
```

支持：**复制界、导入 / 导出文件、模板保存**。**不做线上分享与工坊**（[`../charter/GDD.md`](../charter/GDD.md) §2）。

- 存档版本化键：`solstice.save.v<n>`，**每界一份**（[`../tech/STRUCTURE.md`](../tech/STRUCTURE.md) §6）。
- 导出位置：`%USERPROFILE%\Documents\Solstice\Exports\<realmId>.solstice`。
- **多界并存**与"只推演激活界"见 [`../setting/WORLD.md`](../setting/WORLD.md) §2.3。
- **待细化**：导出文件是否携带"世界故事"摘要（[`../setting/WORLD.md`](../setting/WORLD.md) §11 #1）。
