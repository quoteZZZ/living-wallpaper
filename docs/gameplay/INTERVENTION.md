# 干涉流程与余响经济（INTERVENTION）

## 0 本文件管什么 / 不管什么

- **管**：**玩家怎么用卡、怎么拿到卡、怎么被约束**——一卡三用与施放规则、余响经济、扰动值、卡包与获取、卡与世界的双向联系、接管与释放、动画仪式、红线。
- **不管**：卡本身的设计（三轴 / 矩阵 / 清单 / 生克 / 命名 → [`../setting/CARDS.md`](../setting/CARDS.md)）；时间与现实耦合（→ [`TIME.md`](TIME.md)）；界面布局与键位（→ [`UI-UX.md`](UI-UX.md)）；世界史结构（→ [`../setting/WORLD.md`](../setting/WORLD.md) §4）。
- **来源**：由 `charter/GDD.md` §10.3 / §10.4 / §10.8 / §10.9 + §11 拆出；**§1.3 与 §5.4 含 2026-10-14 的新裁决**。

## 1 一卡三用与施放规则

### 1.1 三种用法

| 用法 | 结果 | 什么时候用 |
|---|---|---|
| **施放** | 卡的效果作用于世界（地形隆起 / 降雨 / 投放物种） | 想改世界 |
| **分解** | 把卡拆解，换一笔**余响**（§2） | 缺资源、卡不对路 |
| **固化** | 把卡留在世界里成为**实体**：一座山、一株树、一只活物、一块碑 | 想留永久的东西 |

> 同一张「熔岩」卡：**施放** = 喷发一次；**分解** = 换余响；**固化** = 留下一座**永久火山**。
> **三者互斥**：一张卡只能选一种用法，用完这张卡就没了（§1.3）。

### 1.2 施放流程

1. 选中卡 → 世界内出现**作用域预览**（笔刷圈 / 区域框 / 单体高亮）；
2. 确认施放；
3. 效果展开 + 写入年表（§5.1）。

**可选仪式感**：在世界上手绘一个简单符（借鉴"神迹"的手势感），**默认关闭**，供玩家手动开启。

**作用域**（[`../setting/CARDS.md`](../setting/CARDS.md) §7）：全局（整界）/ 区域（笔刷或矩形）/ 单体（某个体 / 某格）/ 笔刷（连续涂抹）。

### 1.3 消耗与代价（★2026-10-14 裁决）

**结论：卡是实物，用了就少一张；但施放本身不收资源、不进冷却。**

| 层 | 规则 |
|---|---|
| **施放开销** | **不花余响、不进冷却**——保持"随手就能玩"的手感 |
| **消耗** | 施放 / 分解 / 固化 **都消耗这一张卡的实体**（用了就离手） |
| **低环** | **0 环基础卡永久免费直取**（21 个卡种）→ 等价于"**低环无限用**"，随便折腾 |
| **高环** | 1–9 级卡靠**开包获得实物张数** → 放一次少一张，**这是神卡的天然软限制**（不需要冷却 UI） |
| **禁物** | 一种可持多张，但**同时只能启用一件**；启用即有代价（[`../setting/WORLD.md`](../setting/WORLD.md) §1.8） |
| **补充约束** | **扰动值**（§3）与**级生克**（高环覆盖低环）——世界层面的软约束，不是惩罚 |

> **设计效果**：① "每种卡可持任意多张"这句设定**终于有了意义**——多张 = 能多次放；② **一卡三用从三个按钮变成真正的取舍**：这张卡我留着用、拆成余响，还是固化成山；③ 低环可乱玩、高环有意义。

### 1.4 反馈

每次施放**写入年表**并给即时可见反馈；**跨过阈值的施放额外产出余响**（§2.1）。

## 2 余响：干涉世界的回响（★唯一积累物）

### 2.1 定义与产出

**定义**：你干涉世界 → 世界状态发生**可观测偏移** → 世界"回响"给你一份**余响**。它是全游戏**唯一的可积累物**，语义上是**世界的回声**，不是"钱"。

**产出（三源，只增不减）**：

| 源 | 触发 | 量级 |
|---|---|---|
| **事件回响（主）** | 干涉使世界**跨过阈值**并写入年表：重塑面积、水位升降、相变、种群剧变、灭绝、分化… | **按偏移幅度**给，越大越多 |
| **沉淀回响（次）** | 世界推进（真实或虚拟）时按**生态势能** = 生物量 × 多样性 × 稳定度 持续微量产出 | 小、持续 → 奖励"挂着的活世界" |
| **初见回响（一次性）** | **首次**出现某类现象：初雪 / 第一场雨 / 首次捕食 / 首次灭绝 / 首次分化… | 一次性，同时记入年表 |

> **防刷设计**：只有"让世界真的变了"才给事件回响——**反复刷同一张小卡几乎不产出**，与"看后果"的循环同向。

### 2.2 消耗

| 用途 | 花费 | 性质 |
|---|---|---|
| 开一个**随机元素包**（3–5 张） | 低 | 有随机性与开包仪式 |
| **指定开**某个元素包 | 中 | 确定，规避随机 |
| 解锁**风格包**（T2–T5 皮肤 / 卡面 / UI / 贴图） | 高 | **纯美学** |
| 平息扰动（§3） | 待定 | 世界回到稳定 |
| 卡库直取**已解锁**的卡 | **免费** | 零门槛使用 |

### 2.3 红线：只买选择与审美

- **不设**：战斗、失败、等级 / 属性成长、稀有度、每日任务、签到、广告、成就弹窗。
- **余响买什么**：只买**选择**（更多卡）与**审美**（更多风格）——**全卡功能平权**，只分"何时有用"，不分"强弱"。
- **余响只增不减**（除消费），**无失败扣除**。
- 唯一的"收集"痕迹是**世界史年表**——它是记忆，不是奖励。

### 2.4 数值模型（待定）

产出速率、各类包的价格、平息扰动的花费、解锁曲线——**目前只有"低 / 中 / 高"的定性**，需要一张"**初值表 + 可调参数**"才能在 P4 实现。建议放本文件附表，随实测调整。

## 3 扰动值：世界的状态

干涉会**累积扰动**（0–100）。**扰动不是惩罚，是世界的状态**：

| 区间 | 状态 | 世界表现 |
|---|---|---|
| 0–30 | **稳定** | 天气温和、地形稳、生态规律 |
| 30–60 | **波动** | 天气极端、地形震动、生物行为异常 |
| 60–100 | **剧烈** | 奇观频发：浮空岛、极光暴、物种爆发、地貌抖动 |

- **平息**：消耗余响降低扰动（世界回到稳定）。
- **放任**：不理会，让世界进入"剧烈"——**这是另一种玩法，不是失败**。
- 界面用**一条指示 + 世界画面上轻微的起伏**表达（[`UI-UX.md`](UI-UX.md) §4）。

**待补的规则**（与 §1.3 的"无代价施放"配套必需）：

1. 扰动是**全局一个值**还是**分区累积**？
2. **自然消退速率**（世界日为单位）；
3. **平息的花费公式**（按当前值 / 按降低量）；
4. **"剧烈"除了视觉，是否有机制后果**（建议：只提高奇观与极端事件概率，**不产生失败或损失**）。

## 4 卡包与获取

### 4.1 六种卡包

卡包分**六种**，按"回答什么问题"归为三轨：

| 轨 | 包 | 内容 | 回答 |
|---|---|---|---|
| **玩法轨** | **元素包（Element Pack）** | **一个元素**的整套卡（**11 级 × 3 类 = 33 个卡种**，含该元素格的禁物档） | "这次主玩哪个元素" |
| | **故事包（Story Pack）** | 一段世界故事串联的卡 + 专属记录卡 + 专属卡背 | "讲哪个故事" |
| | **精灵包（Spirit Pack）** | **生灵卡**（物种）成包，一包 = 一个生态位的物种组 | "放什么活物" |
| | **地脉包（Ley Pack）** | **触发卡**成包，一包 = 一套"世界自动规则" | "定什么规则" |
| **审美轨** | **风格包（Style Pack）** | **纯表现层**：卡面美术 + UI 皮肤 + 立牌贴图 + 纸纹 + 粒子 | "我的界长什么样" |
| **现实轨** | **特殊包（Special Pack）** | **与真实时节绑定**：至日包、节气包、雨月包 | "外面是什么季节" |

> **特殊包是"现实的桥"在卡包层的落地**：现实到了冬至，游戏里就浮出「至日包」——**你所在的地球季节直接决定你能开到什么**。
> **包不排他**：同一张卡可同时属于"水元素包"与「逆流的故事」故事包——**包是视角，不是归属**。

### 4.2 获取规则

- **基础卡** = **0 环碎片卡**（7 元素 × 3 类 = **21 个卡种**）——**永久免费直取**。
- **扩展卡**（**级 1 – 9**）——**开包解锁**，解锁后免费直取。
- **禁物档**——**不随机出**，按"发现 / 事件"获得；**同时只能启用一件**。
- **无稀有度**：包内只按主题与协同分组，**不分强弱**。
- 卡种与阶段的关系见 [`../setting/CARDS.md`](../setting/CARDS.md) §1.5 / §1.6。

### 4.3 开包、卡库与卡组

- **开包**：消耗余响 → **撕纸包动画** → 得 3–5 张 + 1 张**签名卡**（该包的核心动作）。
- **卡库**：可**浏览 / 检索**全部卡种（按**卡类 / 类别 / 卡型 / 元素 / 级 / 包**筛选）；每种显示**持有张数**；已解锁的**直接可用**，未解锁的以**剪影**呈现（只提示"存在"，不显示效果）。
- **当前卡组**：从已解锁卡中选一套带入右侧栏，**可反复使用**（因为卡的消耗发生在"用"的那一刻，不是"带"的时候）。

## 5 卡与世界的联系（★重中之重）

"卡"与"世界"不是两样东西——**卡是世界的一部分**。三个方向双向打通。

### 5.1 卡 → 世界：施放即留痕

| 环节 | 表现 |
|---|---|
| 预览 | 世界内浮现作用域（笔刷圈 / 区域框 / 单体高亮） |
| 落地 | **纸板卡从 UI 飞出、翻面、插进世界**（§6） |
| 生效 | 卡的"模拟效果"真的改写世界状态 |
| 留痕 | 写入年表；地形卡留下**永久地貌**，生灵卡留下**活着的个体** |

### 5.2 世界 → 卡：世界会"回话"

| 机制 | 说明 |
|---|---|
| **共鸣高亮** | 当前世界状态下"特别有用"的卡自动发光 / 排前（冰期里「冰封」「雪被」发亮）——**不是解锁，是世界在提示你** |
| **情境表现** | 同类卡在不同条件下表现不同（"雪"卡在极地更持久）——体现"分何时有用，不分强弱" |
| **卡随世界生长** | 生灵卡投放后会**自行演化**：你抽到的"走兽"几代后可能变成新种——**卡本身在变** |
| **世界改写卡** | 触发卡生效后，卡从"待触发"变为"已生效"，卡面盖上**世界印记** |

> **设计红线**：共鸣只改"**排序与视觉提示**"，**绝不改卡的强度数值**。

### 5.3 接管与释放（现实项）

凡是覆盖现实输入的卡（日照 / 天气 / 温度 / 节气），UI 上标记"**已由你接管**"，可**一键释放回现实**（[`TIME.md`](TIME.md) §4.2）。

### 5.4 时间倒带：回滚什么？（★待裁决）

第 11 类卡可"回滚 N 世界分钟""按年表重演"。**必须写明回滚范围**，否则存在"施放 → 抬高扰动 → 回滚 → 再施放"的刷法。

**我的建议（待裁决）**：

| 对象 | 是否回滚 | 理由 |
|---|---|---|
| **世界状态**（地形 / 生态 / 环境） | ✅ 回滚 | 这是"改错了可以退回去重看"的价值所在 |
| **余响** | ❌ **不回滚** | 世界观上"余响 = 世界的回声 = 记忆"，**记忆不可逆** |
| **卡的解锁与持卡** | ❌ 不回滚 | 同上；否则会变成"回滚洗牌" |
| **年表** | ❌ 不回滚（追加一条"曾经回滚过"） | 年表是记忆本身；也天然成为防刷的可查证据 |

> 这套规则同时解决两件事：**世界观一致性**（记忆不可逆）＋ **防刷**（回滚不再能重置经济）。

## 6 动画与仪式（动力来源）

要有"打开它"的动力 → **每一次操作都要有仪式感**。全部程序化 + 2D 生图，**零人工动画资产**。

| 场合 | 动画 |
|---|---|
| **开包** | 纸包从侧边滑入 → **撕开封套**（纸裂声 + 纸屑）→ 卡成扇形飞出 → **逐张翻面**（背面是纸雕纹样）→ 签名卡最后亮起 |
| **施放** | 卡从手牌飞出 → 空中**翻面朝向世界** → 落入落点、**纸片震荡** → 效果展开（地形隆起 / 光柱升起 / 生物落地） |
| **世界反馈** | 硬阴影 + 移轴 + 纸片微动；大事件配一次**镜头轻推 + 纸屑** |
| **触发卡生效** | 世界某处**亮起一枚印记**，UI 里同步"盖章"——**提醒你：你定的规则生效了** |
| **扰动起伏** | 扰动升高时世界画面**轻微起伏**：边缘微卷、光线下沉 |
| **相互作用** | 两条原质在同一区域相遇时，交界处**亮起光纹**，反应随之展开 |
| **年表回放** | 倒带 / 因果重演时纸雕**逐帧倒退** |
| **卡组待机** | 手牌轻微呼吸 / 随风翘动，**让牌面看起来是"活纸"** |

> **可及性**：全部动画可在设置里**降级 / 关闭**（防晕动、省电）。
