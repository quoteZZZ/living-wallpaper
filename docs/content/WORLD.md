# 世界观 · 叙事与命名（WORLD）

## 0 本文件管什么 / 不管什么

- **管**：叙事设计原则、叙事承载方式、**术语与命名规范**（代码与文案共用）、**文案与本地化写作规范**。
- **不管**：**世界观的设定本身**（界 / 界外 / 七原质 / 环级 / 禁物）——真源是 [`../charter/GDD.md`](../charter/GDD.md) §1.3；卡的分类体系是 [`CARDS.md`](CARDS.md)；id 命名规则的技术部分是 [`../tech/STRUCTURE.md`](../tech/STRUCTURE.md) §7。
- **来源**：新建。**世界观定义不在此重复**；其中"叙事设计原则""语料与命名规范"吸收了已作废稿 [`../archive/STORY-v1.md`](../archive/STORY-v1.md) 中与形态无关的部分（见 §5 迁移说明）。

## 1 叙事设计原则

| 原则 | 说明 |
|---|---|
| **不写小说** | 所有叙事可拆成 ≤3 句一屏的短句，或一幅插画级画面；没有线性章节、没有对白剧本 |
| **不解释机制** | 世界观不承担教学功能；教学由 UI、卡面图示与世界反馈承担（守 GDD §16 极简原则） |
| **世界自己讲** | 主叙事载体是**世界本身的状态变化**与**年表**（GDD §15），不是弹窗剧情 |
| **真相靠拼接** | 不提供设定百科；玩家从年表、禁物代价、物种行为里自行拼出"界 / 界外 / 岸"的含义 |
| **原创零借名** | 不得出现任何现有作品的专有名词、角色、术语；命名一律取平实（GDD §1.3） |
| **可留白** | 允许"没有解释"——界不是谁造的，它本来就浮在那里（GDD §1.3） |

## 2 术语与命名规范（代码与文案共用）

### 2.1 核心术语表

| 中文 | 英文 | 代码 id 前缀 | 说明（定义真源） |
|---|---|---|---|
| 界 | Realm | `realm.` | 一座界 = 一个存档单元（GDD §7.3、§13） |
| 界外 | The Outside | — | 界壁之外，七原质的本源（GDD §1.3①） |
| 岸 | The Shore | — | **你的真实世界 = 界外里离这座界最近的那处岸**（GDD §1.3①） |
| 七原质 / 元素 | The Seven (Elements) | `el.`（内部） | 金 · 木 · 水 · 火 · 土 · 光 · 暗，固定七种（GDD §1.3②） |
| 级 / 环级 | Tier | 数字 `0–9` / `ban` | **尺度**，不是强度；`0` 碎片卡 · `1–8` 常规 · `9` 神卡 · 禁物无等级（GDD §1.3⑤） |
| 禁物 | Forbidden | `ban` | 界外漏进界里的碎片，件件带代价，无等级（GDD §1.3⑥） |
| 器物 / 器 | Vessel | — | 界里的一切，都是七原质的配比（GDD §1.3） |
| 余响 | Echo | — | 干涉世界产出的唯一积累物（GDD §11.1） |
| 卡类 | Class | 物 `matter` / 术 `rite` / 律 `law` | 三种卡类（GDD §10.0） |
| 类别 | Category | `cat.` | 四组十二类（GDD §10.1、CARDS §5） |
| 卡型 | Form | `form.` | 十二种生效方式（GDD §10.2、CARDS §6） |
| 扰动值 | Disturbance | — | 世界的状态读数（GDD §10.4） |
| 年表 | Chronicle | — | 世界史记录（GDD §15） |
| 世界钟 | World Clock | — | 双模式时间系统（GDD §5） |
| 现实锚 | Reality Anchor | — | 系统时间 / 纬度 / 联网天气（GDD §6） |
| 风格主题 | Style Theme | `style.` | T1–T5，纯表现层，可随时切（GDD §8） |
| 预设 | Preset | `preset.` | 出厂 / 用户保存的世界预设（GDD §12.2） |
| 物种 | Species | `sp.` | 生态单位模板（GDD §13.3） |

> **卡 id 形态**：`card.<元素>.<级>.<卡类>.<名>`，多元素用 `+`，禁物级用 `ban`——完整规则见 [`../tech/STRUCTURE.md`](../tech/STRUCTURE.md) §7.3。
> **命名风格**：**平实、可读、不中二**；同一概念在 GDD / 卡表 / 代码 / UI 文案里用**同一个词**。

### 2.2 命名禁忌

1. 不用现有作品的专有名词（含音译变体）。
2. 不造生僻字与自造字；优先用能一眼读懂的汉语词。
3. 同一事物不出现两个名字（旧名一律作废，见 [`../charter/DECISIONS.md`](../charter/DECISIONS.md) 里的"改名"条目）。
4. 代码 id 用英文小写 + 连字符；**不要拼音**。

## 3 文案与本地化规范

| 项 | 规则 |
|---|---|
| 语言 | **默认中英双语**（GDD §0）；缺语言时先 `en` 兜底再 `zh` |
| 存储形态 | 文案以 `{"zh":"…","en":"…"}` 成对出现（与 `Config/Solstice/Data/*.json` 一致） |
| 单条长度 | 中文 **≤ 40 字**、英文 **≤ 90 字符**，**最多两行**，超出必须拆条 |
| 语气 | **克制、陈述**；禁咆哮式文案、禁"邪恶"词汇；禁元词（"玩家""点击""镜头"） |
| 禁止 | 长块旁白、一次交代两个以上新设定、直接报出机制数值 |
| 英文 | **口语本地化，非直译**；术语按 §2.1 的英文列统一 |
| 卡面 | 画芯**不含文字**（名称/数值/徽记由 UMG 绘制，见 [`../art/ART-STYLE.md`](../art/ART-STYLE.md) §4） |

## 4 叙事承载方式（现行形态）

| 载体 | 说明 | 真源 |
|---|---|---|
| **年表** | 世界史记录（初雪、灭绝、迁入、玩家干涉…），可**导出为世界故事** | GDD §15 |
| **开包仪式** | 撕包动画与"这次能怎么玩"的期待感，是情绪叙事主力 | GDD §11.6 |
| **禁物代价** | 每件禁物自带负面效果，其代价即是短文案叙事的载体 | GDD §1.3⑥ |
| **物种行为** | 行为与死因可读（因果可读性硬要求），本身承担"世界在活着"的叙事 | GDD §13.6 |
| **界名与导出文件** | 界导出为本地文件时携带世界故事摘要（**待细化**） | GDD §12.4、§7.3 |

> **不做的**：主线剧情、对白剧本、任务文本链、播片。它们与"永续沙盒、无失败、无目标"的定位冲突（GDD §2、§4）。
