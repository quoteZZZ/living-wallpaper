# 归档说明（docs/archive/）

## 0 本文件管什么 / 不管什么

- **管**：本目录下每一份作废稿的「何时作废 / 为何作废 / 还有什么可继承 / 不要拿它做什么」。
- **不管**：任何现行规格。现行真源一律见 [`../INDEX.md`](../INDEX.md)。

**规则**：归档目录内的文档**无约束力**，任何代码、数据、命名都不得以它们为依据；引用它们的唯一合法方式是"沿革"语境。

## 3 不要拿归档稿做什么

1. 不要把它们当"设计参考"来对齐新方案——**形态已换，参考价值只剩沿革**。
2. 不要在现行文档里引用它们作为依据（唯一例外：`## 沿革` 章节里的历史叙述）。
3. 不要把归档稿里的技术词（Tauri / WebGL / Vite / TS / 2.5D / 自走棋 / `shared/` 旧契约 / `studio/` 旧管线）带回现行文档。
