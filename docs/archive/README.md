## 3 不要拿归档稿做什么

1. 不要把它们当"设计参考"来对齐新方案——**形态已换，参考价值只剩沿革**。
2. 不要在现行文档里引用它们作为依据（唯一例外：`## 沿革` 章节里的历史叙述）。
3. 不要把归档稿里的技术词（Tauri / WebGL / Vite / TS / 2.5D / 自走棋 / `shared/` / `studio/`）带回现行文档。
