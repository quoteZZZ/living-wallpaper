# 美术设定 · 五个风格主题（STYLE）

## 0 本文件管什么 / 不管什么

- **管**：**风格主题的设定层**——为什么风格可自由切换、有哪五个主题、每个主题的定义与取舍、参数落在哪、排期。
- **不管**：**执行层参数**（渲染配方、色板 hex、素材规格、QC、验收流程）→ 见 [`../art/ART-STYLE.md`](../art/ART-STYLE.md)；资产生产与登记 → [`../art/ASSETS.md`](../art/ASSETS.md)。
- **边界**：本文件回答"**主题是什么、为什么是它**"，ART-STYLE 回答"**怎么画出来、怎么验收**"。

---

## 1 机制：风格是纯表现层，因此可随时切换

**架构前提**：`Sim`（世界模拟）**零渲染依赖**（[`../tech/ARCHITECTURE.md`](../tech/ARCHITECTURE.md) §2.2）→ 风格完全属于 `Render` 层。于是：

- 风格主题**可逐界独立**、**可随时切换**、**可存为预设**；
- **同一份存档能长出完全不同的长相**；
- **一套几何资产 → 多套皮**（差异只在材质、后期与几何处理策略上），**不会产生多套建模工作量**。

---

## 2 五个风格主题（用户可选）

| 主题 | 名 | 一句话 | 关键技术 | 成本 |
|---|---|---|---|---|
| **T1** | **纸雕微缩** Paper Diorama | 一盒手工纸雕景观：纸厚度、硬折角、锐利投影、层叠景深 | 双面挤出 + Cel LUT + Inverted Hull + 硬阴影 + 移轴 | 中 |
| **T2** | **剪纸立牌** Cutout Puppet | 像纸偶戏舞台：大量 2D 立牌插进 3D 景深，景片层层推远 | 立牌（双面面片）+ 层叠背景板 + 轻雾 | **低（产能最高）** |
| **T3** | **手绘纸墨** Ink & Paper | 墨线 + 平涂 + 纸颗粒，承接旧风格锚 C1 | Cel + 描边 + 纸张叠加 | 低 |
| **T4** | **木刻版画** Woodcut | 黑白高对比 + 排线阴影 + 双色套印 | 阈值化光照 + 程序化排线 + 限色 LUT | 低 |
| **T5** | **粘土定格** Claymation | 柔和光 + 指纹肌理 + 微抖动，像逐帧拍的粘土动画 | 程序化凹凸噪声 + 12–15fps 步进 + 微位移抖动 | 中 |

### 2.1 每个主题由六组参数定义

**着色模型 / 描边方式 / 调色板 / 光照与阴影 / 后期（景深 · 暗角 · 颗粒 · 抖动）/ 几何处理（是否用立牌、是否减面）**。

参数落位（目录状态见 [`../tech/STRUCTURE.md`](../tech/STRUCTURE.md) §0，🟡 = 计划中）：

| 内容 | 位置 | 状态 |
|---|---|---|
| 参数契约 | `shared/schema/style.schema.json` | 🟡 计划中 |
| 主题实例 | `studio/presets/style.*.json` | 🟡 计划中 |
| 主题资产 | `game/Content/Styles/<主题>/` | 🟡 计划中 |
| 执行细则 | [`../art/ART-STYLE.md`](../art/ART-STYLE.md) | ✅ 已定（T1 详，T2–T5 待定标） |

### 2.2 排期

| 阶段 | 主题 | 说明 |
|---|---|---|
| **M0** | **T1（默认）** | 并**打通"换皮"机制**——机制不通，后面加主题的成本会失控 |
| **M1** | T2 | 成本最低、产能最高，适合做第二套验证"换皮"是否真的省 |
| **M2** | T3 · T4 · T5 | 主题是**参数集**，不是独立资产线，因此加主题的成本可控 |

### 2.3 风格与成本的关系（重要）

卡面 / UI / 贴图是 2D 图，**每个风格主题都需要自己的一套**。因此风格包（纯表现层）**按主题分批产出**，使"252 张卡 × N 主题"的成本**分批可控**而非一次爆炸（资产规模预算见 [`../art/ASSETS.md`](../art/ASSETS.md) §1）。

## 3 风格验收（设计层约定）

每个主题上线前必须出**三张对照图（正午 / 黄昏 / 雨）**，由**用户裁决锁定**；出图与风格锚对不上 = 退回重新生成。**风格不定标不进内容量产。**

> 流程细节与 M0 验收挂钩见 [`../art/ART-STYLE.md`](../art/ART-STYLE.md) §6、[`../plan/ROADMAP.md`](../plan/ROADMAP.md) §2 第 9 条。
