# 物种设定集（SPECIES）

## 0 本文件管什么 / 不管什么

- **管**：物种模板字段（数据契约草案）、**M0 五个物种**、种群动力与 tick 顺序、因果可读性硬要求。
- **不管**：世界本身（见 [`WORLD.md`](WORLD.md)）；卡怎么投放物种（见 [`../gameplay/INTERVENTION.md`](../gameplay/INTERVENTION.md)）；模拟内核的实现（见 [`../tech/ARCHITECTURE.md`](../tech/ARCHITECTURE.md) §2）。
- **来源**：由 `charter/GDD.md` §13.3–§13.6 拆出（内容未改）。

## 1 物种模板（JSON 契约草案，P1 定稿）

字段：

`id` · `角色`（生产者 / 消费者 / 分解者）· `体积` · `寿命` · `成熟期` · `繁殖能量阈值` · `繁殖环境条件` · `食性（目标 + 效率）` · `移动速度` · `栖息偏好` · `温度耐受` · `光照 / 水位需求` · `死亡掉落` · `感知范围` · `遗传字段（体型 / 色彩 / 特化）` · `视觉（几何生成器 id + 部件集 + 着色组）`

> 契约落位：`shared/schema/species.schema.json`（🟡 计划中，见 [`../tech/STRUCTURE.md`](../tech/STRUCTURE.md) §5），运行时数据落 `game/Config/Solstice/Data/species.json`。
> **几何与外观**：物种的 3D 主体由**程序化几何生成器**产出（[`../art/ASSETS.md`](../art/ASSETS.md) §1），**不做建模**；动画同样程序化（铰链运动 / 低频摆动 / 顶点位移）。

## 2 M0 五个物种

| # | 角色 | 定位 | 关键机制 |
|---|---|---|---|
| 1 | 生产者 | **苔草**：基础植被 | 提高植被量；需光照与水；低温停长 |
| 2 | 生产者 | **灌木**：慢生、提供遮蔽 | 提升同格湿度、提供庇护 |
| 3 | 消费者 | **走兽**：食草 | 吃植被、饮水、夜休；繁殖需植被阈值 |
| 4 | 消费者 | **掠禽**：食肉 | 捕食走兽；雨雪天活动下降 |
| 5 | 消费者 | **溪鱼**：水生 | 仅水覆盖区；水温敏感；随水位迁移 |

> **为什么是这五个**：覆盖"生产者 × 2 / 消费者 × 3"、覆盖"陆生 / 水生 / 飞行"、且能立刻验证三条因果链——**吃、被吃、缺水**。M0 只证明"它真的活着"（[`../plan/ROADMAP.md`](../plan/ROADMAP.md) §1）。
> **命名与文案**：中英双语成对（`{"zh":…,"en":…}`），规范见 [`WORLD.md`](WORLD.md) §7。

## 3 交互与种群动力

**固定 tick 顺序**：

```
环境更新 → 生产者生长 → 消费者决策（有限状态机 + 局部感知）
        → 进食 / 被捕食 → 繁殖 → 死亡 → 分解回地力
```

- 消费者**不做全局寻路**（性能与可复现）。
- **承载力由植被量决定**；极端条件下转入休眠或留种。
- **"无失败"落到机制**：物种灭绝后仍可由"**种子雨**"（每 N 世界日小概率外来迁入）自然恢复；开启演化时还会分化出新形态。

> 可复现性约束（固定逻辑 tick、随机数分流域、按显式 ID 升序遍历）见 [`../tech/ARCHITECTURE.md`](../tech/ARCHITECTURE.md) §2.2。

## 4 因果可读性（硬要求）

1. 每次死亡带**原因枚举**（饿死 / 被捕食 / 冻死 / 淹死 / 老死）并短暂显示图标。
2. 种群崩溃必须给出**主导原因**并写入年表（[`WORLD.md`](WORLD.md) §5）。
3. **验收**：随机抽查 10 次死亡，玩家都能从画面读出死因（[`../plan/ROADMAP.md`](../plan/ROADMAP.md) §2 第 10 条）。
