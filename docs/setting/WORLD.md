## 1 世界是什么（★核心设定）

**世界是一座界** —— 不是谁造的，而是**本来就浮在那里**。玩家不在界里，而在**界外最近的那处岸上**。

### 1.1 界 · 界外 · 岸

| 层 | 名 | 内容 |
|---|---|---|
| **外** | **界外** | 界壁之外：**七原质**的本源，以及偶尔漏进来的**外来碎片**（即禁物，§1.8） |
| **中** | **七原质** | 世界的**基本材料**：金 · 木 · 水 · 火 · 土 · 光 · 暗，**固定七种、不可增删** |
| **内** | **器** | 界里的一切，都是**七原质的配比** |

**界外与「岸」**：界壁之外不是虚无，是**界外**——它一直在压着这座界。压进来的东西沉进界里，成了**七原质**。

> **你的真实世界，是界外里离这座界最近的那处「岸」。** 真实的时间、天气、纬度不是"联动"，而是**你站在岸上，看着同一片界外压着这座界**（机制见 [`../gameplay/TIME.md`](../gameplay/TIME.md) §2）。

### 1.2 七原质（七元素）

**世界由七种原质组成**：**金 · 木 · 水 · 火 · 土**（五行：走**五行生克**）+ **光 · 暗**（**与五行互相独立**，自成一对生克）。**七原质固定，不可增删**，合称**七元素**（生克表见 [`CARDS.md`](CARDS.md) §8）。

**「质」分两种**（其中异质已整体撤出核心）：

| | 是什么 | 状态 |
|---|---|---|
| **原质** | 世界的**基本材料**，7 种固定 | **核心，本作按此运行** |
| ~~**异质**~~ | 质变的产物：由原质合成 | **★已撤出核心，留档待扩展**（§1.6） |

**质变**：七原质不是死材料——**质可以互相转化（质变）**；卡做的事，就是**推动这种转化**（创造 / 消除 / 转换）。**质变不再对应任何"性"这一层标签**（见下）。

### 1.3 术语表（核心只有一个：原质）

| 名 | 是什么 | 数量 | 状态 |
|---|---|---|---|
| **原质** | 世界的**基本材料** | **7** | **核心**，固定不可增删 |
| ~~原性~~ | ~~原质的作用倾向（7 × 3 = 21 个标签）~~ | —— | **★已删除，不再存在** |
| ~~异质~~ | ~~原质合成出的质~~ | —— | **★撤出核心，留档待扩展**（§1.6） |
| ~~异性~~ | ~~异质自带之性~~ | —— | **★同上** |

> **★已删除「三原性 / 21 个原性标签」的说明**：此前每条原质有三个作用倾向（7 × 3 = 21），既当**卡的效果标签**、又当**世界模拟的物理清单**——**这套设定整体撤出**。卡的描述改用**卡类 × 类别 × 卡型 × 元素 × 级**五项（[`CARDS.md`](CARDS.md) §7），**具体效果写在各卡的"参数与模拟效果"里**。"原性""异性"与"新质"同列作废（沿革见 [`../charter/OPEN-QUESTIONS.md`](../charter/OPEN-QUESTIONS.md) #21–#23、[`../charter/DECISIONS.md`](../charter/DECISIONS.md) 第 26 轮）。

**元素 vs 级（两个正交维度）**：**元素**是世界的材料（7 种）；**级（环级）**是改动的**尺度**（0 – 9 + 禁物，§1.7）。**两者正交**——任何元素都覆盖全部级，任何级都有全部元素；**元素间**走生克，**级之间**只讲尺度覆盖。

### 1.4 唯一用词约定（术语冻结）

| 语境 | 用词 | 含义 |
|---|---|---|
| **世界观 / 设定** | **原质**（七原质） | 世界的材料 |
| **卡片上** | **元素标签** | 同一件东西在卡上的表达（1..N 个） |
| **通用** | **元素**（七元素） | 上述两者的合称 |

> **同一样东西，三个词**——写文档时按语境取词，**不要在同一句里混用**。（本条即"原质 / 元素"漂移的修复约定。）

### 1.5 相合（★已随异质一起留档，暂不运行）

**不是叠加，是化学反应**——**两条原质**相合会生成"第三种质"。**这套产物归类（曾叫"新质"，后叫"异质"）已整体撤出核心**，因此**本节暂不运行**；**世界目前按"七原质"运行**。

**📁 留档：七原质两两相合（21 项，供日后扩展用，当前不作数）**

| 相合 | 曾用名 | 说明 |
|---|---|---|
| 金 + 木 | **器** | 木被金削成形 |
| 金 + 水 | **露** | 金面凝水 |
| 金 + 火 | **炉** | 火炼金 |
| 金 + 土 | **矿** | 金藏于土 |
| 木 + 水 | **浆** | 木生于水 |
| 木 + 火 | **烟** | 木被火化 |
| 木 + 土 | **苔** | 木覆于土 |
| 水 + 火 | **汽** | 水被火蒸 |
| 水 + 土 | **泥** | 水混于土 |
| 火 + 土 | **熔** | 火熔于土 |
| 金 + 光 | **镜** | 光映金面 |
| 木 + 光 | **华** | 光催花发 |
| 水 + 光 | **虹** | 水汽分光 |
| 火 + 光 | **阳** | 光火同炽 |
| 土 + 光 | **霞** | 光染尘云 |
| 金 + 暗 | **锈** | 暗蚀金身 |

### 1.6 异质 · 异性（★整体撤出核心，留档）

**当前决定**：**异质与异性不做进本作**——理由是这套设定没立住（试过的两版都被判定不行）。

| 曾试过的方案 | 结果 |
|---|---|
| **方案 A**：七异质 **引 / 斥 / 熵 / 谐 / 相 / 虚 / 时**（挂引力 / 斥力 / 热力学第二定律 / 共振 / 相变 / 真空 / 时间），各配三条原质配方 | **作废**（"参照物理法则"命名） |
| **方案 B**：异质 = **两条或多条原质合成**、自带**异性**；两条这一层直接沿用 §1.5 的 21 项 | **作废** |
| **保留的结论**：若日后重启，**"两条原质相合"是异质的入口层**（§1.5 名单已留档）；三条以上另出异质、通常带**异性** | 待扩展时再议 |

> **重启时机**：**开发完成之后**再作为**扩展内容**考虑（与"多界 / 演化 / 导入导出"同级的后置项，见 [`../plan/ROADMAP.md`](../plan/ROADMAP.md) §1）。
> **风 / 雷 / 霜 暂不作为元素**：它们降为**「现象」**——不是元素，而是原质在世界里的**表现**，归入卡的「大气与气候」与「天气」两类；**光** 已升为原质；**虚 / 时** 一并留档。
> **禁物（§1.8）不受影响**：那是**从界外漏进界里的碎片**，与"合成出来的异质"是两回事。

### 1.7 环级（0 – 9 · 禁物）

卡按**尺度**分**环级**——**不是强度，是世界被改动的范围**（[`CARDS.md`](CARDS.md) §3）。**数值越大，尺度越大**：

| 环级 | 名 | 说明 |
|---|---|---|
| **超环** | **超环**（高于 9 环） | **独立档位，定义待裁决**（[`CARD-LIST.md`](CARD-LIST.md) §2.5） |
| **9** | **神卡**（常规最高） | 该元素（× 该卡类）的顶点 |
| **8 … 1** | **常规** | 从一粒沙到整界，数值越大改得越广 |
| **0** | **碎片卡**（最低） | **尺度最微的卡**：**有真实效果**，只是小到**"一片碎片"** |
| **禁物** | **禁物**（无环 · 无等级） | **不在尺度上**：界外碎片，**都有负面效果**（§1.8） |

> **定名沿革**：原「星级」及试过的「阶」**均作废**，阶梯统一叫 **级**（**环级**）。「**超环 = 权能卡**」曾在第 27 轮随权能线一并删除；**2026-10-14 由用户恢复「超环」为独立档位（高于 9 环，与权能无关）**，其具体定义待裁决（[`../charter/DECISIONS.md`](../charter/DECISIONS.md) 第 27–28 轮）。
> **0 环「碎片卡」定案（方案 A）**：**它是"尺度最微的卡"**——**有真实效果**，只是**小到"一片碎片"**：一片苔 / 一粒沙 / 一滴水 / 一缕烟。**不是废卡、不是残页**；**低环永远有效、永远能用**，只是痕迹容易被更大尺度盖过（级生克见 [`CARDS.md`](CARDS.md) §8.3）。

### 1.8 禁物（第 11 档 · 无等级）

| 项 | 内容 |
|---|---|
| **是什么** | **从界外漏进界里的碎片**——**不属于任何元素、任何组合**的外来物 |
| **怎么用** | **只能"启用"或"封存"**：**不能养成、不能变强** |
| **代价** | **每一件都有**：启用后留下**抹不掉的痕迹**（扰动值 ↑），并且往往**同时改坏某样东西** |
| **参照** | **SCP 的项目** ＋ **《诡秘之主》的封印物**——**越有用，越危险** |
| **等级** | **无等级**：不分档、不分强弱，只按"用不用"取舍；在卡池矩阵中占**禁物档**，**不带元素标签** |
| **张数** | **一种可持多张**，但**同时只能启用一件** |

**示例**（详细名单与代价见 [`CARDS.md`](CARDS.md) §3.3）：

| 禁物 | 代价 |
|---|---|
| 常温水杯：永远装满水 | **水无处可排** |
| 不落的叶：一株永不落叶 | **它的根周围寸草不生** |
| 逆流的沙漏：一片区域时间倒退 | **该区域留下永久斑点** |
| 无雨的铁云：整界永不下雨 | **生物缓慢失水** |
| 第二颗太阳：天空出现第二颗太阳 | **昼夜紊乱，扰动剧增** |

> **禁物是全作唯一的"负面后果"来源**，与"永远不会输"构成张力（[`../charter/GDD.md`](../charter/GDD.md) §2）。

## 2 世界规模与多界

### 2.1 三档尺寸

| 档 | 尺寸 | 面积 | 格 | 分块 | 隐喻 | 生态域 | 个体预算 |
|---|---|---|---|---|---|---|---|
| **小界** | 128 × 128 | 128 m 见方 | 16,384 | 4 × 4 | **一个地区** | 2–3 | 500–1200 |
| **中界** | 256 × 256 | 256 m 见方 | 65,536 | 8 × 8 | 一片区域 | 4–6 | ~3000 |
| **大界** | 512 × 512 | 512 m 见方 | 262,144 | 16 × 16 | **一个小世界** | 8+ 含气候带 | 8000+（统计式降载） |

- 分块尺寸 **64 × 64 格**；只加载视野内与邻近分块（[`../tech/ARCHITECTURE.md`](../tech/ARCHITECTURE.md) §1.2）。
- 大界通过**气候带**（纬度式温差）+ 多生态域形成"小世界"感。

### 2.2 生态域

**生态域 = 环境参数 + 物种集的组合**：水塘 / 草原 / 林缘 / 岩坡 / 沼泽 / 沙地 / 雪原 / 河谷 / 洞穴 / 高原。
小界 2–3 个（已是"地区"感），中界 4–6，大界 8+ 并带气候带渐变。物种见 [`SPECIES.md`](SPECIES.md)。

### 2.3 多界并存

- 可创建 / 切换 / 复制 / 删除多个界；每界独立存档（存档槽 + 界 id）。
- **同一时刻只推演"激活界"**，其余界冻结（性能与电量前提）；切换即解冻。
- 界可导出 / 导入为本地文件（JSON + 分块数据）；**不做线上分享与工坊**。

## 3 世界模型

### 3.1 地块与地形

- 每格：`高度`（0–64，量化 0.25）、`地表类型`（草 / 土 / 石 / 沙 / 水 / 雪 / 冰）、`植被量`（0–1）、`湿度`（0–1）、`局部温度`。
- 全局 `水位`：`高度 < 水位` 的格自动为水（可结冰）。
- 渲染：分层纸板 mesh（**3–5 层**），由高度场程序化生成并**按分块脏标记重建**。

### 3.2 环境变量

太阳高度角 / 光照强度 / 色温、气温、降水（强度 + 形态）、风力风向、云量、大气含氧量、湿度。

**来源**：现实锚（或虚拟天气）+ 卡池覆盖 + 法则参数（→ [`../gameplay/TIME.md`](../gameplay/TIME.md) §2）。

## 4 世界史年表

- **记录**：初雪、第一场雨、首次繁殖、首次捕食、物种灭绝、物种迁入、种群新高、极端天气、**玩家每次重大干涉（含卡名）**、最长旱季、模式切换、现实项被接管 / 释放、演化分化、**触发卡生效**、**相互作用**、**余响里程碑（首次跨阈值 / 开包）**。
- **结构**：`世界钟时间戳` + `类型` + `涉及物种 / 卡` + `摘要`；环形缓冲 500 条（可扩容）。
- **用途**：① 回看 ② **时间倒带 / 因果重演**的索引 ③ **导出为世界故事** ④ **「余响」事件回响的结算依据**（[`../gameplay/INTERVENTION.md`](../gameplay/INTERVENTION.md) §2）。
- **定位**：年表是**记忆**，不是奖励清单；它是本作唯一"收集痕迹"（[`../charter/GDD.md`](../charter/GDD.md) §2）。

## 5 叙事设计原则

| 原则 | 说明 |
|---|---|
| **不写小说** | 所有叙事可拆成 ≤3 句一屏的短句，或一幅插画级画面；**没有线性章节、没有对白剧本** |
| **不解释机制** | 世界观不承担教学功能；教学由 UI、卡面图示与世界反馈承担（守"首屏即世界"的极简原则） |
| **世界自己讲** | 主叙事载体是**世界本身的状态变化**与**年表**（§4），不是弹窗剧情 |
| **真相靠拼接** | 不提供设定百科；玩家从年表、禁物代价、物种行为里自行拼出"界 / 界外 / 岸"的含义 |
| **原创零借名** | 不得出现任何现有作品的专有名词、角色、术语；命名一律取平实 |
| **可留白** | 允许"没有解释"——界不是谁造的，它本来就浮在那里 |

### 6.2 命名禁忌

1. 不用现有作品的专有名词（含音译变体）。
2. 不造生僻字与自造字；优先用能一眼读懂的汉语词。
3. 同一事物不出现两个名字（旧名一律作废，见 [`../charter/DECISIONS.md`](../charter/DECISIONS.md) 的"改名"条目）。
4. 代码 id 用英文小写 + 连字符；**不要拼音**。

## 7 文案与本地化规范

| 项 | 规则 |
|---|---|
| 语言 | **默认中英双语**；缺语言时先 `en` 兜底再 `zh` |
| 存储形态 | 文案以 `{"zh":"…","en":"…"}` 成对出现（与 `Config/Solstice/Data/*.json` 一致） |
| 单条长度 | 中文 **≤ 40 字**、英文 **≤ 90 字符**，**最多两行**，超出必须拆条 |
| 语气 | **克制、陈述**；禁咆哮式文案、禁"邪恶"词汇；禁元词（"玩家""点击""镜头"） |
| 禁止 | 长块旁白、一次交代两个以上新设定、直接报出机制数值 |
| 英文 | **口语本地化，非直译**；术语按 §6.1 的英文列统一 |
| 卡面 | 画芯**不含文字**（名称 / 数值 / 徽记由 UMG 绘制，见 [`../art/ART-STYLE.md`](../art/ART-STYLE.md) §4） |
