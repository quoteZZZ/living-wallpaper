# 卡片设定集（CARDS）

> **本文档是「卡片」设定的唯一落点**（原 `GDD.md` §10 与旧 `CARDS.md` 的双写已合并至此）；与立项书 [`../charter/GDD.md`](../charter/GDD.md) 冲突时以立项书为准。
> 本轮要点：**无三原性** · **无权能线 / 四权能 / 超环权能卡** · 卡池骨架 = **七元素 × 11 级 × 3 类**（**卡种 ≥ 231**，多元素另计、每种可多张） · 世界观用名 **界**（原「缸」）/ **界外**（原「垣外」）。

---

## 0. 一句话

**一张卡 = 一组元素标签（1..N 个）× 一个级 × 一个卡类**；它具体做什么，由**类别（改什么）**与**卡型（怎么生效）**描述。

---

## 1. 卡池骨架

### 1.1 三个维度

| 维 | 取值 | 数量 | 回答 |
|---|---|---|---|
| **元素**（元素标签） | 金 · 木 · 水 · 火 · 土 · 光 · 暗 | **7**（**可 1..N 个**） | 用哪种材料改 |
| **级**（环级） | **0 – 9**（十档）+ **禁物**（第 11 档） | **11** | 改多大尺度 |
| **卡类** | 物 · 术 · 律 | **3** | 这张卡是什么 |

**元素与级正交**：任何元素都覆盖全部 11 级；任何级都有全部 7 元素。**卡种 = 元素 × 级 × 类。**

### 1.2 卡种（kind）与张数（copy）—— 231 是「种类」下限

| 词 | 含义 |
|---|---|
| **卡种（kind）** | 一种卡 = 一组固定的「元素标签 + 级 + 类 + 类别 + 卡型 + 效果」。**卡池按"种"计。** |
| **张数（copy）** | **同一种卡可以持有任意多张**——带多张进卡组、反复施放 / 分解 / 固化。**卡池实物张数 > 卡种数。** |

> **231 是单元素卡种的下限，不是卡的总张数。**

### 1.3 单元素卡种的构成（下限 231）

| 段 | 算式 | 卡种数 |
|---|---|---|
| **常规卡**（0 – 9 十档） | 7 元素 × 10 档 × 3 类 | **210**（每个卡种都带元素标签） |
| **禁物**（第 11 档） | 7 × 1 档 × 3 类 | **21**（**不带元素标签**，见 §3.3） |
| **单元素合计** | | **231（下限）** |

### 1.4 多元素卡种（额外，往上加）

- **元素标签可取 1..N 个**：多个 = **多元素卡**（如 火 + 木 的野火 / 水 + 光 的虹）。
- 多元素卡是**在 231 之上的额外卡种**，因此**卡池种类"最少 231"**。
- **多元素卡同时参与各元素的生克结算**；**光 / 暗 只与彼此生克，不与五行作用**（§8）。
- **比例与上限待定**（§13）。

### 1.5 阶段切分

| 阶段 | 卡种 | 说明 |
|---|---|---|
| **M0** | **36** | 土 / 火 / 金 三元素 × 级 0 – 3 × 3 类 |
| **M1** | 中界所需 | 另排 |
| **M2** | **≥ 231 全量** | 7 元素 × 11 级 × 3 类，多元素另计 |

### 1.6 卡池的填法规则（★2026-10-14 定案）

| 规则 | 内容 |
|---|---|
| **目标** | **单元素卡以 231 为设计目标**（7 元素 × 11 级 × 3 类）。 |
| **允许留空** | 某元素在某级做不出有意义的某卡类时，**该格允许留空**，登记在 §14「留空清单」；**不允许为凑数而做"白开水卡"**。 |
| **多元素卡不预设** | 多元素卡**不预设清单、不做组合枚举**（全组合最多约 3960 个卡种，必然失控）。**设计具体某张卡时，若它天然跨元素，就给它多个元素标签**——从需求反推，而不是从组合枚举。 |
| **对外口径** | 无论留空多少，**"卡种 ≥ 231"始终成立**：留空的格子由多元素卡补足。 |
| **顺序** | 先填**单元素 231**（M0 只填 36），多元素卡随具体设计自然新增。 |

## 2. 七个元素（原质）

| 元素 | 归属 | 生克归属 | 一句话 |
|---|---|---|---|
| **金** | 五行 | 走五行生克 | 刃、铸、矿、锈 |
| **木** | 五行 | 走五行生克 | 生长、蔓延、腐化 |
| **水** | 五行 | 走五行生克 | 流动、浸润、冰封 |
| **火** | 五行 | 走五行生克 | 燃烧、照亮、焚毁 |
| **土** | 五行 | 走五行生克 | 承载、堆叠、塌陷 |
| **光** | 独立 | **只与暗生克** | 照、折、晒 |
| **暗** | 独立 | **只与光生克** | 遮、藏、灭 |

- **七元素固定，不可增删。**
- **光 / 暗不参与五行生克**，自成一对（§8.2）。
- 世界观里这套材料叫**原质**；落在卡上叫**元素标签**——同一个东西的两个语境。

## 3. 十一个级（环级）

### 3.1 级 = 尺度，不是强度

| 级 | 名 | 尺度参照 | 单元素卡种数 |
|---|---|---|---|
| **9** | **神卡**（最高） | 整界重写 | 21 |
| **8** | 常规 | 半界 | 21 |
| **7** | 常规 | 一个气候带 | 21 |
| **6** | 常规 | 一片荒漠 / 雨林 | 21 |
| **5** | 常规 | 一道山脉 / 一条大河 | 21 |
| **4** | 常规 | 一片林 / 一个湖 | 21 |
| **3** | 常规 | 一座丘 / 一段溪 | 21 |
| **2** | 常规 | 一丛树 / 一口塘 | 21 |
| **1** | 常规 | 一小片草地 | 21 |
| **0** | **碎片卡**（最低） | **一片碎片**（一片苔 / 一粒沙 / 一滴水 / 一缕烟） | 21 |
| **禁物** | **禁物**（第 11 档 · **无等级**） | **不在尺度上** | 21 |

> **规则**：**数值越大，尺度越大**，**不是强度**——**低环卡永远有效、永远能用**，只是它的痕迹容易被更大的尺度盖过（§8.3 级生克）。
> **定名沿革**：原「星级 / 阶」作废，统一叫 **级（环级）**；原「超环 = 权能卡」随权能线一起删除，**最高档就是 9 神卡**。

### 3.2 0 级：碎片卡（方案 A）

- **0 环 = 尺度最微的卡**：**它有真实效果**，只是**小到"一片碎片"**。
- **不是废卡、不是残页**——**不存在"只能分解成余响"的卡**。
- 例：一片苔、一粒沙、一滴水、一缕烟。
- 与更高环的关系：**有效**，但痕迹易被覆盖（§8.3）。

### 3.3 禁物档（21 种 · 无等级）

| 项 | 内容 |
|---|---|
| **是什么** | **从界外漏进界里的碎片**——**不属于任何元素、任何组合** |
| **怎么用** | **只能"启用"或"封存"**；**不能养成、不能变强** |
| **代价** | **每一件都有**：启用后留下**抹不掉的痕迹**（扰动值↑），并且往往**同时改坏某样东西** |
| **参照** | **SCP 的"项目"** ＋ **《诡秘之主》的封印物**——**越有用，越危险** |
| **等级** | **无等级**：不分档、不分强弱，只按"用不用"取舍；在卡池矩阵中占**禁物档格位**，**不带元素标签** |
| **张数** | **一种可持多张**，但**同时只能启用一件** |

**示例（不分档）**：

| 禁物 | 代价 |
|---|---|
| 常温水杯：永远装满水 | **水无处可排** |
| 不落的叶：一株永不落叶 | **它的根周围寸草不生** |
| 逆流的沙漏：一片区域时间倒退 | **该区域留下永久斑点** |
| 无雨的铁云：整界永不下雨 | **生物缓慢失水** |
| 第二颗太阳：天空出现第二颗太阳 | **昼夜紊乱，扰动剧增** |

## 4. 三种卡类（物 / 术 / 律）

**卡类 = 这张卡在世界里"是什么"**——决定**卡面样式 / 牌背颜色 / 落地形态 / 能不能固化**。

| 卡类 | 一句话 | 内容 | 落地后 | 固化 | 例 |
|---|---|---|---|---|---|
| **物** Matter | **世界里的东西** | 生物 · 死物 · 各个事物 | 变成实体或活体，留在世界里 | **能** → 留活物 / 地形 / 器物 / 碑 | 走兽、苔草、岩柱、湖泊、火山 |
| **术** Rite | **主动施展的效果** | 魔法 · 幻想法术等 | 什么都不留下，只改**状态** | **不能** → 只留一块**印记** | 降雨、重力减半、永昼、岩浆注入 |
| **律** Law | **写下来的规则与仪式** | 仪式 · 规则等 | 把一条**条件或誓约**刻进世界 | **能** → 刻成永久规则 | 水位 > 40 自动结冰、献祭唤风暴、命名、立碑 |

- **三类与类别正交**：同一条类别里三类都可能出现（「生命与生态」里既有"物"的走兽卡，也有"律"的保护规则卡）。
- **不分强弱**：三类只是**玩法手感**的区分——**造东西 / 点一下 / 定规矩**。
- **视觉建议**：物 = 灰石 · 术 = 靛蓝 · 律 = 赭红（各风格主题另配一套）。
- **与游戏王的对应**：物 ≈ 怪兽 + 场地 / 装备 · 术 ≈ 魔法 · 律 ≈ 陷阱。
- **231 个卡种的卡类配额（建议）**：**物 ~106 · 术 ~87 · 律 ~38**（M2 定稿时对齐）。

## 5. 四组十二类（改什么）

| 组 | # | 类 | 一句话 | 边界 |
|---|---|---|---|---|
| **环境** | 1 | 地形与地貌 | 抬压、切裂、层叠 | 固体地表 |
| | 2 | 水体 | 水位、潮汐、河流、冰封 | 液态水 |
| | 3 | 大气与气候 | 温度基线、湿度、气压、大气成分 | **长期基线** |
| | 4 | 天气 | 雨雪雾暴、干旱热浪 | **短期事件** |
| | 5 | 天体与光照 | 太阳、月亮、星空、光柱 | 天外与光 |
| | 6 | 温度与能量 | 热源、岩浆、冰期、代谢 | 能量的收支 |
| **生命** | 7 | 生命与生态 | 投放、迁移、灭绝、复活 | 个体与种群 |
| | 8 | 演化与遗传 | 突变、特化、分化 | 跨代变化 |
| **法则** | 9 | 物理法则 | 重力、摩擦、生长率、时间泡 | 世界的常量 |
| | 10 | 世界规则 | 永夏、无重力、巨型化 | 世界的整体设定 |
| | 11 | 时间与因果 | 快进、回溯、局部时间 | 时间轴本身 |
| **记录** | 12 | 记录与叙事 | 命名、立碑、编年 | 世界的记忆 |

**三条边界规则**（防止重叠）：

1. **基线 vs 事件**：3 定长期平均（气候），4 是当下正在发生的（天气）。
2. **物质 vs 法则**：6 管能量的多少（热、光、代谢），9 管物理常量（重力、摩擦、生长率）。
3. **干涉 vs 记忆**：1–11 改世界，12 只记录世界（不产生物理效果）。

## 6. 十二种卡型（怎么生效）

| 卡类 | 卡型 | 生效方式 | 例 |
|---|---|---|---|
| **物** | **生物** | 活体：投放后自行觅食 / 繁殖 / 死亡 | 走兽、掠禽、溪鱼 |
| **物** | **材质** | 只改地表的材质，不改高度 | 把草地变成沙地 |
| **物** | **遗物** | 附着在某个实体上，跟随移动 | 给一棵树挂"不落叶" |
| **物** | **造物** | 直接生成一个**无生命实体**（不动、不附着） | 岩柱、器物、桥、碑 |
| **术** | **瞬时** | 立即结算、不留续 | 小雨、抬升、快进 |
| **术** | **持续** | 持续到释放或被改回 | 恒定湿度、永昼 |
| **术** | **规则** | 写进世界法则，永久 | 重力减半 |
| **术** | **合契** | 需要两种指定元素同时在场才能施放 | 火 × 木 才会成的野火 |
| **术** | **场域** | 立起一片区域环境 | 一片永雾区 |
| **律** | **触发** | **预设"当…时 → …"，世界自动执行**（★最重要） | 水位 > 40 时自动结冰 |
| **律** | **仪轨** | 需要代价或准备时间才能发动 | 献祭生物量唤来风暴 |
| **律** | **记录** | 写入年表 / 在世界上呈现文本 | 命名物种、立碑 |

> **触发卡是本作最重要的机制**：它把"玩家手动点一下"升级为"**玩家给世界定一条规则**"——世界从此自己执行。这是"我在养一个世界"的核心手感。
> **沿革**：原「素材（残页，只能分解成余响）」随 0 环碎片卡定案（方案 A）**作废**，该位由 **造物** 补上，**仍为 12 种**。

## 8. 相互作用（三套生克）

**卡带 1..N 个元素标签**；同一区域内，不同元素的卡按生克**自行结算**。生克有**三套**。

### 8.1 五行生克（金 / 木 / 水 / 火 / 土）

**相生（互相增强）**

| 生 | 结果 |
|---|---|
| 金 → 水 | 金属表面凝露，矿脉渗水 |
| 水 → 木 | 疯长：植被爆发 |
| 木 → 火 | 助燃：火势失控 |
| 火 → 土 | 焦土沃化：灰烬变肥 |
| 土 → 金 | 结矿：土中析出矿脉 |

**相克（互相压制）**

| 克 | 结果 |
|---|---|
| 金 → 木 | 伐：植被被剃光 |
| 木 → 土 | 固：根系锁住土石 |
| 土 → 水 | 掩：填湖、断流 |
| 水 → 火 | 灭：熄火生雾 |
| 火 → 金 | 熔：金属熔化 |

### 8.2 光暗生克（光 / 暗 与五行互相独立）

| 关系 | 结果 |
|---|---|
| **光 生 暗** | 有光才有影：光照到哪，影就长到哪（**昼 → 影**） |
| **暗 生 光** | 暗到极处见光：夜尽天明、暗中之烛（**夜 → 昼**） |
| **光 克 暗** | 照亮即驱散：阴影退散、躲藏者现形（**显形**） |
| **暗 克 光** | 吞没即遮断：光源被吸、能见度骤降（**隐蔽**） |

> **光 / 暗不参与五行生克**（既不生也不克五行，五行也不生克它们），**只与彼此**生克。
> **光暗的平衡 = 昼夜节律**——世界钟与物候的驱动之一。

### 8.3 级生克（尺度覆盖）

| 关系 | 结果 |
|---|---|
| **高环 → 低环：克** | **尺度覆盖**：大尺度的改写会**盖过**同区域内小尺度的既有改动（9 级的改地形盖掉 0 级的一片苔） |
| **低环 → 高环：生** | **累积诱发**：许多小改动长期叠加，会**自己长成**一个大尺度的结果（连年小雨 → 气候变湿） |

> **注意分寸**：这条生克是**尺度覆盖**，**不是数值碾压**——**低环卡永远有效、永远能用**，只是痕迹会被更大的尺度盖住。

**三套可同时结算**：一张卡可以既有元素标签（吃五行 / 光暗生克），又被更大尺度覆盖（吃级生克）。
**反应写进年表**，且是**涌现**的——玩家常会撞见"我没设计过的组合"。

### 8.4 相合（★留档，暂不运行）

**两条元素相合生成"第三种质"**（曾叫「新质」/「异质」）——**该体系已整体撤出核心**，仅留档备查（名单见 [`WORLD.md`](WORLD.md) §1.5），**世界目前按"七元素"运行**。

## 9. 机制

### 9.1 三种用法（一卡三用）

| 用法 | 结果 | 什么时候用 |
|---|---|---|
| **施放** | 卡的效果作用于世界（地形隆起 / 降雨 / 投放物种） | 想改世界 |
| **分解** | 把卡拆解，换一笔**余响** | 缺资源、卡不对路 |
| **固化** | 把卡留在世界里成为**实体**：一座山、一株树、一只活物、一块碑 | 想留永久的东西 |

> 同一张「熔岩」：**施放** = 喷发一次；**分解** = 换余响；**固化** = 留下一座**永久火山**。

### 9.2 扰动值（世界的状态）

干涉会**累积扰动**（0–100）。扰动不是惩罚，是**世界的状态**：

| 区间 | 状态 | 世界表现 |
|---|---|---|
| 0–30 | **稳定** | 天气温和、地形稳、生态规律 |
| 30–60 | **波动** | 天气极端、地形震动、生物行为异常 |
| 60–100 | **剧烈** | 奇观频发：浮空岛、极光暴、物种爆发、地貌抖动 |

- **平息**：消耗余响降低扰动。**放任**：让世界进入"剧烈"——**这是另一种玩法，不是失败**。

### 9.3 作用域与"接管"

- **作用域**：全局（整界）/ 区域（笔刷或矩形）/ 单体（某个体 / 某格）/ 笔刷（连续涂抹）。
- **接管规则**：凡是覆盖现实输入的卡（日照 / 天气 / 温度 / 节气），UI 上标记"**已由你接管**"，可一键**释放回现实**。

### 9.4 时效与现实加成

- **时效**：瞬时卡即刻结束；持续卡到释放；规则卡永久（可改回）。可用余响**延长**持续类。
- **现实加成**：真实节气与天气影响同类卡的表现——冬至冰类更强、下雨时水类更强。

## 10. 卡包与获取

卡包分**六种**，按"回答什么问题"归为三轨：

| 轨 | 包 | 内容 | 回答 |
|---|---|---|---|
| **玩法轨** | **元素包（Element Pack）** | **一个元素**的整套卡（**11 级 × 3 类 = 33 个卡种**，含该元素格的禁物档） | "这次主玩哪个元素" |
| | **故事包（Story Pack）** | 一段世界故事串联的卡 + 专属记录卡 + 专属卡背 | "讲哪个故事" |
| | **精灵包（Spirit Pack）** | **生灵卡**（物种）成包，一包 = 一个生态位的物种组 | "放什么活物" |
| | **地脉包（Ley Pack）** | **触发卡**成包，一包 = 一套"世界自动规则" | "定什么规则" |
| **审美轨** | **风格包（Style Pack）** | **纯表现层**：卡面美术 + UI 皮肤 + 立牌贴图 + 纸纹 + 粒子 | "我的界长什么样" |
| **现实轨** | **特殊包（Special Pack）** | **与真实时节绑定**：至日包、节气包、雨月包 | "外面是什么季节" |

**获取规则**：

- **基础卡** = **0 环碎片卡**（7 元素 × 3 类 = **21 个卡种**）——**永久免费直取**。
- **扩展卡**（**级 1 – 9**）——**开包解锁**，解锁后免费直取。
- **禁物档**——**不随机出**，按"发现 / 事件"获得；**同时只能启用一件**。
- **卡库直取已解锁的卡：免费**（零门槛使用）。
- **无稀有度**：包内只按主题与协同分组，**不分强弱**。
- **包不排他**：同一张卡可同时属于"水元素包"与「逆流的故事」故事包——**包是视角，不是归属**。

## 11. 命名与 id

**卡 id**：`card.<元素>.<级>.<卡类>.<名>`

| 段 | 取值 |
|---|---|
| `<元素>` | `metal` / `wood` / `water` / `fire` / `earth` / `light` / `dark`；**多元素用 `+` 连接**，如 `water+wood` |
| `<级>` | `0` – `9`；**禁物** = `ban` |
| `<卡类>` | `matter` / `rite` / `law` |
| `<名>` | 该卡功能名的**英文小写连字符** slug |

**示例**：

- `card.water.3.rite.rain` —— 水 · 3 级 · 术 · 降雨
- `card.earth.9.matter.mountain-range` —— 土 · 9 级 · 物 · 山脉
- `card.fire+wood.4.rite.wildfire` —— 火 + 木 · 4 级 · 术 · 野火（**多元素卡**）
- `card.metal.ban.matter.sun-cup` —— 禁物档（**无元素标签**，此处的 `metal` 只是矩阵格位）

> **格的坐标 ≠ 属性**：禁物在矩阵里占某个格位，但**它本身不带元素标签**。
