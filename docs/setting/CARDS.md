## 1 卡池骨架

### 1.1 三个维度

| 维 | 取值 | 数量 | 回答 |
|---|---|---|---|
| **元素**（元素标签） | 金 · 木 · 水 · 火 · 土 · 光 · 暗 | **7**（**可 1..N 个**） | 用哪种材料改 |
| **级**（环级） | **0 – 9**（十档）+ **禁物**（无环）+ **超环**（高于 9 环） | **12 档** | 改多大尺度 |
| **卡类** | 物 · 术 · 律 | **3** | 这张卡是什么 |

**元素与级正交**：任何元素都覆盖全部常规级；**禁物不带元素标签**（§3.3），**超环的档位定义待裁决**（[`CARD-LIST.md`](CARD-LIST.md) §2.5）。

### 1.2 卡种（kind）与张数（copy）

| 词 | 含义 |
|---|---|
| **卡种（kind）** | 一种卡 = 一组固定的「元素标签 + 级 + 类 + 持续性 + 效果」。**卡池按"种"计。** |
| **实体（copy）** | **你实际持有的"张"**——开包开出、被手牌随机抽到、被释放或回收消耗（[`../gameplay/INTERVENTION.md`](../gameplay/INTERVENTION.md) §1.5 / §1.6）。 |

> **卡种 ≠ 实体**：卡种是"设计",实体是"持有"。**"卡种 ≥ 252"说的是种类下限**；实际能打出多少手，取决于实体池。

### 1.3 单元素卡种的构成（下限 252）

| 段 | 算式 | 卡种数 |
|---|---|---|
| **常规卡**（0 – 9 十档） | 7 元素 × 10 档 × 3 类 | **210**（每个卡种都带元素标签） |
| **禁物**（无环） | 7 × 1 档 × 3 类 | **21**（**不带元素标签**，§3.3） |
| **超环**（越界档） | 7 × 1 档 × 3 类 | **21**（**带元素标签**；每元素每卡类各 1 张） |
| **单元素合计** | | **252（下限）** |
| **多元素卡种** | 元素组合 × 级 × 类 | **另计，往上加** |

### 1.4 多元素卡种（额外，往上加）

- **元素标签可取 1..N 个**：多个 = **多元素卡**（如 火 + 木 的野火 / 水 + 光 的虹）。
- 多元素卡同时参与各元素的生克结算；**光 / 暗 只与彼此生克，不与五行作用**（§8.2）。
- **不预设、不枚举**（§1.6）——设计具体某张卡时按需给标签。

### 1.5 阶段切分

| 阶段 | 卡种 | 说明 |
|---|---|---|
| **M0** | **36** | 土 / 火 / 金 三元素 × 级 0 – 3 × 3 类 |
| **M1** | 中界所需 | 另排 |
| **M2** | **≥ 252 全量** | 7 元素 × 12 档 × 3 类，多元素另计 |

### 1.6 卡池的填法规则（2026-10-14 定案）

| 规则 | 内容 |
|---|---|
| **目标** | **单元素卡以 252 为设计目标**（常规 210 + 超环 21 + 禁物 21）。 |
| **允许留空** | 某元素在某级做不出有意义的某卡类时，**该格允许留空**，登记在 [`CARD-LIST.md`](CARD-LIST.md) §5；**不允许为凑数而做"白开水卡"**。 |
| **多元素卡不预设** | **不预设清单、不做组合枚举**（全组合最多约 3960 个卡种，必然失控）；设计具体某张卡时，**若它天然跨元素，就给它多个元素标签**——从需求反推。 |
| **对外口径** | 无论留空多少，**"卡种 ≥ 252"始终成立**：留空的格子由多元素卡补足。 |
| **顺序** | 先填**单元素 252**（M0 只填 36），多元素卡随具体设计自然新增。 |

## 2 七个元素（原质）

| 元素 | 归属 | 生克归属 | 一句话 |
|---|---|---|---|
| **金** | 五行 | 走五行生克 | 刃、铸、矿、锈 |
| **木** | 五行 | 走五行生克 | 生长、蔓延、腐化 |
| **水** | 五行 | 走五行生克 | 流动、浸润、冰封 |
| **火** | 五行 | 走五行生克 | 燃烧、照亮、焚毁 |
| **土** | 五行 | 走五行生克 | 承载、堆叠、塌陷 |
| **光** | 独立 | **只与暗生克** | 照、折、晒 |
| **暗** | 独立 | **只与光生克** | 遮、藏、灭 |

- **七元素固定，不可增删**；**光 / 暗不参与五行生克**（§8.2）。
- 世界观里这套材料叫**原质**；落在卡上叫**元素标签**（[`WORLD.md`](WORLD.md) §1.4）。

## 3 级（环级：0 – 9 · 禁物 · 超环）

### 3.1 级 = 尺度，不是强度

| 级 | 名 | 尺度参照 | 单元素卡种数 |
|---|---|---|---|
| **超环** | **超环**（高于 9 环） | **越界**：改的是"规则之所以成立" | **21** |
| **9** | **神卡**（常规最高） | **整界**（★相对当前界尺寸：小界全覆盖、大界约 1/16） | 21 |
| **8** | 常规 | 半界 | 21 |
| **7** | 常规 | 一个气候带 | 21 |
| **6** | 常规 | 一片荒漠 / 雨林 | 21 |
| **5** | 常规 | 一道山脉 / 一条大河 | 21 |
| **4** | 常规 | 一片林 / 一个湖 | 21 |
| **3** | 常规 | 一座丘 / 一段溪 | 21 |
| **2** | 常规 | 一丛树 / 一口塘 | 21 |
| **1** | 常规 | 一小片草地 | 21 |
| **0** | **碎片卡**（最低） | **一片碎片**（一片苔 / 一粒沙 / 一滴水 / 一缕烟） | 21 |
| **禁物** | **禁物**（无环） | **不在尺度上** | 21 |

> **规则**：**数值越大，尺度越大，不是强度**——**低环卡永远有效、永远能用**，只是痕迹容易被更大的尺度盖过（§8.3）。
> **定名沿革**：原「星级 / 阶」作废，统一叫 **级（环级）**；**超环**在 2026-10-14 由用户重新引入为**独立档位**（历史上它曾是"权能卡"的别称，已于第 27 轮随权能线删除，**现与权能无关**）。

### 3.2 0 环：碎片卡（方案 A）

- **0 环 = 尺度最微的卡**：**有真实效果**，只是**小到"一片碎片"**。
- **不是废卡、不是残页**——不存在"只能分解成余响"的卡。
- **玩法特权**：0 环是**唯一永久免费、无限补进实体池**的档（[`../gameplay/INTERVENTION.md`](../gameplay/INTERVENTION.md) §1.6）；**但不可回收**（释放即销毁、无资源返回，§2.3）。

### 3.3 禁物档（21 种 · 无环）

| 项 | 内容 |
|---|---|
| **是什么** | **从界外漏进界里的碎片**——**不属于任何元素、任何组合** |
| **怎么用** | **只能"启用"或"封存"**；**不能养成、不能变强** |
| **代价** | **每一件都有**：启用后留下**抹不掉的痕迹**（扰动值 ↑），并且往往**同时改坏某样东西** |
| **参照** | **SCP 的"项目"** ＋ **《诡秘之主》的封印物**——**越有用，越危险** |
| **等级** | **无等级**（无环）：不分档、不分强弱；在卡池矩阵中占**禁物档**，**不带元素标签** |
| **张数** | **一种可持多张**，但**同时只能启用一件** |
| **回收** | **不可回收**（不许靠回收逃避代价） |

**示例（不分档）**：

| 禁物 | 代价 |
|---|---|
| 常温水杯：永远装满水 | **水无处可排** |
| 不落的叶：一株永不落叶 | **它的根周围寸草不生** |
| 逆流的沙漏：一片区域时间倒退 | **该区域留下永久斑点** |
| 无雨的铁云：整界永不下雨 | **生物缓慢失水** |
| 第二颗太阳：天空出现第二颗太阳 | **昼夜紊乱，扰动剧增** |

> **禁物只"启"不"养"**：不能变强、不能养成，只能**启用**（承担反噬）或**封存**——**全作唯一的"负面后果"来源**，与"永远不会输"构成张力。

## 4 三种卡类（物 / 术 / 律）

**卡类 = 这张卡在世界里"是什么"**——决定**卡面样式 / 牌背颜色 / 落地形态 / 能不能固化**。

| 卡类 | 一句话 | 内容 | 落地后 | 落地成实体 | 例 |
|---|---|---|---|---|---|
| **物** Matter | **世界里的东西** | 生物 · 死物 · 各个事物 | 变成实体或活体，留在世界里 | **能** → 留活物 / 地形 / 器物 / 碑 | 走兽、苔草、岩柱、湖泊、火山 |
| **术** Rite | **主动施展的效果** | 魔法 · 幻想法术等 | 什么都不留下，只改**状态** | **不能** → 只留一块**印记** | 降雨、重力减半、永昼、岩浆注入 |
| **律** Law | **写下来的规则与仪式** | 仪式 · 规则等 | 把一条**条件或誓约**刻进世界 | **能** → 刻成永久规则 | 水位 > 40 自动结冰、献祭唤风暴、命名、立碑 |

- **不分强弱**：三类只是**玩法手感**的区分——**造东西 / 点一下 / 定规矩**。
- **视觉**：物 = 灰石 · 术 = 靛蓝 · 律 = 赭红（各风格主题另配一套）。
- **与游戏王的对应**：物 ≈ 怪兽 + 场地 / 装备 · 术 ≈ 魔法 · 律 ≈ 陷阱。
- **252 个卡种的卡类配额（初值，2026-10-15 按 252 重算）**：**物 ~115 · 术 ~95 · 律 ~42**（按 231→252 等比放大取整；M2 定稿时对齐）。

## 6 ~~十二种卡型~~（★第 43 轮删除，机制改字段）

**「卡型」分类已删除**——生效方式不再是独立维度，改为卡上的**字段与可选参数**：

| 字段 / 参数 | 取值 | 承载的原卡型语义 |
|---|---|---|
| **持续性**（必填枚举） | **瞬时 / 持续 / 永久 / 触发** | 瞬时 ← 瞬时；持续 ← 持续 / 场域；永久 ← 规则；**触发 ← 触发**（"给世界定规则"由 **律类 + 持续性 = 触发** 承载，语法见 [`../gameplay/TRIGGERS.md`](../gameplay/TRIGGERS.md)——**机制不变**） |
| **释放条件**（可选参数） | 如"需元素 X 同时在场" | ← 合契 |
| **释放代价**（可选参数） | 如"消耗生物量 N / 准备 1 世界日" | ← 仪轨 |
| **落地形态**（写在模拟效果里） | 活体 / 地表材质 / 附着 / 无生命实体 / 区域环境 | ← 生物 / 材质 / 遗物 / 造物 / 场域 |
| **记录性**（写在模拟效果里） | 写入年表 / 世界呈现文本 | ← 记录 |

> **"给世界定规则"仍是本作最重要的机制**——它现在由「律类卡 + 持续性 = 触发 + TRIGGERS 词表」承载，地脉包、生效规则清单（12 条上限）全部不变。

## 8 相互作用（三套生克）

**卡带 1..N 个元素标签**；同一区域内，不同元素的卡按生克**自行结算**。生克有**三套**。生克效果是**物理属性结算的自然涌现**（原质→物理映射见 [`PHYSICS.md`](PHYSICS.md) §4），不需要逐卡特判。

### 8.1 五行生克（金 / 木 / 水 / 火 / 土）

**相生（互相增强）**

| 生 | 结果 |
|---|---|
| 金 → 水 | 金属表面凝露，矿脉渗水 |
| 水 → 木 | 疯长：植被爆发 |
| 木 → 火 | 助燃：火势失控 |
| 火 → 土 | 焦土沃化：灰烬变肥 |
| 土 → 金 | 结矿：土中析出矿脉 |

**相克（互相压制）**

| 克 | 结果 |
|---|---|
| 金 → 木 | 伐：植被被剃光 |
| 木 → 土 | 固：根系锁住土石 |
| 土 → 水 | 掩：填湖、断流 |
| 水 → 火 | 灭：熄火生雾 |
| 火 → 金 | 熔：金属熔化 |

### 8.2 光暗生克（光 / 暗 与五行互相独立）

| 关系 | 结果 |
|---|---|
| **光 生 暗** | 有光才有影：光照到哪，影就长到哪（**昼 → 影**） |
| **暗 生 光** | 暗到极处见光：夜尽天明、暗中之烛（**夜 → 昼**） |
| **光 克 暗** | 照亮即驱散：阴影退散、躲藏者现形（**显形**） |
| **暗 克 光** | 吞没即遮断：光源被吸、能见度骤降（**隐蔽**） |

> **光 / 暗不参与五行生克**（既不生也不克五行，五行也不生克它们），**只与彼此**生克。
> **光暗的平衡 = 昼夜节律**——世界钟与物候的驱动之一。

### 8.3 级生克（尺度覆盖）

| 关系 | 结果 |
|---|---|
| **高环 → 低环：克** | **尺度覆盖**：大尺度的改写会**盖过**同区域内小尺度的既有改动（9 环的改地形盖掉 0 环的一片苔） |
| **低环 → 高环：生** | **累积诱发**：许多小改动长期叠加，会**自己长成**一个大尺度的结果（连年小雨 → 气候变湿） |

> **注意分寸**：这条生克是**尺度覆盖**，**不是数值碾压**——**低环卡永远有效、永远能用**，只是痕迹会被更大的尺度盖住。

**三套可同时结算**：一张卡可以既有元素标签（吃五行 / 光暗生克），又被更大尺度覆盖（吃级生克）。
**反应写进年表**，且是**涌现**的——玩家常会撞见"我没设计过的组合"。

### 8.4 相合（★留档，暂不运行）

**两条元素相合生成"第三种质"**（曾叫「新质」/「异质」）——**该体系已整体撤出核心**，仅留档备查（名单见 [`WORLD.md`](WORLD.md) §1.5），**世界目前按"七元素"运行**。

## 9 机制（用法与作用域）

### 9.1 两个动作（释放 / 回收）

| 动作 | 结果 | 什么时候用 |
|---|---|---|
| **释放** | 卡的效果作用于世界；**有可落地形态时可选"生效即散 / 落地成实体"**（即原"固化"） | 想改世界 |
| **回收** | **销毁这张卡**，换回**折扣余响** | 卡不对路、缺资源 |

> 完整规则（含消耗、手牌、实体池、回收定价）见 [`../gameplay/INTERVENTION.md`](../gameplay/INTERVENTION.md) §1 与 §2.3。
> 同一张「熔岩」卡：**释放（生效即散）** = 喷发一次；**释放（落地成实体）** = 留下一座永久火山；**回收** = 换回折扣余响。

### 9.2 时效

瞬时即刻结束；持续到被改回；**永久写进法则**（可改回）；触发按 WHEN-THEN 规则自动执行。持续性是卡的**字段**（§6 / §7）。

### 9.3 作用域（字段取值）

全局（整界）/ 区域（笔刷或矩形）/ 单体（某个体 / 某格）/ 笔刷（连续涂抹）。

### 9.4 与世界状态的接口

**扰动值 / 接管与释放 / 现实加成**属玩法层，见 [`../gameplay/INTERVENTION.md`](../gameplay/INTERVENTION.md) §3 / §5.2 / §5.3。

## 10 卡与卡包的归属

**卡包（怎么获得）与手牌（怎么用）属玩法层** → [`../gameplay/INTERVENTION.md`](../gameplay/INTERVENTION.md) §4。
本节只记两条**设计约束**：

1. **包不排他**：同一张卡可同时属于多个包——**包是视角，不是归属**。
2. **无稀有度**：包内只按主题与协同分组，**不分强弱**；"保值率"（§2.3 的回收率）只影响回收，**不影响功能**。

## 11 命名与 id

**卡 id**：`card.<元素>.<级>.<卡类>.<名>`（**技术层唯一真源**；[`../tech/STRUCTURE.md`](../tech/STRUCTURE.md) §7.3 只作指针）

| 段 | 取值 |
|---|---|
| `<元素>` | `metal` / `wood` / `water` / `fire` / `earth` / `light` / `dark`；**多元素用 `+` 连接**，如 `water+wood` |
| `<级>` | `0` – `9`；**禁物** = `ban`；**超环** = `over` |
| `<卡类>` | `matter` / `rite` / `law` |
| `<名>` | 该卡功能名的**英文小写连字符** slug |

**示例**：

- `card.water.3.rite.rain` —— 水 · 3 级 · 术 · 降雨
- `card.earth.9.matter.mountain-range` —— 土 · 9 级 · 物 · 山脉
- `card.fire+wood.4.rite.wildfire` —— 火 + 木 · 4 级 · 术 · 野火（**多元素卡**）
- `card.metal.ban.matter.sun-cup` —— 禁物档（**无元素标签**，此处的 `metal` 只是矩阵格位）

> **格的坐标 ≠ 属性**：禁物在矩阵里占某个格位，但**它本身不带元素标签**。
> **文案与命名规范**（中英对照、命名禁忌）见 [`WORLD.md`](WORLD.md) §6。
