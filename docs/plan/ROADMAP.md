## 1 三阶段切分（防范围爆炸）

| 阶段 | 内容 | 不含 |
|---|---|---|
| **M0 小界** | **小界 128² 单界**；纸雕风格锚（描边 + 色阶 + 硬阴影 + 移轴）；双时间模式（真实模式含联网天气）；**混沌初态 + 生命引入**（预设自带或生命卡引入，5 物种模板）；**卡池 36 个卡种范围**（**土 / 火 / 金 三元素 × 环级 0 – 3 × 3 类 = 36**，逐卡制作）；**「余响」+ 开包 + 卡库（0 环免费无限补池；卡库只读）**；年表；离线暂停；中英双语；分块流式 + SimLOD 基础 | 中 / 大界、多界、演化、时间倒带、界创建向导、扩展卡解锁 |
| **M1 中界** | 中界 256² + 4–6 生态域；卡池扩到 6 类（+水体 / 大气 / 生命）；**扩展卡解锁（余响 → 开包）**；**界创建向导（简化版）**；8 物种；时间倒带；**音频基础**（环境音分层 + 纸声仪式感 + 极简 UI 音 + 音量总线，来源策略到时定）；**存档与离线续跑**（自 M0 验收移入，第 46 轮） | 大界、多界、演化、物理法则卡、风格包与剪影（第 47 轮否决） |
| **M2 大界与小世界** | 大界 512² 分块 + 8+ 生态域与气候带；**卡种全量 ≥ 252（7 元素 × 12 档（0 – 9 / 超环 / 禁物）× 3 类，多元素卡种另计）**；演化系统；**多界并存**；创世面板全参数；导入导出 + 出厂预设 | —— |

> 「详细丰富多彩」是**最终形态**（M2），M0 只证明三件事：**它真的活着**、**纸雕风格立住了**、**干涉看得见后果**。

## 3 M0 前置条件（用户侧）—— ✅ 2026-10-16 全部满足

1. **引擎** ✅：`D:\Epic Games\UE_5.8`，版本 **5.8.3**（此前 15.67GB 未登记残件的判断已随重装失效）。
2. **VS2022 生成工具 +「使用 C++ 的桌面开发」** ✅：落在 `D:\VS2022`，MSVC 14.44.35207，Windows SDK 10.0.22621.0 落 `C:\Program Files (x86)\Windows Kits\10`。
3. **`.NET Framework 4.6.2 SDK`** ✅：原本三处全无、注册表也没有，是 UBT 的**唯一硬阻塞**（`SwarmInterface.Build.cs`）。已从本机 VS 渠道清单提取官方包并部署到 `D:\_toolchain\AutoSDK\…`，做法见 [`../ops/ENV.md`](../ops/ENV.md) §1.3。
4. **缓存外置** ✅：`UE-LocalDataCachePath=D:\UE-DDC`。
5. **磁盘结论：不需要清理 C 盘**。实测 C 盘 77.4GB，C 盘实际需求约 10–15GB（`check-env.ps1` 的 120GB 只是保守阈值）。
6. **本机编译须加 `-NoUBA`**：UBA 的文件系统 detour 在本机报 access denied，会把 PCH 编译全部打挂。原因与绕过见 [`../ops/ENV.md`](../ops/ENV.md) §2.4.1。

> 具体安装步骤与脚本见 [`../ops/ENV.md`](../ops/ENV.md) 与 `tools/README.md`。

## 4 风险与对策

| 风险 | 对策 |
|---|---|
| **全 3D 切断 2D 生图产能** | 程序化几何为主 + 生图线转产纸纹 / 卡面；风格选"块面 = 纸雕"使低模成为优点（[`../setting/STYLE.md`](../setting/STYLE.md)、[`../art/ASSETS.md`](../art/ASSETS.md)） |
| **范围爆炸**（三档界 + ≥252 个卡种 + 演化 + 向导） | 本文 §1 三阶段切分；M0 锁死 128² 单界 + 36 个卡种（三元素 × 0–3 级） |
| 程序化几何看着廉价 | 靠"纸雕"风格与硬阴影 / 移轴 / 层叠支撑识别度；风格不定标不进内容量产 |
| 性能（大界 + 8000 个体） | SimLOD + 只推演激活界 + 分块流式 + 实例化（[`../tech/ARCHITECTURE.md`](../tech/ARCHITECTURE.md) §1） |
| **余响引入"进度感"** | 红线约束：只买**选择与审美**、不买**强度**；无稀有度、无失败扣除、无日常任务；余响只增不减（[`../gameplay/INTERVENTION.md`](../gameplay/INTERVENTION.md) §2.3） |
| **干涉机制学习成本** | 首屏只默认展示"瞬时卡"，扰动值 / 相互作用 / 触发卡由玩家在世界反馈里自行发现（不做教程弹窗，守 [`../gameplay/UI-UX.md`](../gameplay/UI-UX.md) §3 极简原则）；卡面用图示直白表达（[`../gameplay/INTERVENTION.md`](../gameplay/INTERVENTION.md) §3、[`../setting/CARDS.md`](../setting/CARDS.md) §8） |
| 无目标 → 打开理由缺失 | 现实耦合 + 开包的"这次能怎么玩" |
| 真实模式变化太慢 → 无聊 | 定位为"挂着的活世界"；想玩一键切虚拟 |
| 时间倒带 / 因果重演的实现复杂度 | 依赖"固定 tick + 指令流 + 快照"，M1 才做；M0 只做年表 |
| 编辑器无法由 AI 操作 | 可代码化 / 脚本化的默认由 AI 做；蓝图配逐条说明书 |
| 联网失败导致真实模式不可用 | 三级降级 + UI 标记；不阻塞 |
| 纸雕风格在 3D 中不易立住 | 三张对照截图先行定标（[`../setting/STYLE.md`](../setting/STYLE.md) §3），定不下就回退到 2D 精灵方案 |
| **音频延后到 M1 的工程返工** | ★2026-10-15 挂账：M0 工程里**预留音频总线占位**（Master / Environment / UI / SFX 四条 SoundMix 总线 + 音量设置页），只留接口不产内容——避免 M1 接音频时动工程结构 |
| **打包版读不到运行时 JSON**（UAT 只 stage `Default*.ini`，`Config/Solstice/` 下的契约数据与本地化不会进包） | ★2026-10-16 登记：P5 打包前迁 `Content/Solstice/` + `DirectoriesToAlwaysStageAsUFS` 并实测一次打包（[`../tech/STRUCTURE.md`](../tech/STRUCTURE.md) §10.7）；编辑器内运行不受影响 |

## 5 执行计划（P0–P5）

**依赖链**：`P0 → P3 → P4 → P5`，`P1 → P2 → P4`；P2 与 P3 无依赖可并行。**关键路径是 P2**。

| 阶段 | 状态 | 内容 | 验收 | 谁做 |
|---|---|---|---|---|
| **P0 环境就绪** | ✅ 2026-10-16 | 装引擎（5.8.3）、装 VS2022 生成工具、补 `.NET Framework 4.6.2 SDK`、缓存外置 | `check-env.ps1` 全绿；能生成空工程并编译 | **用户执行**，AI 出命令 |
| **P1 契约收尾** | 🟡 | 核对 `STRUCTURE.md`（**v3.0 已定稿**）；`species.json` / `cards.*.json` / `world.json` **已落地**，`save.json` 待 M1；M0 卡种范围框架确认 + **首批卡逐张制作启动**（第 38 轮口径） | 文档自洽、契约可校验 | AI |
| **P2 逻辑内核 ★** | ✅ 主体 | `Sim/SolsticeKernel.cpp`（约 2500 行）：双模式世界钟 + 现实锚 + 地形 / 五轴生态域 / 天气状态机 / 五物种生态 / SimLOD / 卡指令接口 / 余响 / 年表；**`-run=SolsticeBench` headless 基准** | 验收 2（部分）、4（逻辑部分） | AI（纯 C++） |
| **P3 风格与骨架** | 🟡 骨架完成，风格未定标 | `Solstice.uproject` + 2 个 Target + 2 个模块 + Build.cs；程序化几何生成器；纸雕主材质（**由代码生成**，4 档 Cel 分带 + unlit + 顶点色自发光）；HUD（纯 Slate）；**描边 / 硬阴影 / 移轴与三张对照截图未做** | 验收 1 ✅、5、9 | AI 为主，风格裁决用户 |
| **P4 M0 小界** | 🟡 内核齐、玩法未接 | 小界 128² ✅ + 5 物种 ✅ + 卡池 / 手牌 / 开包 / 卡库（内核已实现，**UI 未接**）+ 双模式 ✅ + 联网天气 🟡 + 年表 ✅ + 离线暂停 ✅ + 双语 🟡 | 验收 6–8、11–13 | AI |
| **P5 卡面与打磨** | ❌ 未开始 | ComfyUI 卡面与纸纹管线 + 四季色板 + 性能收尾 + 运行时 JSON 打包 stage 修正（§4） | 验收 4（GPU 部分）、12 | AI + 用户挑图 |

> M1 / M2（中界 / 大界 / 多界 / 演化 / 向导）在 P5 之后另立计划。

**P2 路线裁定**：不做 Python 原型，直接写引擎无关的 C++ 内核。代价：P0 完成前无法验证任何逻辑。
