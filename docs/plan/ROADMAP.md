| 阶段 | 内容 | 不含 |
|---|---|---|
| **M0 小界** | **小界 128² 单界**；纸雕风格锚（描边 + 色阶 + 硬阴影 + 移轴）；双时间模式（真实模式含联网天气）；**卡池 36 个卡种**（**土 / 火 / 金 三元素 × 环级 0 – 3 × 3 类 = 36**）；**「余响」+ 开包 + 卡库（基础卡全免费直取）**；5 物种；年表；离线暂停；中英双语；分块流式 + SimLOD 基础 | 中 / 大界、多界、演化、时间倒带、界创建向导、扩展卡解锁 |

> 「详细丰富多彩」是**最终形态**（M2），M0 只证明三件事：**它真的活着**、**纸雕风格立住了**、**干涉看得见后果**。

## 2 M0 验收标准

| # | 验收 |
|---|---|
| 1 | 编译通过，VSCode 一键构建 |
| 2 | headless 批量快进：30 世界日 < 10 秒；同种子同结果（连续 3 次一致） |
| 3 | 连续运行 1 真实小时不崩、无实体泄漏（实体数守恒校验通过） |
| 4 | **性能**：小界观测态 GPU < 5%、逻辑 ≤ 2ms；推演态 20x 逻辑 ≤ 8ms；内存 < 1.5GB |
| 5 | 分块流式生效：移动相机时无卡顿尖峰（> 50ms 的帧为 0） |
| 6 | 真实模式：联网取到真实天气并进入世界；断网降级到虚拟天气且 UI 明确标记 |
| 7 | 虚拟模式：暂停 / 1x / 4x / 20x 生效、比例可调；切到真实模式后时间控件消失 |
| 8 | 离线再打开：生态从冻结处继续，真实模式环境已同步到当前现实 |
| 9 | **风格**：正午 / 黄昏 / 雨三张截图与风格锚一致（用户裁决） |
| 10 | 因果可读性：抽查 10 次死亡均能从画面读出死因 |
| 11 | 中英双语无遗漏（UI 与卡面文案） |
| 12 | **余响**：事件回响与偏移幅度正相关；反复刷同一张小卡几乎不产出（防刷） |
| 13 | **人工验收：窗口摆在桌面 10 分钟，你不想关掉它** |

## 3 M0 前置条件（用户侧，2026-10-14 核查后修订）

1. **引擎**：处理 `D:\Epic Games\UE_5.8` 残件（15.67GB 未登记下载暂存，无 `Engine/`）后重装；目标 `D:\Epic Games\`。
2. **VS2022 生成工具 +「使用 C++ 的桌面开发」**；C 盘紧张时用官方 bootstrapper 指定 `--installPath D:\VS2022`。**Windows SDK 固定落 `C:\Program Files (x86)\Windows Kits\10`**，不提供改路径选项。
3. **缓存外置**：`UE-LocalDataCachePath=D:\UE-DDC`。
4. **磁盘结论：不需要清理 C 盘**。实测 C 盘 77.4GB / D 盘 354.3GB，C 盘实际需求约 10–15GB（`check-env.ps1` 的 120GB 只是保守阈值）。

> 具体安装步骤与脚本见 [`../ops/ENV.md`](../ops/ENV.md) 与 `tools/README.md`。

## 4 风险与对策

| 风险 | 对策 |
|---|---|
| **全 3D 切断 2D 生图产能** | 程序化几何为主 + 生图线转产纸纹 / 卡面；风格选"块面 = 纸雕"使低模成为优点（[`../setting/STYLE.md`](../setting/STYLE.md)、[`../art/ASSETS.md`](../art/ASSETS.md)） |
| **范围爆炸**（三档界 + ≥252 个卡种 + 演化 + 向导） | 本文 §1 三阶段切分；M0 锁死 128² 单界 + 36 个卡种（三元素 × 0–3 级） |
| 程序化几何看着廉价 | 靠"纸雕"风格与硬阴影 / 移轴 / 层叠支撑识别度；风格不定标不进内容量产 |
| 性能（大界 + 8000 个体） | SimLOD + 只推演激活界 + 分块流式 + 实例化（[`../tech/ARCHITECTURE.md`](../tech/ARCHITECTURE.md) §1） |
| **余响引入"进度感"** | 红线约束：只买**选择与审美**、不买**强度**；无稀有度、无失败扣除、无日常任务；余响只增不减（[`../gameplay/INTERVENTION.md`](../gameplay/INTERVENTION.md) §2.3） |
| **干涉机制学习成本** | 首屏只默认展示"瞬时卡"，扰动值 / 相互作用 / 触发卡由玩家在世界反馈里自行发现（不做教程弹窗，守 [`../gameplay/UI-UX.md`](../gameplay/UI-UX.md) §3 极简原则）；卡面用图示直白表达（[`../gameplay/INTERVENTION.md`](../gameplay/INTERVENTION.md) §3、[`../setting/CARDS.md`](../setting/CARDS.md) §8） |
| 无目标 → 打开理由缺失 | 现实耦合 + 开包的"这次能怎么玩" |
| 真实模式变化太慢 → 无聊 | 定位为"挂着的活世界"；想玩一键切虚拟 |
| 时间倒带 / 因果重演的实现复杂度 | 依赖"固定 tick + 指令流 + 快照"，M1 才做；M0 只做年表 |
| 编辑器无法由 AI 操作 | 可代码化 / 脚本化的默认由 AI 做；蓝图配逐条说明书 |
| 联网失败导致真实模式不可用 | 三级降级 + UI 标记；不阻塞 |
| 纸雕风格在 3D 中不易立住 | 三张对照截图先行定标（[`../setting/STYLE.md`](../setting/STYLE.md) §3），定不下就回退到 2D 精灵方案 |

## 5 执行计划（P0–P5）

**依赖链**：`P0 → P3 → P4 → P5`，`P1 → P2 → P4`；P2 与 P3 无依赖可并行。**关键路径是 P2**。

| 阶段 | 内容 | 验收 | 谁做 |
|---|---|---|---|
| **P0 环境就绪** | 清残件装引擎、装 VS2022 生成工具、缓存外置 | `check-env.ps1` 全绿；能生成空工程并编译 | **用户执行**，AI 出命令 |
| **P1 契约收尾** | 核对 `STRUCTURE.md`（已定稿）；定 `species.json` / `cards.json` / `world.json` / `save.json`；36 个 M0 卡种定稿 | 文档自洽、契约可校验 | AI |
| **P2 逻辑内核 ★** | 双模式世界钟 + 现实锚（可注入假时钟 / 假天气）+ 生态演化 + SimLOD + 卡指令接口 + headless 基准 | 验收 2、3、4（逻辑部分）、10 | AI（纯 C++） |
| **P3 风格与骨架** | `Solstice.uproject` + 模块 + Build.cs；程序化几何生成器；纸雕渲染管线（Cel LUT / 描边 / 硬阴影 / 移轴）；**三张对照截图定风格** | 验收 1、5、9 | AI 为主，风格裁决用户 |
| **P4 M0 小界** | 小界 128² + 5 物种 + 36 个卡种 + **余响 / 开包 / 卡库** + 双模式 + 联网天气 + 年表 + 离线暂停 + 双语 | 验收 6–8、11–13 | AI |
| **P5 卡面与打磨** | ComfyUI 卡面与纸纹管线 + 四季色板 + 性能收尾 | 验收 4（GPU 部分）、12 | AI + 用户挑图 |

> M1 / M2（中界 / 大界 / 多界 / 演化 / 向导）在 P5 之后另立计划。

**P2 路线裁定**：不做 Python 原型，直接写引擎无关的 C++ 内核。代价：P0 完成前无法验证任何逻辑。
