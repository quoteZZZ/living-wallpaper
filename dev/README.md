# dev/ —— 工程基建（与游戏内容、素材都无关）

| 目录 | 内容 |
|---|---|
| `sync/` | 双机协作的 git 自动同步脚本（代码机 pull-only / 素材机 `-Push`），用法见 `docs/SYNC.md` |
| `spikes/` | **已验证机制留档**：一次性验证脚本，验证过的机制沉淀进 `docs/DESIGN.md` 后，脚本留在这里当证据，不参与运行 |

## 归属判断

- 影响"游戏跑起来是什么样" → `app/`
- 影响"素材长什么样、怎么生产" → `studio/`
- 影响"两台机怎么协作、机制能不能跑通" → `dev/`
- 只是给人看的规定 → `docs/`
